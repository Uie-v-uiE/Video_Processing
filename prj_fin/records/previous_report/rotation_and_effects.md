# 旋转、缩放与效果：算术与数据通路

这一章讲几何和效果链怎么算，以及哪些常数钉死了取值范围。所有运算在像素时钟上完成，使用定点算术，不调用浮点单元，也不依赖 PS。

## 坐标映射

屏幕坐标先做逆映射，得到源坐标 `sx, sy`、越界标志和双线性权重。缩放系数用 Q8 定点：码值 256 表示 1.00 倍，码值越大画面越小。八档手动倍率是 0.25、0.33、0.50、0.75、1.00、1.33、1.50、2.00。默认停在 1.00 倍，自动呼吸是另一条命令。

无旋转时，映射就是把屏幕坐标相对中心缩放：

```text
sx = W/2 + ((x - W/2) * inv) >> 8
sy = H/2 + ((y - H/2) * inv) >> 8
```

有旋转时，先算缩放偏移，再套 Q8 的正弦和余弦。角度范围 0 到 359°，正弦和余弦各用一张 360 项的查找表。旋转和缩放共用这组算子，所以原图和处理图看到的是同一个几何。

旋转打开时，控制器会把倍率收进“当前角度刚好装得下”的那一档，避免转出画面。手动档号不会丢，关掉旋转后立刻恢复。代价是旋转态不提供放大，1.33、1.50、2.00 三档会被拉回拟合档；缩小方向照旧。0° 时不受这条限制。

越界像素填黑。这是有意的：它让“画面转出边界”在屏上直接可见，而不是被悄悄裁掉。

## 双线性插值

每个源像素需要四个邻点。读口按像素时钟的节拍把它们取齐，`bilin_en=0` 时逐位退化为最近邻，方便对照“插值本身带来了多少差异”。

读口是单口的，一对结果要下一对才读得到，因此比最近邻多两显示行的延迟；这个延迟在顶层坐标里一起抵消。插值权重由逆映射的小数部分给出，不需要除法。

## 窗口滤波取在目标域

旋转之后再做 3×3 窗口滤波，有三种做法。

A：角度不为 0 时关掉窗口滤波。实现简单，但效果随角度消失，演示不成立。

B：先把整帧旋转到另一个缓冲，再在源域滤波。需要双缓冲，BRAM 不够，延迟也大。

C：在目标域做。逆映射之后，按屏幕光栅取 3×3 邻域，滤波和显示在同一个域里完成。当前采用这一种。

代价是窗口半径按显示像素算，横向半径只有半个源像素；处理内容整体滞后 4 行，顶层把右窗的读坐标提前 4 行来抵消。这是当前画幅下的既定取舍，不是待修的问题。

## 效果链

效果链共六级。级 0 是 gamma，查找表组合读出，不占拍。级 1 到 5 依次是：

| 级 | 算法 | 拍数 |
|---|---|---:|
| 1 | 灰度、反色 | 1 + 1 |
| 2 | 箱式模糊、锐化 | 3 + 3 |
| 3 | Sobel | 3 |
| 4 | 二值化（带判决反相） | 1 |
| 5 | 腐蚀或膨胀 | 3 |

把各级拍数相加，正好是 15 拍。这个常数与打开哪些级无关，因为旁路路径按同样的级数延迟。竖缝的左右两半必须在同一拍对齐，如果延迟随配置变化，缝两侧就会出现固定的错位。

腐蚀与膨胀互斥。两位同时置位时两个都不做，因为开运算和闭运算需要两遍 3×3 窗口，这里只有一遍。这是明确旁路，不是悄悄当成开运算。

形态学的掩码每个像素只存 1 bit，两条行缓存一共 512 bit × 2。二值化之后的图只有黑白两种值，用掩码做邻域判断比存 16 位像素省得多。

## 竖缝的两种坐标

竖缝可以按屏幕列设置，也可以按画面列设置。前者是固定的屏幕位置，后者跟着旋转和缩放一起走，适合检查旋转状态下的边界。

标记线默认画两像素宽，位置与画面几何使用同一个越界判据，线的端点不会跑到画面外。做像素测量时应当关掉标记线，因为它本身会被误认成一条竖线。命令是 `split marker 0`。

## 串口与屏上现象的对应

| 命令 | 屏上应该看到 |
|---|---|
| `pipe 000000001` | 处理侧变灰，缩放和缝位不变 |
| `pipe 000010000` | 处理侧出现 Sobel 边缘 |
| `pipe 000001000` | 处理侧变二值 |
| `zoom 1.0` | 回到 1.00 倍；`zoom 1` 是开关，不是倍率 |
| `rot auto 1` / `rot speed 0` | 画面开始转 / 停在当前角度 |
| `split video` | 缝跟着画面转 |
| `split marker 0` | 关掉两像素标记线 |

命令的确切格式、哪些写法会被拒，以 `report/commands.md` 与 `report/command_precedence.md` 为准。屏上观感要人眼确认，落点在 `board/acceptance.md`。

## 证据

几何有三支台架：`tb_zoom_mapper` 管 1.0 倍恒等、0.5 倍中心和越界；`tb_zoom_sel` 管旋转生效时倍率被收进哪一档；`tb_fb_bilinear` 管四个邻点的取法和旁路。

效果链的 15 拍由台架逐拍量过再与声明值比较；形态学、二值化和窗口级各有自己的台架。完整视频台架把这些能力放在一起跑，跑满 4,569,600,090 ns，0 errors。

更细的模块端口和逐拍假设在 `report/src-map.md`；这一章只讲算术和通路，不重复抄端口表。
