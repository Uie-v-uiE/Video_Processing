## A. 业务与赛道（先背）

### A1 赛事规则 ★
- 科技创意类 = 方案/技术报告，**不要求实物**；软件/仿真类决赛要**演示功能**
- 附件可含：视频、图片、源代码
- 评审三性：科学性、创新性、实用性；三自：自己提出、自己构思、自己制作
- 提交窗口：2026-09-15～10-10；每校创意类限 10 件
- 往届创意一等奖形态：应急车道监督、智能红绿灯、智能救生圈 → **强应用闭环**

### A2 共享单车电子围栏业务 ★
- 围栏用途：规范停放、调度费/信用分、城管考核
- 痛点：高楼多径 → 解算漂出框 → **误扣费、申诉、投诉**
- 运营量级概念：全国千万级车辆、热点地铁口误判率敏感
- 与蓝牙信标/地磁对比：成本 vs 精度；可作 HOLD 后的复核手段 ◆
- 「不可信不扣费」的商业含义：体验优先 vs 秩序（可讨论漏判违停）◆

### A3 竞品/替代方案（能说 3 个）★
1. 纯多边形包含（现状）
2. 蓝牙信标/UWB 厘米级（贵、部署密）
3. 多星座+多频提高精度（不解决欺骗）
4. 云端轨迹后处理（延迟、隐私）

## B. GNSS 定位基础

### B1 伪距定位 ★
- 伪距 ≈ 几何距离 + 接收机钟差 + 误差
- 至少 4 颗星解 x,y,z,dt
- WLS / 最小二乘迭代：设计矩阵 H（视线单位矢量 + 钟差列）
- 几何：ECEF、本地 ENU、简化星座 vs 精密星历 ◆

### B2 误差源 ★
- 多径：反射导致码/载波偏差，城市峡谷主因
- 电离层/对流层、卫星钟差、相对论（概念级即可）◆
- 为什么本作品用「简化星座 + 注入」：验证方法，不是精密定位产品

### B3 载波相位 / RTK / PPP（知道即可）◆
- 为何本方案不用：锁端成本、初始化、遮挡

## C. 完好性与检测（核心算法层）

### C1 RAIM / 残差一致性 ★★
- 残差 = 观测 − 预测几何距离（去公共钟差）
- RMS 超阈 → 可疑；可用星不足或 RMS 巨大 → 拒止
- 与航空 RAIM 的异同：我们服务计费，不是航电认证 ◆
- 阈值：sigma0、k 倍、剔野 4σ 类规则——会解释「为何 4σ」

### C2 欺骗类型 ★
- 慢拉欺骗（slow pull-off）：偏置随时间增大，早期难察觉
- 本作品：部分卫星公共偏置 + 小通道差
- 拒止/压制：噪声淹没、失效通道

### C3 为何残差对多径/欺骗有效（定性）★
- 多径：部分星异常 → 残差抬升
- 慢拉：公共部分被钟差吸收一部分，**通道不一致性**仍可显
- 局限：全部星近公共偏差时可能漏检 ◆（诚实边界）

## D. 数字孪生与实验方法

### D1 什么是本作品的「数字孪生」 ★
- 不是 3D 可视化，是：**可配置场景 → 可复现观测 → 可量化指标**
- 与硬件在环（HIL）区别：无 RF，成本低，适合教学/回归 ◆

### D2 测试集设计 ★
- 维度：清洁 / 城市多径 / 慢拉欺骗 / 复合 / 局部拒止
- 贴边停车轨迹：模拟「找车位靠边停」
- 同源：PC 与板端同一 `fence_testset.h`

### D3 指标定义 ★★
| 指标 | 含义 |
|------|------|
| naive_ff | 真在框内却判外（旧逻辑误扣） |
| trusted_ff | 本方案误扣 |
| hold | 不可信占比（不扣费） |
| p95 误差 | 定位误差分位数 |
| 漏判违停 | 真在外却判内（了解，报告可写） |

- 为何用「误扣率」而不是只报 RMSE：**业务可读**

### D4 边界与不确定性（评委爱问）★
- 简化星座几何真实性
- 阈值需运营标定
- 实采数据、星历升级路径

## F. 嵌入式 / 上板（加分，但要能说）

### F1 Zynq 是什么 ★
- PS = ARM Cortex-A9；PL = FPGA fabric
- 本作品板端只用 **PS**；PL 可选加速（非必须）

### F2 JTAG 下载 standalone ★
- 不依赖 SD 启动；Vitis/xsct `dow` ELF → `con`
- 串口 xil_printf 打 EVAL

### F3 为何量产用 MCU 不用 Zynq ★★
- 成本、功耗、锁控算力绰绰有余
- Zynq：研发验证 / 未来 RSU 多车聚合 ◆

### F4 你只审 FPGA 时看什么 ★
- 分区是否「可选」、资源估是否吹牛、接口是否服务业务
- 不要求你改算法

## H. 可能被追问的「深水」题（选学，防卡壳）

| 题 | 答题要点 |
|----|----------|
| 与 RAIM 论文比有何新？ | 应用集成 + 计费语义 + 复合剧本，不是新检测理论 |
| 会不会被用来逃费？ | HOLD 进人工/信标复核队列，可限频、可信用分 |
| 阈值谁定？ | 运营按误扣/漏判权衡 ROC 式标定 ◆ |
| 多星座 BDS+GPS？ | 可扩展，星数↑几何改善；本作品先 BDS 叙事 |
| 隐私？ | 仅位置用于围栏，可本地判定不上传轨迹细节 ◆ |

| 延迟？ | 停车结算允许秒级；1 Hz 历元足够 |
| 开源/数据？ | 场景与代码在工程内，金标准 CSV 可复现 |

## J. 白板最小板书（建议练）

```text
伪距: ρ = |x_sat - x| + c·dt + ε
残差: r = ρ - |x̂ - x_sat|  →  RMS
RMS 大 → 不可信 → 不扣费
RMS 小 → 围栏包含 → OK / FEE
指标: 84%→11% (多径误扣)
```

## K. 增强层 PLTG 必背（被追问"你这不是不判了吗"时用）

```text
经验阈值的问题：多径 8 m 时 P1 的 HOLD=0（照样出结论）→ 漏判违停 5%
                 多径 20 m 时 P1 误扣 0.8%   → "这次没误扣" ≠ "不会误扣"

T   = Σr²/σ₀²  vs  χ²(1−P_fa, M−4)      P_fa = 1e-2      → 门限来自预算
σ_h = √(Qxx+Qyy)，Q = σ̂²(HH)⁻¹
HPL = k·σ_h，k = √(−2 ln P_hpa) = 3.72   P_hpa = 1e-3
IMargin = |d| − HPL                        d = 到围栏边界的有符号距离

零速聚窗：W 历元共用 1 个平面位置 + 每历元 1 个钟差
          钟差用"历元内去均值"解析消掉（FWL 等价）→ 未知数 2+W → 2
          等效精度 ~1/√W；多径正弦结构窗口内自相消 → HOLD 变 3 s 延迟定案

围栏对偶假设检验：δ = (SSE_out − SSE_in)/σ̂²，δ_th = χ²(0.999, 2) = 13.8
                  δ≥+门限 合规 / δ≤−门限 违停 / 否则 HOLD
                  约束解 = 活跃集投影（4 条贴边解 + 4 个角点解取最小）

分级降级：GNSS χ² 失败 → 3 个路侧锚点(σ=0.3 m，与卫星无关)重解 → 仍不可判才人工复核

数字：旧逻辑 误扣13.31% / P1 0.17%+HOLD44.0% / P2(仅保护级)HOLD96.5%
      P3 误扣0%+HOLD75.4%+3s定案 / P4 误扣0%+HOLD2.6%+自动判决97.4%
      期望代价 4.84 → 1.78 → 2.35 → 0.08（P4 = P1 的 1/22）
消融：只用保护级 HOLD 96.5% → 保护级+聚窗+对偶检验缺一不可
      去掉 χ² 门：误扣仍 0，但最差定案 3 s → 76 s
敏感性：窗口 6→40、HPL_max 2→8 m → HOLD 只在 0.752~0.760 之间（不是调出来的）
可移植：fpga/software/plfg_window.c（纯 stdio/math）↔ Python，363 历元判决动作 100% 一致
```

诚实边界（不要回避）：多径 20 m 时 GNSS 单源 HPL 6.37 m > 围栏最小半宽 6 m，
**判不动是物理事实**；逐星独立且小于噪声的智能欺骗不承诺检出（射频层问题）。
