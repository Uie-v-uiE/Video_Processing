# FPGA / SoC 架构（**可选落地形态**，非方案必要条件）

> 定位说明（给答辩）：  
> 本作品核心是「可信电子围栏计费规则 + 数字孪生验证」。  
> **量产锁控以 MCU/模组为主路径**；Zynq 仅作研发验证与路侧 RSU 原型的一种载体。  
> **禁止**将本节表述为「必须 FPGA / 加速跑分」。

---

## 1. 与业务的关系

| 层级 | 是否绑 FPGA |
|------|-------------|
| 三态计费规则 | 否 |
| 残差完好性 | 否 |
| 数字孪生指标 | 否（PC） |
| 锁端量产 | **否（MCU）** |
| 研发板验证 | 可选（Zynq PS） |
| RSU 多车并行 | 远期可选（PL） |

---

## 2. 若使用 Zynq：本作品已验证路径

```text
测试集(fence_testset.h) → PS 批处理 WLS+残差+围栏 → UART EVAL
```

- 工程：`fpga/vivado_proj`，XSA：`fpga/fence_demo.xsa`  
- ELF：`fpga/vitis/app_component/build/app_component.elf`  
- 手册：`docs/BOARD_VALIDATION.md`

## 3. 若量产：MCU 主路径（概念）

```text
GNSS 模组 NMEA/二进制 → MCU 定位/完好性 → 围栏 → 锁控/计费标志
```

- 算力：1 Hz 伪距解算在 M4/A7 级别可实现简化版  
- 功耗与 BOM 远优于 Zynq  

## 4. 远期 RSU（不承诺本期实现）

- 多车观测并行残差/完好性  
- PL 流水相关/鉴相仅当有真实观测吞吐需求  
- 与本期创意交付无关
