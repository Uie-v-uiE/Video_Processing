# 第一部分：一句话讲清项目

**问题**：车停在停车点旁，高楼把北斗信号反射（多径），解算坐标“漂”出停车框，平台按违停扣调度费——用户被冤枉扣钱。

**方案**：扣费前先判断“这个位置可不可信”。不可信 → **不扣费**；可信再判是否在框内。

**证据**：同一套数字测试集下，城市多径场景误扣费率从约 **84% 降到 11%**；多径+欺骗从 **74% 降到 0%**。

**一句话**：先判信不信，再判罚不罚。

# 第四部分：技术原理（必学）

## 4.1 北斗/GNSS 是什么

- 卫星发信号，接收机算“到每颗星的距离”，交会出位置  
- 本项目先做**伪距**（码距离），不用载波 RTK（锁端成本高）

## 4.2 伪距定位（必须会画）

```
伪距 ρ_i ≈ |x_sat_i - x| + c·dt + 误差_i
```

- 未知数：x,y,z + 钟差 dt → 至少 4 颗星  
- 我们用 **WLS（加权最小二乘）** 迭代解  

白板公式：

```
H = [单位视线矢量, 1]
dz = 观测 - 预测几何距离
解 dx = (HᵀH)⁻¹ Hᵀ dz
```

## 4.3 残差与完好性（核心检测量）

```
残差 r_i = ρ_i - |x̂ - x_sat_i|  （去掉公共钟差后）
RMS = sqrt(mean(r_i²))
```

| RMS | 含义 | 计费 |
|-----|------|------|
| 小 | 观测自洽，可信 | 正常判围栏 |
| 中 | 可疑（多径/欺骗迹象） | HOLD |
| 大 / 可用星<4 | 拒止 | HOLD |

这就是 **RAIM 思想** 的简化版：用“观测之间是否一致”判断信不信。

## 4.4 三种干扰（本项目场景）

| 干扰 | 现象 | 业务后果 |
|------|------|----------|
| **多径** | 高楼反射，部分星偏差 | 坐标漂出框 → 误扣 |
| **慢拉欺骗** | 部分卫星偏置随时间变大 | 早期难察觉，持续偏航 |
| **拒止** | 大噪声/星不可用 | 定位不可用 |

## 4.5 数字孪生（本项目“实验方法”）

不是 3D 动画，而是：

```
可配置场景 → 可复现观测 → 可量化指标
```

- 不买天线、不跑外场  
- PC 上批量跑剧本，出图出表  
- 板子上可用**同一套测试集**注入验证  

## 4.6 关于 IMU（扩展知识，答辩可能被问）

| 概念 | 说明 |
|------|------|
| IMU 是什么 | 惯性测量单元：加速度计 + 陀螺仪 |
| 数据格式 | 通常是时间戳 + ax,ay,az + gx,gy,gz（m/s² 与 rad/s 或 °/s） |
| 和 GNSS 关系 | GNSS 低频、易受多径；IMU 高频、短时准、会发散 |
| 组合 | GNSS+IMU 松/紧耦合，GNSS 异常时 IMU 短时桥接 |
| 本项目 | **当前主链路是纯北斗伪距**；IMU 作为扩展答辩点：锁端可加低成本 IMU 做 HOLD 时短时推算 |

**答题**：评委问 IMU 就说「扩展融合方向，本期先证明纯北斗可信计费规则有效」。

## 4.7 项目文件夹为何叫 IMU

历史文件夹名，**本作品正式名是共享单车可信电子围栏**。报告与答辩用正式名，避免误导。

## 电梯稿

> 停车点旁多径会误判扣费。我们先输出「可信/不可信」，不可信就不扣费：多径误扣从约 84% 降到约 11%。再进一步，我们把"可信"量化成带虚警预算的保护级，用锁车静止先验把"不判"变成 3 秒延迟定案，判不动时降级到 3 个路侧锚点——误扣 0%、停摆 2.6%、期望业务代价降到 1/22。算法 MCU 就能上；Zynq 板已验证同源测试集可跑。有 FPGA 是加分，没有方案也成立。

# 第十一部分之二：增强层 PLTG（进阶讲法 / 被追问时使用）

## 11b.1 为什么要做（先自曝短板，再给方案）

| 事实 | 数字（10 个静止停车场景均值） |
|---|---|
| 三态门控把不可信一律 HOLD | HOLD **44.0%**，自动判决只剩 56% —— 业务停摆 |
| 阈值是经验值（4σ、80 m） | 多径 8 m 时 HOLD=0、照样出结论，此时**漏判违停 5%**；20 m 时**误扣 0.8%** |
| 结论 | "这组数据上不误扣" ≠ "不会误扣"；需要**带预算的可证明性** |

## 11b.2 三件套（每件套都有量化证据）

1. **χ² 完好性门 + 水平保护级**：`T=Σr²/σ₀²` 对 `χ²(1−P_fa, M−4)`，P_fa=10⁻²；`HPL=k·σ_h`，`k=√(−2 ln 10⁻³)=3.72`；判决裕度 `|d|−HPL`。
2. **零速窗口联合**：W 历元共用 1 个平面位置（竖直固定 0）+ 每历元 1 个钟差；钟差用历元内去均值解析消掉（Frisch–Waugh–Lovell 等价），未知数 2+W→2，单窗口 <1 ms 可上 MCU。→ HOLD 变"延迟定案"，实测 **3 s**。
3. **围栏对偶假设检验**：`δ=(SSE_out−SSE_in)/σ̂²`，`δ_th=χ²(0.999,2)=13.8`；δ≥+门限合规、δ≤−门限违停、否则 HOLD。→ 可回答"凭什么敢扣这一单"。
4. **分级降级**：GNSS 门失败 → 丢弃全部卫星观测，用 3 个路侧 BLE/UWB 锚点（σ=0.3 m，与卫星无关，3 个是为消除两圆镜像模糊）重解并继续对偶检验 → 仍不可判才进人工复核。

## 11b.3 必背数字

| 策略 | 误扣 | HOLD | 自动判决 | 代价 |
|---|---|---|---|---|
| 旧逻辑 | 13.31% | 0% | 100% | 4.84 |
| 三态门控 | 0.17% | 44.0% | 56.0% | 1.78 |
| 仅保护级（消融） | 0% | **96.5%** | 3.5% | 3.02 |
| PLTG(GNSS) | 0% | 75.4% | 24.6% | 2.35 |
| **PLTG+锚点** | **0%** | **2.6%** | **97.4%** | **0.08** |

- 代价模型：误扣 10 / 漏判 6 / HOLD 1 → P4 = 三态门控的 **1/22**、旧逻辑的 **1/60**
- 单场景：多径 8 m+慢拉欺骗 旧逻辑误扣 **53.7%**→0%；局部拒止 旧逻辑 **71.1%**→0%（且自动判决 97.5%）
- 消融：只用保护级 HOLD 96.5% → 证明"保护级+聚窗+对偶检验"缺一不可
- 敏感性：窗口 6→40 历元、HPL_max 2→8 m，HOLD 只在 0.752~0.760 之间 → **不是调出来的**
- χ² 门的价值：去掉它误扣仍 0，但最差定案时延 **3 s → 76 s**（坏数据把 δ 拉进模糊带反复抖）

## 11b.4 主动交代的边界（被追问时不要退）

- 多径 20 m 时 GNSS 单源 HPL 6.37 m > 围栏最小半宽 6 m：**判不动是物理事实**，不是算法缺陷；处置是降级或复核。
- 逐星独立、幅度小于噪声的智能欺骗**不承诺检出**（射频层：验相关峰/多频）。
- 卫星钟差参数 `sat_clock_sigma_m` 默认 5.0 保持既有场景与板端测试集**逐位不变（MD5 已校验）**；静止场景族取 0.5 m（接近广播钟差改正后的真实残差），否则任何 χ² 检验恒失败。
- 锚点需与围栏 ID 绑定 + 测距窗一致性校验，生产化需认证。

| HOLD 75% 不是更判不出来？ | 是"拒绝在没把握时下结论"；产品形态是 P4：锚点降级后 HOLD 2.6%、自动判决 97.4% |
| 既然要装锚点，为何不直接用信标定位？ | 只在高误判代价车位分级部署；普通车位靠 GNSS+零速聚合，成本可控 |
| 门限是不是调出来的？ | 全部由预算与几何给出；窗口 6→40、HPL 2→8 m 指标不动 |
| 锁车后被挪走算不算漏判？ | 零速门（漂移率>0.2 m/s）与 χ² 门双重拦截 → HOLD 复核，不误扣也不放过 |
| IMU？ | 扩展融合方向，本期先证明纯北斗规则 |
| 板上数字为何不同？ | 实现差异；金标准 PC |
