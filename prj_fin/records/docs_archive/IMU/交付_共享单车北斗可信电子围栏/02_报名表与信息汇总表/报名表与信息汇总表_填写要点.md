# 报名表 / 信息汇总表（待学校下发表样后填写）

通知口径：各校要求"以学院为单位报名"，并把 **报名表（附件2）+ 信息汇总表（附件3）+ 作品**
一并发至学院组委会办公室指定邮箱；表样随本校通知下发，本仓库不含官方表样，故此处只列填写要点。

## 填写前请核对

| 项 | 要求 | 备注 |
|---|---|---|
| 作品名称 | 面向共享单车的北斗可信电子围栏 | 与报告封面、PPT 首页一致 |
| 作品类别 | 科技创意类 | 不要写成"科技制作类" |
| 团队成员 | 1–4 名学生 | 顺序即组长优先 |
| 指导教师 | 1–2 名 | 与学校备案一致 |
| 学院签字盖章 | **必须** | 缺章通常不予受理 |
| 作品文件命名 | 常见格式：学院+作品类别+作品名称+组长姓名 | 以本院通知为准 |

## 随作品一并报送的材料（建议顺序）

1. `01_主交/作品方案报告.docx`
2. `01_主交/作品介绍PPT.pptx`
3. 报名表、信息汇总表（盖章扫描或原件交学院）
4. 如学院要求打包：`附件_证据图` + `附件_指标数据` + `附件_源代码`（可选 `附件_板端加分材料`）

## 尚未确认、需向学院核实的三件事

1. 本院**报送邮箱与截止时间**（各校不同）；
2. 《参赛作品格式规范》（附件1）的**具体排版参数**是否与本报告一致；
3. 创意类**每校/每院限项数**，是否需要校内答辩预选。
