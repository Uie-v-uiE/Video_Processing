- [ ] 摘要 400–600 字 + 关键词；Abstract + Key words 齐全

- [ ] 报告与 PPT 的数字与 `04_附件_指标数据/` 一致（工程内 `python src/check_project.py` 复核）
- [ ] 书面材料不含未做过的实测或未验证承诺（边界已写明）

## 7. 源代码包独立复现（`07_附件_源代码/`）

```powershell
# 依赖：Python 3.10+ 与 numpy（不需 scipy / 不需网络 / 不需 GNSS 硬件；C 对照需 gcc）
pip install -r src\sim\requirements.txt
python src\sim\run_fence_eval.py     # 基线：out/fence_metrics.csv + 证据图
python src\sim\run_pl_eval.py        # 增强层：五策略 / 消融 / 干扰扫描

python src\sim\crosscheck_c.py       # C 参考实现 ↔ Python 逐历元一致
```
包内目录结构与工程一致（`src/sim/`、`fpga/software/`），脚本自动定位根目录，解压到任意位置均可运行。
上述复现命令已在临时目录实测通过：`run_fence_eval.py` 输出 84.2%→10.5%，与主报告一致。
交付前自检 `src/check_project.py` 面向**完整工程**（需核对 docs/ 下的报告与 PPT），在最小源码包内运行会报缺项；其结果已随附 `04_附件_指标数据/交付前自检结果.txt`。
