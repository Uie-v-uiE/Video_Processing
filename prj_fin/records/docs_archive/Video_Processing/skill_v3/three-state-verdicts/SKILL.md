# 三态判定：把"没测到"从"通过"里分出来

## 适用场景

- 要新写一个检查器，或收紧一条已有判据。
- 症状：某条判据从项目开始就没红过；比较数为 0 却报通过；同一个脚本两次读出不同结论；
  豁免越加越多而没人说得清它挡住了什么。

## 使用方法

**先查**：被检对象的**真实形状**（哪一层有值、字段叫什么、单位是什么）——一手资料是那份件本身，
不是记忆里的表头。**先跟用户确认**：把判据从门禁摘出、降级为提示、扩充豁免、调阈值——
这些改的是"什么叫通过"，属于人来定的事。

### 语言（本包所有尺子共用）

| 词 | 含义 |
| --- | --- |
| `PASS` | 做了比较且比较成立 |
| `FAIL` | 做了比较且比较不成立 |
| `NOT_MEASURED` | 没做成比较：空集、读不到、解析失败、缺依赖、格式不含这个维度 |

- **每行一个判定，判定词是这一行的最后一个字段**（解析时取最后一格，别在整行里找子串）。
- **`判 N 项` 的 N = 做了多少次比较**，不是通过多少条；双侧都读不到也计入比较次数。
- **退出码**：`0` 全绿；`1` 有红；`2` 没红但有未测。红优先于未测，但未测数照样打印，不能被红盖掉。
  ⇒ "退出码 0"永远不是结论，结论是那三个条件同时成立：`判 N 项 红=0 未测=0`。
- **空集、解析失败、读不到一律 `NOT_MEASURED`**。把"没扫到"写成通过，是最贵的一类失效。

### 每条判据自带的三件东西

1. **比较数地板**：一条判据必须声明"这一层至少要完成 K 次比较"，K 可以调大来验证它会红。
   K 只能挡"0 次比较的通过"，挡不住"1 次无关比较"——判据强度要另用覆盖维度核。
2. **能红的对照**：每条判据登记"它最近因什么红过"（哪次注入、哪个已知缺陷）。
   登记不出来就标"未配对照"，并在门禁里**降级为提示、不参与放行结论**。
3. **逐层计数打印**：扫描范围用 `find` 现算成函数，打印每一层抓到的数量；
   某层为 0 而该层目录存在 ⇒ `NOT_MEASURED` 或直接拒绝。手写文件清单会随目录变深**静默变窄**。

### 计数单位要选对

**"数量"必须数在被保护的东西上**：数文件还是数条目，差别极大——
一份 607 行、带 31 个条目的失败分析，按"文件数"算只有 1 分；删掉 28 个条目，读数纹丝不动。
同理，判据强度用"做了多少次比较"，文档质量用"带读数的条目数"，覆盖率用"扫到的对象数"。

## 失效条件

- **判定词写成字面量**：`return 'PASS'` 而上面没有任何比较 ⇒ 这条判据是装饰，且永远不会红。
- **异常被 `try/except` 兜成成功**：缺依赖时全绿。要走 `NOT_MEASURED` 并打印原因。
- **豁免与统计用两种正则方言**（例如一个按扩展正则统计、一个按基本正则删除）：
  会打印"已豁免 840 条"而实际一条都没挡住 ⇒ 豁免与计数必须共用一个匹配器，并另打印"实际被挡住的对象数"。
- **判定词取自整行子串**：期望说明里出现的"应报 FAIL"被数成一条红。⇒ 只读判定列。
- **格式不可比当成红**：某个维度在该输入格式里根本不存在，判据却要求它 ⇒ 报的是尺子瞎，不是设计坏 ⇒
  要么按格式分支返回 `NOT_MEASURED`，要么明写"此输入上这一格不可比"。
- **收紧判据后只跑自测**：买通的只是测试。收紧后必须重跑真实件与一次已知有缺陷的件。

## 已验证效果

本包自带的两把尺子就是这条的可复跑形式：

```bash
node _meta/check-package.mjs . --self      # 25 项，含"正对照全绿"与"带声明就不该报"两条对照
node evals/route-eval.mjs . --self         # 4 项，含"期望写错该红"与"样本不够判未测"
```

实跑读数：前者 `判 25 项 不符=0 PASS`、后者 `判 4 项 不符=0 PASS`（这两个数字是本包自测的比较次数，
随条目增删而变——引用前要现跑，别抄这里的数）。

配套：`ruler-teeth-and-empty-sets`（这些假绿的具体形态与修法）、`anchor-bench-before-edit`（改前先红）。
