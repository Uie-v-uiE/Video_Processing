# 全域名册：不许只追最差那一条

用户的常驻规矩：**只看最差路径的改动等于没有改动**。本条把它变成可读数的形状。

## 适用场景

- 一次时序改动后，要回答"整体好了还是把债挪了个地方"。
- 报告只有一个 WNS，而设计有多个时钟域、setup 与 hold 两笔账。
- 重建之间读数会跳，需要知道噪声底。

## 使用方法

**先查**：本工具按时钟域出摘要的命令与开关（`report_timing_summary` 的域分段、`-nworst`/`-max_paths` 的真实语义）、
上一轮**同一把尺子**的位置与口径。**用 `help` 探针实测形状再写解析**（一次不开设计的批处理约 40 秒，比猜便宜）。
**先跟用户确认**："别的域不许变差"的阈值定在哪一档、哪个域可以让位（这是取舍，不是技术判断）。

名册的最小形状：一行一个时钟域，列 = `setup 相对余量`、`hold 相对余量`、`失败端点数`、`占用（LUT/BRAM/DSP）`，
外加与上一轮的**成对差分**。要点五条：

1. **用相对余量，不用绝对 slack**。8 ns 域上 0.7 ns 与 20 ns 域上 14.9 ns 不是一回事；
   按绝对值排刀口会排反（相对余量前者紧、后者松）。
2. **hold 与 setup 同表同尺度**。只报 setup 的名册等于半张表。
   hold 的余量符号与不确定度的口径要一致——不同域用了不同条带子的，**不可比**，要标出来。
3. **一次改动最多抬多少，先算再动**（见 `depth-vs-routing-cut`）：名册用来验收，不用来找方向。
4. **噪声底要先量**：同一份已布线检查点连跑两次，逐格差都应为 0；
   不为 0 的那个量就是这把尺子的噪声底，跨构建的小于它的移动**一律标"不可比"**，不许写进收益。
   实测里 placement 在同一工具同一种子上可逐位复现 ⇒ 跨构建的差更多来自约束/射程（见 `clock-change-constraint-reach`）。
5. **计数地板按"做了多少次比较"记**：`域数 × 判定列数` 是要打印的分母；
   某格双侧都读不到也要计入比较次数（记"做了多少次比较"，不是通过多少）。空集 ⇒ `NOT_MEASURED`。

## 失效条件

- **只列赢的那一格**：局部收益掩盖别处回退，下一轮在带暗伤的新基线上继续加刀。差分必须成对（赢的与跌的一起列）。
- **拿跨构建的绝对 WNS 差当收益**：换了种子、换了约束射程、换了报告口径都会动。
  对照只能在同一份检查点上做，否则结论只能写"新基线，无对比"。
- **按 `-nworst 12` 取"12 条最差"却以为是 12 个层级**：同一对起点终点在不同沿组合下会被重复报，
  12 行可能只有 1 层 ⇒ 从写出的文件里回读去重数并打印。
- **把最差路径的修法当整域的修法**：一个上限只对**这一把杠杆**成立，不对整个域成立。
- 名册的判据名（哪一列算赢）改了 ⇒ 与上一轮不可比；改动判据要同轮改所有引用它的句子。

## 已验证效果

形状已在真实工程里跑通（读数随设计变，本包不装工程专有值）：同一检查点连跑两次的逐格差为 0，
跨构建的两次则出现过"表观改善其实来自约束射程丢失"——那一次是靠名册的 hold 列与其他域同时列才暴露的。
可复跑的形式：任选一轮改动，输出名册差分表；判据 = "存在至少一格变差而未登记" ⇒ 红；
空表（域数 0）⇒ `NOT_MEASURED`，不许读成"全好"。

## 来源

长自两类观察：一处改动把最差两格拉起来同时把另一个域的 hold 打下去；以及"四个域 hold 都差不多"这类
句子在口径不一致时根本没法验证。配套：`depth-vs-routing-cut`（先算上限）、
`clock-change-constraint-reach`（改钟后的覆盖名册）、`three-state-verdicts`（计数与三态）。
