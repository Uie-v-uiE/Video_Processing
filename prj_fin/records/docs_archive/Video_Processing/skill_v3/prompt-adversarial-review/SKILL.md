# 提示词：让另一个会话只审计、不动手

审计的价值在于**它能推翻我**；一旦它开始修文件、给综合评分，价值就消失了。

## 适用场景

- 一份报告/一段改动/一版交付要第三方复核。
- 症状：审计结论没有指到具体件；它报的数复跑不出来；它"顺手改好了"而改动没人核过。

## 使用方法

**先查**：把要审的范围钉死（文件清单由遍历现算并打印数量，别手写名单——它会随目录变深静默变窄）。
**先跟用户确认**：是否允许审计者改文件（默认不许）；是否允许它跑会动硬件的命令（默认禁止）。

粘贴这段：

```text
角色：对抗性审稿人。只做三件事：找可驳之点、点名证据件、给出能复跑的判别式。禁止编辑任何文件。
逐条主张检查：
1 这句话指的是哪个件？给出相对路径。件不在盘上 ⇒ 判"失实"。
2 这个数字现在能复跑吗？写出命令与应看到的读数形态。复跑不出 ⇒ 判"借来的数"。
3 有没有一个实验能在 10 分钟内否掉它？写出实验设计。写不出 ⇒ 判"信念"。
4 表格：列与行的配对成立吗？逐行用第二个件独立核（数字全对而用途列整列错位是真实发生过的）。
输出格式：每行 `编号 | 主张（原文） | 判定 ∈ {成立, 存疑, 失实, 借来的数} | 依据 | 下一步实验`。
不许输出"整体合理/大体没问题"这类没有指到件的结论。
零改动 + 说明为什么不必改，也是合格交付。
```

**接住审计结果的规矩**：它说"这里没修好"时，先分类再动——把它的每条主张按上面四项归到某一类，
然后**只修那一类里数量最大的**。两个独立审计都指出同一处与交付文档矛盾 ⇒ 那是证据，
这时把**文档当嫌疑人**去核 RTL/报告，而不是替文档辩护。

## 失效条件

- **它顺手改了文件**：改动没走你的判据 ⇒ 回滚，重发"只报不改"的提示。
- **它的计数被你当读数引用**：agent 的计数与"这条分支没问题"都是**主张**，复跑或标"借来的数"。
- **它报的失实其实是匹配器瞎**：新尺子首跑的一大半"问题"常是它自己的正则 bug ⇒
  先分类假阳性，再动被检对象。
- **你只挑它同意的那部分**：那叫背书，不叫审计。
- 审计者给出"整体合理" ⇒ 退回，要求逐条指到件。

## 已验证效果

未量过，属建议：这套形状来自几次真实协作（一次两个独立审计同时指出与交付文档矛盾、结果文档确实错了；
多次"agent 的数复跑不出"）。可自查的形式：任选一次审计输出，检查"判定 ∈ 四类且每行有依据"的比例，
低于全部 ⇒ 该次审计不作数。

## 来源

长自四类观察：无件的综合好评、审计者越界改动、它的数字复跑不出、它报的失实是它自己的匹配器问题。
配套：`three-state-verdicts`、`ruler-teeth-and-empty-sets`、`delivery-package-integrity`。
