# 让尺子有牙：空集、射程与豁免的十七种假绿

**在nothing上通过的尺子比没有尺子更坏**：它给你一张绿表，于是没人再去查。下面每一条都是真实付过学费的形状。

## 适用场景

- 新写一个检查器、加一层合规门禁、或收紧一条已有判据。
- 症状：自测全绿而真实运行红；一条根因连带红一片；某条判据从项目开始就没红过、报告被自己的遍历扫进射程；
  报告被自己的遍历扫进射程；死链/违规计数在改了射程后跳变。

## 使用方法

**先查**：被检件的真实形状与提取层在哪（以一手文件为准，别按记忆写解析）。
**先跟用户确认**：把判据降级为提示、扩豁免、调阈值——都在改"什么叫通过"；以及是否允许为变异临时插桩（要能一键复原）。

### 十七种假绿（每条都要在新增判据时逐条过一遍）

1. 比较数为 0 却报通过 ⇒ 要比较数地板；地板只挡 0，不挡"1 次无关比较"。
2. 缺依赖/缺夹具被 `try` 兜成成功 ⇒ 走 `NOT_MEASURED` 并打印原因。
3. 夹具绕过了提取层：`--self` 全绿而真实件红。夹具要从真实件裁一段脱敏，逐字段对齐形状。
4. 变异靠改**期望值**而不是改被检数据 ⇒ 只证明比较在跑，不证明提取在跑。
5. 判据之间共享状态（前一条写临时件、后一条读）⇒ 单条绿、跑批红，归因彻底乱掉。
6. 检查器把自己的输出扫进射程 ⇒ 自指红或自指绿。输出落包外并显式排除，打印排除了哪些。
7. 收紧判据后只跑自测 ⇒ 必须重跑真实件与一次已知有缺陷件，确认新增的红都可解释。
8. 一条变异合理连带红 N 条 ⇒ 把连带写下来（"注入此处，X/Y/Z 同时红，因为它们共用提取层"），
   不要靠削弱判据换"归因干净"。
9. 永远不可能红的判据 ⇒ 登记"它最近因什么红过"，登不出来标"未配对照"并降为提示。
10. 豁免统计与实际删除用了两种正则方言 ⇒ 报"已豁免 840"而实际挡住 0 条。共用一个匹配器，
    并另打印"实际被挡住的对象数"，`命中>0 而挡住=0` 直接红。
11. **规则发出不等于规则生效**：重写层打印"改了多少条"，要回到**产出件**里再 grep 原始 token，
    残留应为 0；非 0 就逐条解释。
12. 计数单位数错对象：数文件看不见条目被删；数条目才看得见（见 `three-state-verdicts`）。
13. 按 glob 顺序"取最新"其实是文本序 ⇒ 交付包带上旧一轮的身份行。按内容过滤 + mtime 选，并打印候选。
14. `set -euo pipefail` 下 `N=$(find … | wc -l)`：目录不存在时 find 退出 1 经管道传进来，
    脚本在那一行死掉，后面的 `REFUSE` 文案根本没打印。⇒ 用 `{ find … || true; } | wc -l`，
    并且**必须拿一棵真的缺这个目录的树**去验那条分支。
15. `.gitignore` 无法在已被排除的目录里再包含某件 ⇒ 要排除目录内容而不是目录；用 `git check-ignore` 验配对声明。
16. 自测桩恒答"不存在"：存在性判据的变异用例就永远绿。桩必须有一个**真的返回存在路径**的正对照。
17. 判据的射程写成两段路径，真实引用是三段 ⇒ 一条都没判却照样打印"死引用=0"。
    匹配器要**按深度容错**写，并在改完射程后念出"抓到 N 条"；N 跳变是**尺子开始看见**，不是文档变坏。
    右边界同样是射程：分隔符前瞻不认反引号，中文文档里最常见的 `` `path` `` 就一条都不判。

### 三条结构性纪律

- **范围由遍历现算**，打印每层计数；某层为 0 而目录存在 ⇒ 拒绝。手写清单会静默变窄。
- **豁免词汇表只有一份**，由 owning 尺子的源码现读；读不到就**全部判红**（fail-closed），不许静默跳过。
- **每条豁免配一对能红/能绿对照**：名单外的照旧红；同形状在盘上的不许红。

## 失效条件

- 判据读的是自己的输出 ⇒ 上一轮的读数触发下一轮。
- 检查器依赖外部命令而环境里没有 ⇒ 全绿假象。
- 为了让归因干净而放宽判据 ⇒ 尺子在无人注意时退化。
- 用一条 grep 命中就下结论 ⇒ 先证明那条分支可达。
- 自己新写的尺子第一次输出的数：那是**关于尺子的主张**，先分类它的假阳性，再动被检对象
  （同一族里，首跑 75 条"没有这个件"有 49 条是它自己的正则 bug）。

## 已验证效果

本包的两把尺子就是这条的落地：`_meta/check-package.mjs --self` 25 项、`evals/route-eval.mjs --self` 4 项，
都含"正对照必须全绿"与"期望写错该红"两类对照（数字随条目增删而变，引用前现跑）。
其余十七条来自真实工程里逐个修掉的假绿，具体计数不随本包复用，故不在此引用。
