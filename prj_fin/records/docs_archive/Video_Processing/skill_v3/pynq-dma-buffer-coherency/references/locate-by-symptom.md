# 搬运侧的接口事实与按症状分诊

本表只收与"搬运 + 缓存一致性"这一条相关的行；Overlay 身份与寄存器层的出处见各自条目。
所有位置都是可点击的公开位置：源码给 `blob/<提交号>/<路径>#L<行>`，文档给站点与小节标题。

## 接口事实（逐条可复查）

| 断言 | 出处 |
| --- | --- |
| `Buffer` 默认可缓存；非缓存是显式选项 | 文档 "Uncached Buffers"；`pynq/buffer.py`（3.0.1 提交 `e45a0d1`，类定义 `#L21`，构造 `#L57`） |
| `Buffer.__init__` 在 3.0.0 改签名 ⇒ 2.7 的位置参数写法在 3.0 直接报错 | 同上 `#L57` |
| `allocate(size, flags, cached)` 第三参才是缓存标志；`qalloc()` 无此参数 | `pynq/xlnk.py` |
| `contiguous` 默认 0 | `pynq/buffer.py` |
| 全量搬运：地址与长度按 8 字节对齐；流式：写指针 8、字节数 16；非缓存缓冲强制行对齐 | `pynq/lib/axidmadma.c` |
| 违反上述对齐且要求非缓存 ⇒ 直接报"长度或地址未对齐的缓冲不能设为非缓存"（不是静默损坏） | 同上 |
| Python 侧收发**不强制**对齐 ⇒ 违反时不报错、坏在数据上 | `pynq/_xlnk.c` 的通道设置入口 |
| 下发只写描述符、不等待；等待超时**返回假值而非抛异常** | `pynq/xlnk.py`；`pynq/_xlnk.c` 的等待实现 |
| `TCircularity` / `Alignment` 异常只在旧栈的 `pynq-dmadma`（2.7.x）存在 | 提交 `a736927` `pynq/dmadma.py`；PyPI 页 pynq-dmadma |
| Zynq 非一致 DMA：`dma_alloc_coherent` 不保证一致 ⇒ 读到旧数据/残影 | 官方 AR 记录 752564（FAQ 内交叉引用） |
| 缓存维护方向不对称：写出走清理、读入走失效；失效会丢弃未写回数据 | 通用 ARM 缓存维护语义 + FAQ "no exception but wrong data" |
| `xlnk.stat()` 只读；配额段固定 16×64 MB；保留区一般 1 GB | `pynq/xlnk.py`；文档 `reference/sdma.rst` |
| 流式帧尾缺结束标记 ⇒ 接收端不出末拍 ⇒ 读帧永不返回 | FAQ "End of Frame" |
| 按行宽算字节数；stride 非 4 倍数报 `LineStrideError`；输出侧对齐"不保证"（官方原话） | 文档 Display / VDMA；`pynq/lib/vvideo.c` |
| `InValueError`/`OutValueError` 只在旧栈 `pynq-video` 1.x；新栈没有 | 提交 `170d616` 对比 `e45a0d1` |
| 下发前改过 `mmap` 内存"可能不生效"（官方提示，非实现细节） | FAQ "Downloading a Buffer" |

## 按症状分诊

| 症状 | 先查 | 再查 |
| --- | --- | --- |
| 数据整体错位、跨行错开 | 对齐与起址取整 | 字节序（引擎与处理器谁大端） |
| 上一帧残影、局部旧值 | 失效做了吗、范围覆盖全了吗 | 读的路径是否命中缓存 |
| 只有长度非对齐倍数时坏 | 尾部处理 | 取整越界撞到邻居 |
| 随机少一小块 | 失效与本地写并发（归属规则被违反） | 两条通路是否都在写同一块 |
| 偶发、与负载相关 | 带宽竞争（转 `external-memory-bandwidth-account`） | 完成判定是否退化成延时 |
| 搬运不报错也不异常，数据是旧的 | 缓存一致性（非一致端口） | 是否用了缓存分配却指望硬件直读 |
| 读帧永不返回 | 末帧有没有结束标记 | 期望长度与实际字节数 |
| 换个缓冲大小就好/就坏 | 内存布局与对齐 | 一致端口与非一致端口混用 |
| 照文档写的异常捕不到 | 该异常类在本版本是否存在（先 `import` 探一次） | 栈版本与文档版本是否同一代 |
