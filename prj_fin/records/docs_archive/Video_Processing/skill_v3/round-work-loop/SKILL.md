# 一轮工作的节拍（九步，每步都有产出物）

**一轮 = 一个提交 = 一个可被推翻的假设**。缺哪一步，下一轮就在哪里断链。

## 适用场景

- 改 RTL、改约束、改流程脚本、改上位机侧代码，只要"要被证明而不是看着对"。
- 症状：说不清这一轮相对上一轮赢在哪；报告只在看时存在；下一轮第一件事是"上一轮那个读数在哪"。
- 不适用：纯查资料的轮次（那种只记"查了什么、出处在哪"，可省尺子不可省判据）。

## 使用方法

**先查**（一手资料优先：厂商用户指南/数据手册/接口规范 ＞ 应用笔记 ＞ 教程 ＞ 模型记忆）：
本工程的构建命令与报告落点、上一轮同一把尺子的位置与口径、目标平台的资源与时序边界。
**先跟用户确认**：本轮边界（"只做这一件事"是否被认可）、会动到外观或演示顺序的部分、任何不可逆动作。

| 步 | 产出物 | 缺了它下一轮怎么断链 |
| --- | --- | --- |
| 1 立案 | 一句话现象 + 1–3 个可驳假设 + 判据（看到什么算赢） | 结论既不能被推翻也不能被继承 |
| 2 配尺子 | 判据 + 在**未改**树上跑出的"改前红"落盘 | 分不清"DUT 变了"与"期望本来是我猜的" |
| 3 单变量 | 一处能用一句话解释的 diff | 差分归因失效，赢的那格不知是谁的功劳 |
| 4 构建 | 构建日志 + 产物与版本号；**在飞禁改同一批源** | 后面所有量都在读旧树 |
| 5 量 | 报告落盘为**可复跑文本件**（带命令、工具版本、时间戳） | 下一轮拿不到同口径输入 |
| 6 差分 | 与上一轮同一把尺子的**成对**表（赢的格与可能跌的格一起列） | 局部收益掩盖别处回退 |
| 7 落件 | 件与被引结论进**同一次提交**，结论点名件路径 | 交付包"点名的件不在盘上" |
| 8 改口 | 所有引用旧数字处一次改完 + 数字对账（旧值全文命中数应为 0） | 两处文档各说一个真相 |
| 9 提交 | 一次提交＝一轮；判定用三态，`判 N 项` 记比较次数 | 结论无法被复核 |

**一轮记录最小字段**（照抄即可，多一栏都不要）：标题 / 判据（命令＋应看到什么＋改前红）/
件路径 / 结论（三态＋成对差分两格）/ 欠账（本轮没做完、下一轮必须接走的）。

## 失效条件

- **同轮多刀破坏了单变量**：要么逐刀各配判据、各取改前红，要么整轮降级为"动过，归因不明"，
  不许写"因为 X 所以赢了"。征兆＝diff 横跨两个模块而判据只有一条。
  例外要显式：长跑构建的窗口里，**已经各自带凭据**的多刀可以合并（把代价与理由写进日志，别假装很干净）。
- **改了没量**：提交里有源改动、没有新落盘的件，或件时间戳早于 diff。征兆＝结论句用"应该/预计"。
- **量了没落件**：读数只在终端活过一轮。征兆＝复跑命令写不出来。
- **落件没改口**：件是新版、文档还挂旧数字；对账搜索命中旧值。
- **0 字节日志当"还在跑"**：判活看进程在册、日志增长、产物 mtime 三样，都读不到 ⇒ `NOT_MEASURED`。
- **尺子换了**：改了期望/容差/口径 ⇒ 只能写"新基线，无对比"。

## 已验证效果

未量过，属建议：本条按通用节拍整理，没做过"带这条 vs 不带这条"的干净 A/B（增益的测法见 `evals/gain-ab.md`）。
自查三个读数：本轮"改前红"件数（应为 1 或每刀 1）、旧值对账命中数（应为 0）、
结论来自落盘文本件的比例（应为全部）。三个齐了才算这条在被执行。

## 来源

长自"长夜里三类断链"（在飞改源、量了不落件、改口没改完）与一次"同轮三刀但各带凭据"的取舍记录。
配套：`anchor-bench-before-edit`、`artifact-provenance-binding`、`global-timing-roster`。
