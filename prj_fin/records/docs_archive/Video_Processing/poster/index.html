01

Who asks for this

Camera bring-up on a line

Industrial cameras push raw frames. The usual fault is a dropped packet eating part of the image, and the field only saw "it froze". Here the drop and corruption counters live in the fabric, read at the same instant as the picture.

Tuning an image pipeline

Comparing before/after on one frame usually costs a laptop, a capture card and a second screen — and the PC preview is not the RTL. Here it is one seam and one control word.

Teaching and lab work

83 benches, one command, one bitstream with an identity: the whole design can be re-run and refuted by somebody else, not only believed.

02

Where a pixel travels

Ingress

RGMII → GMII in the PL. IDDR + IDELAY, frame reassembly, port filter; ARP and ICMP answered in RTL.

Storage

DDR ping-pong. Three banks, BRAM row rings, a single-owner arbiter across ETH / SD / test card.

Geometry

Zoom · rotate · bilinear. Eight fixed-point ratios 0.25–2.00× plus auto-fit; 0–359° stays inside the panel.

Effects

Six stages, nine switches. One 9-bit control word, fixed 15-cycle latency for any combination.

Display

A/B seam → OSD → TMDS. 1024×600 @ 59.5 Hz off a 50 MHz pixel clock, ×2 serialised.

03

Why the picture can be trusted

Invariant

One coordinate operator

zfit solves the fit factor in 3 DSP48 blocks; zmap maps every pixel through 8, rotation running inverse-mapped with two linear interpolations. Eight ratios plus auto-fit, so a rotated frame always stays inside the panel — checked by a two-sided bench, not by an eye.

Invariant

Latency is a constant

Six stages, each window stage keeping its own column tag, so the chain is 15 cycles and −4 rows for every combination. The fabric exposes one number, u_pipe.LATENCY; the read scheduler never re-derives it. Across the frame boundary the read-side wrap is keyed to the ring’s write beat, so the previous frame’s pixels are fixed, not stale.

Discipline

Every claim can go red

A criterion with no way to fail is not evidence. 83 benches carry a mutation control — flip one bit, delete one line, the bench must go red — and a 24-item gate runs before release. A zero-hit scan is reported as a blind ruler, never as a pass.
