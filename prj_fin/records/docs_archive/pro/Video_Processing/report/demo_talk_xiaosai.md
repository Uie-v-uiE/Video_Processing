# 校赛演示话术（台词 + 动作 + 屏上判据）

> 用法：**加引号的是念出来的话**，`代码`是敲进串口的命令，"看"那一行是**必须亲眼看到才继续下一步**的东西。
> 全程一次串口终端 + 一次推流窗口，不换工具。
> 命令语法的正本在 `demo_script.md`；原来单独一页的 3 分钟综合演示稿（含它的 2 分钟砍法）已并入这一份。
> 这一份是**校赛桌上用的**：
> 假设评委不会完整听完，所以每一幕都能被单独打断、单独收住。追问的答案在 `judge_qa_xiaosai.md`（下文简称"问答"）。
> 时间预算：**开场 20 s + 五幕 30/35/35/35/25 s = 3 分 20 秒**；被压到 2 分钟就砍第 4、第 5 幕（见文末）；只有 90 秒就演第 1、3、4 幕。

## 0. 上台前 90 秒（不在台上做的事）

| 检查 | 判据（看到什么算过） | 不满足怎么办 |
|---|---|---|
| 板卡拨码在 QSPI 档 | 断电重上电，屏自己出画面、`DONE` 亮 | 改走 JTAG 加载，第 0 幕的"不接电脑"这句立刻删掉 |
| SD 卡里有裸帧序列 | 敲 `sd` 回摘要；串口敲 `stat`，回行里 `playing=1` | 提前跑 `make_sd_video.mjs`，**不要现场做** |
| 串口终端已连 | 敲 `stat` 出 `[STAT] …` 一行 | 同一个 COM 口只容一个写入者，先关掉别的终端 |
| 推流窗口就绪（先不敲回车） | `node src/host/video_sender.mjs --fps 15 --test bars` | 网口那一幕改成只讲不演 |
| 起点状态已抄在纸上 | 抄下这一整行 `stat`，第 5 幕要逐字段对账 | 漏抄就只能说"回到这一行"，证不到"可逆" |
| 屏顶那一小条 | `rot speed 1` + `rot auto 1` 转起来看屏顶：散开只在**逐帧换角**时出现，`rot speed 0` 停住就该没有 | 若停住还在，第 3 幕别提"顶行"，并按 §4 禁语第 5 条的口径讲 |

## 第 0 幕 · 开场（0:00–0:20）

**说**：
> "作品叫《多源视频流多效果变换处理系统》。芯石块是 Zynq-7020，一半是 ARM 一半是可编程逻辑。
> 我现在**不接电脑、不下位流**——断电、上电，它自己就起来了，位流和固件都在板载 flash 里。
> 今天不报功能清单，报三条从头到尾没换过的规矩：**一条通路**——从网线到屏不经处理器，三路片源共用同一套
> 乒乓缓存、共用同一次显示提交；**一套坐标**——旋转、八档缩放、双线性插值用的是同一个逆映射算子；
> **一条恒延迟链**——九个开关怎么叠，链子的延迟都是 15 拍。名字里那两个词就是这三条撑起来的，
> 待会儿每条我当场做给你们看一次。"

**做**：手指屏；说"上电"时按下电源开关。
**看**：屏上出画面 + 左上角五行 OSD 字。
**兜底**：5 秒内没画面就一句"这一格今天不演，我走 JTAG"，**不要在台上查线**。

## 第 1 幕 · 网口进、屏上出，链路坏了它自己换（0:20–0:50）

**说**：
> "片源三路：网线推来的 UDP 视频流、SD 卡上的帧序列、芯片里自己画的测试图卡。
> 关键是**以太网协议栈整个做在可编程逻辑里**——RGMII 收发、MAC、IPv4/UDP、ARP、ICMP 全是硬件，
> **网线这一路的像素 ARM 一次都不碰**（SD 那一路是 PS 把文件读进 DDR、再由 PL 搬上屏，这两件事我不混着讲）。
> 所以推流的时候我还能 ping 通它。现在接上网这一路。"

**做**：敲推流命令 → 指屏。
**看**：`SRC:` 变成 `ETH`（后面**没有星号**）。
**说**：
> "没有星号说明是它自己让位的，星号是我手动锁住的意思。"

**做**：**拔网线**。
**看**：半秒内画面回到 SD，屏上字样跟着改口。
**说**（插回去之前）：
> "它没冻住——是自己判断'这一路静默了'然后换源。插回去又自己切回来，全程不复位。"

**回指**：这幕证的是**一条通路**与它的推论——换源、恢复都只落在消隐窗里那一次原子拷贝，所以屏上看不见半帧。
被追问"这套协议栈是不是全自己写的"就照实答：这一层与 RGMII 收发的初版来自板卡厂商的 `eth_udp` 例程，
本工程改写了五处（组帧判据、端口过滤、把 PL 改成 AXI 主设备直写 DDR、健康计数、采样窗），出处句在交付文档里写着。

## 第 2 幕 · 缩放与旋转：装得下是算出来的（0:50–1:25）

**说**：
> "源是 512×300，屏是 1024×600。缩放和旋转用的是同一套逆映射，倍率八档、角度一度一格。"

**做**（依次）：`zoom 1.0` → `zoom 1.5` → `zoom 2` → `rot speed 1` → `rot auto 1`
**看**：画面逐档变大、边缘不糊；开始转之后屏上 `Zoom:` 那一格**同时**变成带 `(Fit)` 的字样。
**说**（指着 `(Fit)`）：
> "这一格是板子自己报的：旋转时倍率交给角度算，'这个角度刚好装得下'是多大就缩到多大，
> 整幅永远在屏内，不会出现角点转出去。这不是我说的，是硬件那一帧真的在用的数——它能机读回来。"

**做**：`rot auto 0` → `zoom fit 0` → `zoom 1.0`（收回干净状态）。
**注意**：转着的时候**别说**"放大到 2 倍"——旋转态会把手动档拉回 fit，这是设计取舍，被追问再解释（见问答 Q9）。

## 第 3 幕 · 招牌：同一帧、左右两半（1:25–2:00）

**说**：
> "接下来是这个作品的核心。九位控制字，一位一个算法，任意组合。我一条命令让它做边缘检测。"

**做**：`pipe 000010000` → `split 50` → `split marker 0` → `th 60` → `pipe 000001010`
**看**：屏中间出现一条缝，**左半边原图、右半边处理后的图**；`th 60` 一改，右半黑白面积立刻变。
**说**（放慢，这是全场最该被记住的 20 秒）：
> "请注意这两半是**同一帧、同一时刻**的画面——不是两台设备、不是录屏回放、没接采集卡。
> 缝的位置是一个运行时参数，可以扫，也可以钉在画面内容上跟着一起转。
> 所以'这个算法到底改了什么'，在桌上一眼能判。
> 反过来它也当尺子用：错位、少列、越界填黑这类几何错误，会在缝两侧**当场露出来**。"

**做**：`split 20` → `split 80`（缝扫一遍）。
**念法一**：`split 30` 之后屏上那一格写的是 **29%**——屏上的百分数由存进去的值反算，100% 会被夹到 1023
并且在回显里当场说出来。所以这句念"缝能扫遍整幅"，不念"打多少就显示多少"。
**念法二**：`pipe` 那串九位是**八个算法位 + 一个判决反相位**，第九位只把黑白反过来、不是第九种算法。
名字里"多效果变换"数得齐，靠的就是当场补这一句。
**回指**：这幕证的是**一条恒延迟链**——延迟与哪个开关开着无关，缝才能钉在任意一列而两侧不错位；
反过来缝还当尺子用，这一点是交付文档"创新点"第一条的原话。

## 第 4 幕 · 板子自己数自己的账（2:00–2:35）

**说**：
> "第三个特点是链路自己会报数。"

**做**：`gamma 1.8` → `temp` → `stat`
**看**：`gamma 1.8` 之后**只有右半**中间调被压暗（左边是原图，对照当场成立）；`temp` 一行里同时给驱动读数、屏上那三个字符、写进芯片的 GPIO 值；`stat` 把当前所有状态念一遍。
**说**：
> "这一行里的数，屏上看见一份、串口看见一份、调试口用 JTAG 读也是同一份，因为读的是同一组寄存器。
> 丢帧、坏帧、帧间隔这些计数是芯片里的逻辑自己数的，不是我口述的。
> 长跑数据在报告里：512×300、三十帧每秒，九千帧、三百秒，丢帧、坏帧、重复帧都是零。"

**禁**：不要念屏上左上角那个 `FPS:59`——那一格数的是**屏幕刷新**，不是片源帧率。
**口径**：这一路读数分三条独立来源，别把它们说成互相验证——屏上是芯片自己数的、`temp` 那行是 PS 侧 XADC、
`build/power.rpt` 的功耗与结温是**工具估算**（置信度低）。台架数量一律念**随包那一版的 83 支**；
提交之后又多了一支（修细线那一条），被追问就照实说，不主动改口。
**回指**：这幕证的是**一条通路**的可观测面——控制面只有两只 GPIO 加一条串口，所以"屏上看见一份、
串口看见一份、JTAG 读回来还是那一份"是同一组寄存器的三个出口，不是三份数。

## 台上不许说的七句话

1. 不提"AI / 识别 / 深度学习"——这套系统里一个都没有。
2. 不说"能设成某个绝对角度"——角度只有板上按键每次 ±1°，没有绝对值写入口（串口也没有）。
3. 不把屏上 `FPS:` 当片源帧率念。
4. 不说"入流能到 116.7 帧"——那是**下界**：不限速跑了 960 帧不丢字，过载点没顶到，所以只能说"至少"。
5. 关于屏顶：**不要再说"顶部那条带是上一帧的像素"**。上一帧的**像素**这一族已经修掉并被判据钉住
   （`tb_edge_rim` 的 D3：四个窗口级全绿，60/60 列稳定 + 末行对照 60/60 会交替）；
   现在唯一声明保留的红是**自动旋转逐帧换角时，帧头那 6 行吃的是上一帧的角度**（差 1–2 个源行，
   只有角在顶部、且角度每帧在变的时候看得见，停住角度就没有）。
   评委没问就别主动展开；问了照问答文档 **Q16** 答（含"为什么不顺手修掉"和位移量读数）。
6. 不说"**三路片源都不经 CPU**搬像素"——不经处理器那一条只管网口这一路。SD 那一路的像素确实由 PS
   从文件系统读进 DDR，再由 PL 搬上屏（发布脉冲见 `src/ps/sd_play.c` 头部那段协议说明）。
7. 不说"实测撕裂率 0"，也不把 `drop_words → 0` 念成"推流时零丢字"——同帧完整那句是**结构论证 + 一次眼睛
   判据**；而留档那次板级复验里 `lane30` 的 `eth_live` 是 0，也就是那次读回发生在**没有流**的状态下。
   要念"推流中不丢字"，得重跑一次把 json 落进 `build/evidence/` 才算。
