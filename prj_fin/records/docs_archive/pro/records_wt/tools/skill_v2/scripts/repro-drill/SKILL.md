# 复现演练：文档点名的件是否真在盘上（只读）

## 适用场景

- 文档写"跑 tools/xxx.mjs"，但那件不在包里也不在盘上，对方第一步就卡死。
- 批量改口（重命名、挪目录）之后，文档里的相对路径悄悄漂成死引用。
- 交接前想确认"照着这份文档能走通"，但又不允许真跑任何命令（命令有副作用）。
- 表格行、清单里的路径被别的工具当成"待改写对象"动过手，需要有人证明没被动过。

## 使用方法

```bash
node scripts/drill.mjs --dir <文档根目录>            # 只读扫描
node scripts/drill.mjs --dir <文档根目录> --quiet     # 不逐条列"在盘"
node scripts/drill.mjs --self                        # 跑随包夹具与对照
```

跑完应看到（对夹具 `fixtures/docs` 的实测读数，退出码 1，因为夹具故意含 1 条死引用）：

```
死引用 runbook.md:4 tools/flash_host.mjs（盘上找不到）FAIL
豁免 runbook.md:5 tools/bit_gen.mjs（同行声明词：不随包/自备）NOT_MEASURED
在盘 runbook.md:10 notes/setup.md（按文件位置）
命令抽取 runbook.md:15 bash notes/run.sh —— 未执行
扫描文件数=2 抓到引用数=10 豁免命中数=4 死引用数=1
命令抽取数=3（只抽取、不执行 ⇒ 命令能否跑属于未测）
判 8 项 红=1 未测=7 FAIL
```

判定与退出码：**死引用 > 0 ⇒ exit 1**；**扫到 0 个 Markdown ⇒ NOT_MEASURED 且 exit 1**（没扫到不等于没有）；
只剩豁免项与抽取项 ⇒ exit 2（声明不等于证明）；全在盘且无豁免 ⇒ exit 0。红永远优先。

口径（写死在脚本里，别靠猜）：

- **射程由遍历现算**：`--dir` 之下递归到的 `.md/.markdown/.mdown`，没有手写文件清单；`node_modules` 与点开头目录跳过。
- **引用形状**：形如 `dir/xxx.yyy`（至少一段目录 + 扩展名）。解析先按"该 md 文件所在目录"，再按扫描根。URL、版本号、纯中文不吃。
- **豁免**：同行出现声明词 `不随包 / 未随包 / 本地留档 / 未写 / 规划 / 示例 / 自备 / 未提交` ⇒ 不判死，但计入"未测"。
- **代码块里的命令行只抽取、只报数，绝不执行**；`--fix / --rewrite / --delete / --write / --in-place` 一律拒绝——本工具对被检查的树**只读**。

**先查什么**：先拿到"哪些件本该随包"的一手依据（交付清单、打包脚本的入包规则、目录骨架约定），拿它当裁判；
不要拿文档里的一句话当裁判，那正是漂移的来源。
**先跟用户确认**：`--dir` 指到哪一层（指错就 0 文件）、声明词口径（哪些允许不在盘上）、
死引用是补件还是改文档（本工具不代你做这个选择，也不替你写盘）。

## 失效条件

- **抽取不等于验证**：命令被抽出来、报了数，不代表它能跑——参数、前置条件、所在目录、权限一个都没验。
  命令是否真能跑要单独演练（在隔离副本上、按上板纪律逐步确认），别把"命令抽取数=N"读成"N 条命令可用"。
- 只认"带目录的相对路径"：裸文件名、变量拼出来的路径、`~` 开头、图片与锚点链接都不在射程 ⇒ 会漏报死引用。
  征兆：某个你明知缺失的件没被点名。
- 声明词按**整行**匹配：一行里既有真引用又恰好有"示例"字样，就整行被豁免（假阴性）。
  征兆：豁免命中数明显高于预期 ⇒ 逐条翻 `豁免` 行确认声明是否成立。
- "在盘"只证明文件存在，不证明内容对、版本对、能跑。
- 扫描根写歪（指到只有一层 README 的目录）⇒ 0 文件 ⇒ 报未测而不是绿，这是有意的；别把它当"包很干净"。
- 统计数随遍历结果浮动：新增/挪动 md 会改变 `扫描文件数`，跨次比较必须用同一个根。

## 已验证效果

`node scripts/drill.mjs --self` 实跑读数（退出码 0）：

```
S1 死引用必须抓到并点名（夹具含 1 条） 退出码=1 死引用数=1 点名=tools/flash_host.mjs PASS
S2 同行声明词豁免（不随包/未写/规划） 豁免命中数=4/4 全部命中=是 引用总数=10 PASS
S3 表格行按引用统计（不改写、不当路径重排） 表格/正文引用被判在盘=是 夹具文件改动=0 PASS
S4 写盘请求被拒绝（本工具只做只读检查） 退出码=1 说明=含"只读" PASS
S5 射程为空 ⇒ NOT_MEASURED 且退出码 1 空目录退出码=1 缺目录退出码=1 结论=未测 PASS
S6 代码块命令只抽取、只报数、不执行 抽取数=3/3 逐条标注未执行=3/3 判定不受影响=是 PASS
S7 射程由遍历现算（临时塞 4 个嵌套 md 必须全进射程） 退出码=0 扫描文件数=4 PASS
S8 全程只读（跑完 7 项后夹具字节不变） 比对文件=2 改动=0 PASS
判 20 项 红=0 未测=0 PASS
```

夹具形状：`fixtures/docs/runbook.md`（1 条死引用、3 条同行声明豁免、1 个表格行、1 个代码块）+
`fixtures/docs/notes/setup.md`（1 条声明豁免、按扫描根解析的在盘引用）+ `fixtures/docs/notes/run.sh`
（被文档点名的真实件）+ `fixtures/docs/empty/`（空目录 ⇒ 未测对照）。
未量过：在真实交付包上"演练一遍省下多少现场卡住"没量过，属建议。
