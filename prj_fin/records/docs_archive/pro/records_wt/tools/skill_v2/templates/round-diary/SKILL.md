# 一轮记录的模板（可交接的最小事实集）

## 适用场景

任何"要被证明而不是看着对"的一轮的收尾动作：改设计源、改约束、改构建流程、改上位机侧、
调外观参数都算。症状级触发：

- 隔了一天回去看自己的结论，已经想不起当时的判据是什么。
- 同一指标在两个文件里各有一个数，差一点点。
- 有人问"这一轮赢在哪"，答案是一句话而不是一个表。
- 交接给别人时，对方第一句是"这个读数是在什么状态下量的"。

不适用：纯查资料的一轮（只记出处与结论边界，可省尺子与差分表，不可省欠账）；
同轮多刀且没法逐刀拆开的（那种先按"归因不明"降级记录，别硬套模板）。

## 使用方法

**动手前先查**：上一轮**同一把尺子**的位置与口径（期望、容差、提取方式）、上一轮件的路径与读数、
本轮目标域的边界条件（哪类改动会牵动别处）。**先跟用户确认**：本轮的边界是否就是"只做这一件事"、
会不会动到外观或演示顺序（这两类由人判，见 `acceptance-and-eye-check`）、有没有不可逆动作。

步骤（每步的产出物都要落进 `templates/round.md` 对应栏）：

1. **开一页**：复制 `templates/round.md`，命名跟随本轮凭据件的轮次标识，与件同目录或文档区。
2. **立案**：现象写观察到的，不写成结论；假设 1–3 个且每个都可被本轮推翻——写不出"什么读数会推翻它"
   的假设不算假设。
3. **先配能红的尺子**：在**未改**的树上跑出"改前红"并把读数抄进判据栏。跑不出红就先别改
   （两次"改前红"其实是我猜错了期望，被测对象是无辜的）。
4. **单变量改动**：改动栏只写一处、且一句话能解释。多刀要么拆轮，要么逐刀各自有改前红与判据。
5. **构建与版本**：命令 + 产物标识（版本/哈希）+ 工具版本；构建在飞时禁改同一批源。
6. **量与差分**：读数落点写相对位置；成对差分表必须两格并列——本域收益 + 别处代价
   （占用、别的路径余量、别处的覆盖面）。**只列赢面视为没做差分。**
7. **三态结论**：`PASS / FAIL / NOT_MEASURED`，判定词是结论行最后一个字段；空集、读不到、
   解析失败都归 `NOT_MEASURED`，不许当绿。
8. **欠账 + 需要人确认的事**：各至少一行；确无欠账就写"无（本轮范围为…）"，不要留空格。
9. **提交**：一次提交 = 一轮，记录、件、改动同处；提交信息带判据与读数。

栏位与断链对照（这就是每一栏为什么不能省）：

| 缺的栏 | 下一轮怎么断链 |
|---|---|
| 标题 | 这一轮检索不到、索引不上，交接时别人只能按时间猜是哪一轮 |
| 现象/假设 | 结论无法被推翻也无法被继承，下一轮不知上一轮在赌什么 |
| 判据（含改前红） | 改后无论报告长什么样，都分不清"对象变了"与"期望本来猜错" |
| 单变量改动 | 差分归因失效，赢的那格不知道是谁的功劳 |
| 构建与版本 | 无法确认读数属于这一份源，后面所有量可能在读旧树 |
| 读数落点 | 读数只在终端里活过一轮，下一轮第一件事是重跑或凭记忆 |
| 成对差分表 | 局部收益掩盖别处回退，下一轮在带暗伤的基线上继续加刀 |
| 三态结论 | "应该/预计"混进交付文档，复核只能整体判 `NOT_MEASURED` |
| 欠账 | 欠的活没人认领，到交付时以"未做"的形式暴露 |
| 需要人确认 | 自作主张改外观/口径/演示顺序被打回，整轮白做 |

## 失效条件

- **单变量前提被破坏**：diff 里同时出现两个模块或两类改动而判据只有一条 ⇒ 整轮降级为
  "动过，归因不明"，不许写"因为 X 所以赢了"。
- **尺子被换了**：改了期望/容差/提取口径 ⇒ 与上一轮不可比，结论只能写"新基线，无对比"，
  并把旧口径那一份读数一起留着（否则将来对不上账）。
- **件晚于改动、或件的时间戳早于 diff**：说明读数是旧的。征兆：结论句用"应该/按道理"而不是抄读数。
- **把观感写成本轮结论**：外观/流畅度是人判项，机器读数不能替代；只能记"人已判，见验收记录"。
- **长批次里的 0 字节日志**：日志存在且为 0 字节通常意味着刚起或已成孤儿，不是进度证据。
  判活看进程在册、日志是否增长、产物 mtime 是否推进；三者都读不到 ⇒ `NOT_MEASURED`，
  不许猜成"还在跑"然后继续下一刀。
- **模板被写成叙事**：一栏里塞三段故事 ⇒ 下一轮无法比对。表格填不满就删栏，不要改成散文。

## 已验证效果

未量过，属建议：本模板按通用节拍整理，没做过带/不带的干净 A/B。可自查的 3 个读数都是可复跑的形式，
数值本身只在同一设计里成立、随设计变，**不可当普适结论**：

1. 每轮"改前红"件数：应为 1（多刀则每刀 1）——按轮次标识过滤凭据件目录即得。
2. 一轮记录里 11 栏（模板的第 0 到第 10 栏）的空格数：应为 0（欠账可为"无"，但不能为空）。
3. 成对差分表列数：收益列与代价列都在的轮次占比，目标全部；只有赢面的轮次数应为 0。
