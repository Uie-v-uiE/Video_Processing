## 作品简介（≤500，推荐 · 497 字）

```
本作品在 Zynq-7020 上实现从网线到屏幕的全硬件视频流水线。上位机以 UDP 推送 512×300 RGB565 画面，PL 侧完全自研 RGMII/ARP/ICMP/UDP 协议栈与 offset 拼帧逻辑（不依赖 lwIP/PYNQ，PS 不参与数据面），经手写格雷码跨钟 FIFO 与流水化 AXI 写通道写入 DDR 乒乓 bank；显示侧用提交锁把新帧就绪对齐到 HDMI 消隐窗口上升沿，在消隐预算内把整帧原子拷进显示 BRAM，从结构上排除撕裂。像素通路提供灰度、二值化、模糊、Sobel、反色五种效果，0–359° 任意角旋转（Q8 三角查表逆映射）与以原始尺寸为最大的右屏无极缩放；HDMI 1024×600 左窗原图、右窗处理结果并列显示，左上角自写 OSD 叠加 FPS/角度/效果位。PS 仅经串口与 AXI GPIO 做控制。全设计 WNS +0.97 ns、0 违例、BRAM 64.6%、30 项仿真回归全绿；板级用自描述 frameid 图案加 JTAG 逐字回读判定，15/30/60 fps 最新帧命中率 100.0%、包内各字节带丢字率 0.0%。
```

```
本作品以 Zynq-7020 为平台，完整实践了逻辑设计、状态机、时序约束与接口协议四类基本能力。接口协议方面：PL 侧手写 RGMII 采样（IDELAYE2+IDDR）、ARP/ICMP/UDP 协议栈与按 offset 拼帧的重组状态机，不依赖 lwIP 与厂商网络 IP。逻辑设计方面：手写格雷码跨钟 FIFO、乒乓 bank 换页逻辑、64bit 打包器与按 lane 生成的 WSTRB。状态机方面：提交锁把「新帧就绪」对齐到消隐窗上升沿，配合 20 ms 看门狗与越窗粘滞告警，杜绝两帧混合。时序约束方面：以 -include_generated_clocks 声明三组异步时钟、按时机拆分约束文件，并把 eth_rxc 域一条 11 级进位链改写为饱和累加，使 WNS 由 +0.50 ns 提升到 +0.97 ns，全设计 0 违例、BRAM 64.6%、动态功耗 2.18 W。功能上实现五种效果、0–359° 旋转、右屏无极缩放与 HDMI 双窗对比输出；验证上 30 项仿真回归全绿，并以自描述图案 + JTAG 逐字回读给出可复算的板级判据。
```

### C. 强调「问题驱动 + 可复算判据」（讲述故事线）· 464 字

```
本作品是一条跑在 Zynq-7020 上的以太网视频处理流水线，重点在于「问题如何被发现并量化解决」。第一版用 PS 的 lwIP 收包，吞吐与抖动受软件调度限制；第二版把 RGMII/ARP/ICMP/UDP 全部改写成 PL 逻辑，PS 退为纯控制面，同时用目标域 3×3 窗口解决了旋转与滤波不兼容。之后屏幕出现拖影：显示侧改了三遍都没好，最后用「像素值同时编码地址与帧号」的自描述图案配合 JTAG 逐字回读，把问题定量化为「每个包从第 48 字节起按 16bit 粒度被丢弃」，根因是打包通道逐字等待 AXI 写响应、在途深度恒为 1；流水化写通道 + 按 lane 生成 WSTRB 之后，15/30/60 fps 三档最新帧命中率从 42~52% 变为 100.0%。在此基础上又完成三轮资源改造（BRAM 98.93%→64.6%、寄存器 51.3%→4.0%）和一轮时序改写（WNS +0.50→+0.97 ns，0 违例）。功能覆盖五种效果、0–359° 任意角旋转、右屏无极缩放与 HDMI 双窗对比输出。
```
