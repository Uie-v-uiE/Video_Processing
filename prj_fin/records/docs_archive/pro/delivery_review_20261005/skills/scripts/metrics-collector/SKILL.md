# 报告指标采集器（先探针再取值，产出 CSV + Markdown，抓不到写 NOT_MEASURED）

## 适用场景

- 每轮都要从几份文本报告里手抄同一批指标到表格，抄漏过、抄错过。
- 出现"这一列是空的"被当成 0 用；或同一指标一份报 `ns` 一份报 `ps`，直接相减得出"变好了"。
- 报告换了工具版本，某个字段静默抓不到，表里那一栏从此一直是空——没人报红。
- 要把资源/时序/台架读数落成一件可复跑、带三态判定词的东西，供门禁或复盘引用。

## 使用方法

在条目根目录跑（`<报告目录>` 是你自己的文本报告所在目录，脚本递归扫，跳过空文件与二进制）：

```bash
node scripts/collect.mjs <报告目录> [--out metrics.csv] [--report metrics.md] [--spec <file>] [--self]
```

**先查什么**：报告原文本身。打开那件报告，亲眼确认目标字段长在哪一行、数值与单位之间是什么分隔（`=` 还是 `:`、括号里是不是还藏着"可用量/百分比"）。一手顺序仍是 厂商用户指南里的报告格式说明 ＞ 应用笔记 ＞ 教程 ＞ 模型记忆。
**先跟用户确认什么**：哪些指标算"必中"（缺了就红）、同一指标出现两种单位时是判红还是要求先归一、CSV 的落点与是否覆盖上一轮的件。这三件都会改变读数口径。

按序走：

1. 第一次跑先看**探针段**（`# 探针 [类别] 指标 锚=/…/ 候选行=N` 加下面的原文行），逐条核对候选行是不是你以为那一行。"摘要行在第几行"靠猜就别往下读。探针段之后才出现 `M…` 取值行——顺序是刻意的。
2. 读结论行：`判 N 项：文件=F 抓到=X 未测=Y 单位冲突=Z 红=R <token>`。三个计数地板（扫描文件数 / 抓到的指标数 / NOT_MEASURED 数）都在 `P1`、`Z1`、`M` 行上单独打印。N 是**做了多少次比较**（打印出的判定行数），不是通过多少。
3. 应看到的样子：核心三类报告齐时 `文件=3 抓到=14 未测=1 单位冲突=0 红=0 NOT_MEASURED`——最后那个 token 是 `NOT_MEASURED` 不是 `PASS`，因为名册里有一条本目录不存在的指标。**"抓到"永远不等于"名册齐"**。
4. 每条必中指标的 `命中=0` ⇒ 该行判 `FAIL`（射程收窄不许静默）；非必中的落 `NOT_MEASURED`，仍然写进 CSV，值/单位/来源三栏都写 `NOT_MEASURED`，不留空、不编。
5. 换工具版本或换报告口味后，用 `--spec <file>`（JSON 数组，字段 `metric/cls/probe/re/required`，`re` 第 1 组取数值、第 2 组取单位）自带名册，别改脚本；名册文件坏了会判红，不会悄悄退化成内置的。
6. 动过名册或取值逻辑，第一件事是 `node scripts/collect.mjs --self`。
7. 退出码：有 FAIL ⇒ 1，其余 ⇒ 0。**退出码 0 不等于通过**，要判的是每行最后一个字段。

## 失效条件

- **报告格式随工具版本变 ⇒ 正则射程静默变窄**：锚是按字面找的，改名、换分隔符、字段折行、把单位挤进括号，都会让命中数从 1 变 0，而表里看起来只是"这一栏没填"。征兆：`候选行=0` 但报告里明明有那个数；或某指标的 `命中` 从 2 悄悄降到 1。**取值锚必须紧贴赋值号**（`标签…[=:] 数值`）；写成"跳过非数字去找下一个数"，遇到 `… = 12 tiles (可用 220 tiles)` 这种行，主数值一改写法就会静默抓到括号里的 220——这个坑在本条目夹具上实测到过，是收紧锚形才修掉的。
- **把夹具绿当真实可用**：`--self` 只证明这 4 份合成件被按预期抓住。真实报告的首轮要在探针段里逐条人工核对原文行，核对过的那一条才算成立。
- **0 样本真空通过**：扫描到 0 个文件时整条判 `NOT_MEASURED`（不判红也不判绿），名册条数照写进 CSV。看到 `文件=0` 先回去查目录与产出件的时间戳，别在调用处加 `|| true`。
- **跨单位相减**：同一指标出现多种单位时判红，且 CSV 的值栏写 `NOT_MEASURED` 而不是"取第一个"——宁可不给数，也不给一个口径不明的数。要把两侧归一到同一单位再入表，归一规则写进名册而不是写进结论叙述。
- **把必中指标改成非必中来消红**：这是"豁免买通"的近亲。红的那一条要说清是报告没了、还是锚没跟上；改 `required` 之前先跟用户确认。
- 值为 0 与"没抓到"是两回事，本器按字面数值入表（`未约束端点 = 0` 会抓成 0），但**空字符串永远不代表 0**。
- 指标名相同、语义不同的两份报告会被当成一条并判多单位；这时该拆指标名，不该关掉单位检查。

## 已验证效果

`node scripts/collect.mjs --self` 实跑读数：`判 10 项：红=0 夹具=4 名册=15 … PASS`，退出码 0。断言逐条为"期望=实得"：

- 干净三件基线：`文件=3 抓到=14 未测=1 单位冲突=0 红=0`，整体 token `NOT_MEASURED`（不是 PASS）。
- CSV 行数 16（名册 15 + 表头）；抓不到的那条实写为 `结温读数,NOT_MEASURED,NOT_MEASURED,NOT_MEASURED,…`，值/单位/来源都不留空。
- **能红对照**：把 `DSP 占用 = 12 tiles` 改写成 `= 十二 tiles` ⇒ `抓到=13 少抓 1 红=1 FAIL`。这条在收紧锚形之前曾是**绿的假象**（宽松锚抓到括号里的 220，抓到数不降），修完才具备能红的性质。
- 换单位那件加入后：`文件=4 多单位指标=2 红=3 token=FAIL`；0 文件目录：`文件=0 token=NOT_MEASURED 红=0`；名册文件写坏：`红=1 FAIL`（不退化成内置名册）。
