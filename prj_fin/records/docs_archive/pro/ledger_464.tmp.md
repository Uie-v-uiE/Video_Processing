  其余六条全 OK、`RESULT=FAIL`。分解式这边是 `main 非厂商 1131 + all 叠加 83 + 本地尺子 3 = 1217`。
- 定位方法（不是猜的）：用与脚本同一把 `find`（同一份剪枝名单）现数副本的仓库半，再与
  `git ls-tree main + git ls-tree all` 的非厂商并集做 `comm` 双向差 ⇒
  `bundle 有 / 期望无 = sd.mp4` 一支、`期望有 / bundle 无 = 空`。它是 2026-09-22 就在盘上的 SD 那一路原始片源
