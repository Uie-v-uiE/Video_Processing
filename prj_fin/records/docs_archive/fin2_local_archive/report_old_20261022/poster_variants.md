# 海报候选：四个版本与选用口径

这一页只解决一件事：把四个已完成的海报版本并排放好，让选的人知道每一版的尺寸、风格、适合的场合和当前缺什么。四个版本都已导出 PNG 与 PDF，PPTX 源文件同名放在 `poster/` 下。根目录的 `poster.*` 目前放的是 C 版（A4 竖版，默认交付候选）；A/B/D 三个候选都在 `poster/` 下。最终交哪一版由队伍选定后再改根目录。

| 版本 | 文件 | 画幅 | 风格 | 适合 |
|---|---|---|---|---|
| A | `variant_a_dark_16x9.*` | 16:9（2560×1440） | 深色科技感，架构图为主 | 屏幕展示、答辩投影 |
| B | `variant_b_light_16x9.*` | 16:9（2560×1440） | 浅色技术说明，左侧三条主张、右侧同帧对照 | 屏幕展示、快速阅读 |
| C | `variant_c_warm_a4_portrait.*` | A4 竖版（2480×3508，300 dpi） | 暖纸色编辑风，大标题与大幅同帧对照 | 决赛 A4 彩打 |
| D | `variant_d_blueprint_a4_landscape.*` | A4 横版（3508×2480，300 dpi） | 深色蓝图纸，架构路径与读数并重 | A4 横打、技术评审 |

## 画面里的那张对照图是什么

不是屏幕照片。它由 `build/make_poster_hero.py` 用同一张 512×300 测试帧渲染：左半是原图，右半是同一帧经 Sobel 边缘链处理后的结果（0°，不旋转），中间是 A/B 竖缝。海报上写明 “Sobel chain at 0°, no rotation”，没有把渲染图说成上板照片。第三点写的是“故障注入后可测量、可恢复”（CALIBRATED BY FAULT INJECTION），不把“self-test goes red”当卖点。

## 选版时看什么

- 如果决赛只收 A4 彩打，优先 C；C 的正文最小 6.8 pt，A4 原尺寸打印可读，缩到 A3 也不糊。
- 如果现场用投影或电子屏，A/B 的 16:9 画幅没有黑边。
- D 的深色底大面积打印会吃墨，彩色激光机打出来容易发闷；它更适合屏幕或 A3 展板。
- 四版共用同一组读数。当前四份 PPTX 的版本行是 r171 / WNS 1.341 ns / WHS 0.025 ns / bit `9734f3ec3019`；`build/make_posters_cd.py` 顶部的常量仍停在 r162（它只是初版生成器），**不要直接重跑它**，否则会把版本行写回 r162。换版按 PPTX 里的文本替换（rNN / WNS / WHS / bit），再用 `build/export_pptx.ps1` 按原尺寸重导。

## 还缺什么

- AMD 官方 PPT 模板尚未拿到；模板到手后，把选中的版本内容按模板母版重排，不直接套用现在的自绘版式。
- 队名、学校、队员信息按规则不放进海报；当前四版都没有队伍信息。
- 根目录最终只保留一个海报文件；`poster/` 里的四个候选用于选择，不随最终提交包一起交。
