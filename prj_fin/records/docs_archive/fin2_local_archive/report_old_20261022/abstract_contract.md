## 0. 这一页是什么、不是什么

- **是什么**：报名表单里**已经交出去、不能再改**的两件文本——作品名称《多源视频流多效果变换处理系统》
  与作品简介（499 字那一版）——现在就是合同的甲方。本页把它们逐句拆开，每行写清四件事：现场用什么
  动作兑现、凭据落在哪一件产物里、由讲稿的哪一段念、这一句现在的状态。
- **不是什么**：本页**不产生新读数**，也不把任何数字当自己的权威。要念数就念
  `data/metrics.csv` 与 `仓库留档 gates.txt（剪枝件，不随包）` 的末行；本页只给指路（同 `report/submission-package.md`
  第一条硬规矩：两处各报各的数 = 一定有一处会漂）。
- **状态只有三个值**：
  - `兑现` = 演示动作能当场做出这句字面的事，并且凭据件在包里。
  - `半关` = 字面的那一半已经成立、另一半还缺一次留档；写清缺哪一半、补它要跑什么。
  - `需念法` = 这句成立，但口径有弯（屏上的数与请求的数差一格、"不经 CPU"只管网口那一路、九位里有一
    位不是算法）。念错就等于自己制造一个可被推翻的说法，所以每一行把"该怎么念"写死。
- 已交文本的原文在校赛那轮的草稿里（仓库外的一份表格稿，不随包），仓库里不复制，
  避免第二个真相源。创新关键词那三个框**没有交**，所以讲稿的主线不受它约束。

## 3. 三条规矩与这些行的对应（讲稿主线用）

1. **一条通路**：从网线到屏不经处理器（只管网口那一路），三路片源共用同一套乒乓缓存与同一次显示提交
   → A02 A03 A06 A07 A08 A09 A15。动作：拔网线看它自己换源，屏上不见半帧。
2. **一套坐标**：0–359° 旋转、八档缩放、双线性插值共用同一个逆映射算子 → A12（"装得下"是算出来的，
   不是试出来的）。动作：转起来看屏上 `Zoom:` 自己变成 `(Fit)`。
3. **一条恒延迟链**：九位任意组合恒 15 拍、内容偏移恒 −4 行 → A10 A11 A13（缝能钉在任意列而两侧不错位，
   正是这条不变式的推论）。动作：叠两级算法再扫缝。

而**同帧左右对照**（A01 A13）不是第四条规矩，是把这三条读出来的那台仪器：错位、少列、越界填黑都会在
缝两侧当场露出来。讲稿按"一条规矩 + 一个动作 + 一次回指"排，功能不单独成段。
