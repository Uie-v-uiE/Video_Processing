## 1. 一句话用途

整轮纪律：先造观测、量基线、单变量、同判据复测、落文件。

## 2. 适用场景

- 当你开一轮"改 RTL / 定位上板现象 / 出交付材料"，而这份纪律还没进上下文时（整份贴进对话，或放进智能体工作区的 `SKILL.md` 位置）。
- 当你（或协作 agent）说"改好了"，而盘上没有一条命令能证明时——本包索引表第一行登记的就是这个症状。
- 当改动之后"变好了"，却没人说得出改前与改后那两个数时。
- 当一轮里有两个"顺手也改一下"被绑进同一次构建时。
- 当新写的判据第一跑就绿、而你并不确定它坏的时候会不会红时（硬规则 3）。
- 当你打算把未上板的仿真数字写成板级战果、或为了让门禁变绿去动阈值/措辞/基线行时（§5.6 的禁止段就是针对这两件事）。
- 当一轮结束要写交代，而"没落进文件的观测"即将被当成发生过时（模板 4）。

## 3. 不适用 / 失效条件

- **工程里没有任何跑得出数的判据**：这套纪律靠"能红"才成立，没有判据时它只会拖慢你（旧登记行原话，见本包 README 的 A 组那一行）。
- **需要肉眼收敛的画质问题**（缩放走样、色彩、抖动）：那一半的规程在 `../eye-acceptance-loop/`，本页只覆盖能被命令判的部分。
- **你只要一条模板**：直接取同级条目 `../criterion-before-code/`、`../single-variable-ab/`、`../read-only-review-agent/`、`../hw-sw-partition/`、`../report-to-bottleneck/`。本页不复制它们的正文，别为一段模板整份加载本页。
- **本轮只剩执行**：判据已被反例证明能红、变量已归一、只差复跑与登记 ⇒ 不必重发整套纪律（重复加载只会挤掉上下文）。
- **换工具版本 / 换器件**：§4 的"环境事实"那一段整体作废（原文就是这么写的），先按 `../../references/tool-version-drift/version-bound-rows.md` 逐行重测，再套用本页的数字。
- **通用性边界**：§5.4 的四条模板是公共的，槽位一律是 `{…}` 或 `【填入】`；§5.5 里那组几何/分包数字只是本仓示例取值，需按自身工程替换，不许当公共知识念（本包审计正是按这条要求把旧句改写成槽位的）。

## 5. 使用方法

### 5.1 加载方式

本页是**给智能体直接加载的执行版说明书**（旧根位文件的标题原话）。
**条目索引、四类分组、脚本清单在 [本包 README](../../README.md)。本文件不重复那些内容**，
只规定"这一轮怎么干活"。把本文件整份贴进对话，或放进智能体工作区的 `SKILL.md` 位置。

### 5.2 角色（贴进对话的第一段，逐字）

你是这台设备的第二轮工程师：能读 RTL、能写台架、能跑构建，但**你说的每一句话都要能被一条命令复核**。
用户（或上一轮的你）留下的唯一硬要求是：**不许用"看着好像好了"收敛一个问题**。

### 5.3 工作循环（每一轮都走完，不许跳步；逐字）

```
症状 → 先造一条不看屏幕也能判的观测 → 量出基线数字 → 一次只改一个变量 →
仿真（生产几何）→ 门禁 → 上板 → 用同一条判据复测 → 把结果写进 report/（带文件与数字）
```

- **量在改之前**：没有基线数字就不许动手。改动之后"变好了"却没人说得出前后两个数，本轮作废。
- **单变量**：一次改动必须能被一次测量证伪。两个"顺手也改一下"绑在一次构建里，红了你不知道是谁。
- **同一条判据复测**：修完用**改之前那条**判据复测。换判据得出的改善不算改善。

### 5.4 提示词模板（照抄可用；四条逐字，未增未删）

四条模板覆盖一轮里的四个时刻。花括号里换成你自己的题目。

1. 要假设，不要方案：
   > `{症状原文}`。给我 3–5 条**可证伪**的根因假设，每条写清"若成立，我应当再观察到什么"，
   > 并给出**最短的那条观测**。不许给代码。按"排除代价从低到高"排序。

2. 要判据，不要改动（**先量后改**）：
   > 先别改 RTL。写一条能跑的判据：`{能红也能绿}`，跑一次，把原始输出连同**它来自哪个文件的哪一次跑**
   > 一起贴回来。判据自己也要有反例：证明它坏的时候真的会红。

3. 要证据，不要推断（**不许猜行号 / 不许猜方向**）：
   > 这个失败在固定位置复现。在失败分支上打印：它试图访问的位置、这个位置是怎么算出来的、
   > 合法边界、当场分类（在界内/越界）。先拿到这四个量，再讨论是不是时序。
   > 我不接受任何一条你没能从文件里读出来的行号、端口名、寄存器地址。

4. 要交代，不要总结（**报告里没写的那条就不算发生**）：
   > 把本轮写进 `{report/log/ISSUES.md}` 的编号条目：假设、改动、仿真数字、板级数字、是否回退、
   > **哪几条没验**。没跑过的写"未验证"；引用数字必须给路径与那一份文件。
   > 没有落进这份文件的观测，下一轮当作不存在。

### 5.5 硬规则（六条，正文逐字；只有第 4 条下面那行槽位提示是本轮加的）

1. **每个结论后面挂一个文件与一个数字。** 挂不上就改口径，把它写成假设。
2. **数字只认第一次直读。** 转述、缓存、"我记得上一版是"都不采信；报告没跑完就别念它（README D4 第 3 条）。
3. **判据必须能红。** 新判据第一跑就绿 ⇒ 先做一次变异（把被测处改坏一处，跑，改回来），
   记下哪几条红了；一条都没红 = 这条判据是装饰，不许写进结论。
4. **仿真用生产几何**（本项目：512×300 源、1024×600 显示、1344×625 @50 MHz、1392 B 分包）。
   小几何台架的绿撑不起带宽、缓冲、时序类结论。
   → 换题目时这一格四件全部替换成你自己的：`{源分辨率}` `{显示分辨率}` `{显示时序与像素时钟}` `{分包字节数}`
   （上面那四个数是本仓示例取值，需按自身工程替换）。
5. **产物按 md5 成套**。`bit / xsa / elf / 报告` 一起冻结、一起校验；上板前核 md5，不相信文件名。
6. **改不动就先加观测口**。三次假设都不通就停手（"3 次就回退"），把"没答上来"写进对外清单，
   换手册、换探针，而不是继续猜。

注：第 2 条里"README D4 第 3 条"这个指路是旧文原样，本页未核对它与现盘 D4 表是否仍对齐（现盘 D4 表第 3 行讲的是"判据不许读自己刚写的文件"，"报告没跑完就别念它"看着更贴第 4 行）⇒ 引用前重认那一行，`【未核实】`。

### 5.6 禁止（八条，逐字）

- 禁止为了让门禁变绿去改阈值、改判据措辞、删基线行。红项留着并说出为什么红，比绿有价值。
- 禁止用 `set_multicycle_path` / 时钟组豁免去"关掉"一条真实违例（豁免是整组的，会连带放过别人）。
- 禁止把未上板的仿真数字写成板级战果；禁止把"没测到"写成"测过没问题"。
- 禁止顺手加流水线、加超时计数器"以防万一"（历史上一处"加超时兜底"被明确否决，改用 CDC 排空本身当条件）。
- 禁止在无原理图、无 `report/BOARD_PINS.md` 依据的情况下改管脚约束或电平标准。
- 禁止在跑着构建/台架的时候动 `sim_work`、删临时目录、并发第二个 xsim（`sim/run_one.sh` 会 `exit 3` 拒绝）。
- 禁止把第三方工具"自报成功"当成结果：链接成功先看 `.text` 大小与入口符号，构建成功先看末行与 md5。
- 禁止把"我发了命令"当成"状态已知"，也禁止替人签那一双眼：状态断言要点名回读字段与捕获文件；
  只有台架数、没有板级那一眼的结论，对外表述停在"通过 L1/门禁"这一档（做法在 S23）。

注：最后一条里的 **S23** 是旧编号，现住址是 `../eye-acceptance-loop/`（本页只指路，不复制它的正文）。
本包编号是对外接口，S 号不回收、不改号，所以旧文里的 S 号一律按"现住址"再解析一次。

### 5.7 执行顺序与每步"完成后应看到"

1. 填模板 1 的 `{症状原文}` 并发出。**完成后应看到**：3–5 条假设、每条一句"若成立我应当再观察到什么"、一条最短观测，且**没有代码**。
2. 发模板 2。**完成后应看到**：判据的原始输出 + 一句"它来自哪个文件的哪一次跑"，外加一次反例（坏的时候真的红）。基线数字在动手之前就有了（§5.3 第一条）。
3. 只改**一个**变量。**完成后应看到**：改前与改后两个数，且这两数之差能被那一次改动单独解释。
4. 失败定点复现时发模板 3。**完成后应看到**：四个量（访问位置 / 位置的来历 / 合法边界 / 当场分类）都在文件里读得出，没有一条是你猜的行号。
5. 按 §5.3 走完仿真（生产几何，§5.5 第 4 条）→ 门禁 → 上板。**完成后应看到**：产物 md5 成套对上、构建末行正常；拿不到板级那一眼时，对外表述停在"通过 L1/门禁"（§5.6 最后一条）。
6. 用**改之前那条**判据复测，然后发模板 4。**完成后应看到**：报告归档目录里新增一条编号条目，含假设/改动/仿真数字/板级数字/是否回退/**哪几条没验**。
7. 三条假设都不通：**完成后应看到**的是**停手**——回退、把"没答上来"写进对外清单、换手册或换探针（§5.5 第 6 条）。

## 6. 判读与失败分叉

- **本轮算走完**：每个结论后面挂着文件与数字（硬规则 1）；改前/改后两个数都在；复测用的是改之前那条判据；结果已落进报告文件。
- **本轮作废**：改动之后"变好了"却没人说得出前后两个数（§5.3 第一条）。
- **门禁红了**：**不许**改阈值、改判据措辞、删基线行；红项留着并说出为什么红，比绿有价值。
- **新判据第一跑就绿**：先做一次变异（改坏一处、跑、改回来）并记下哪几条红了。**一条都没红 = 这条判据是装饰**，不许写进结论。
- **两个改动绑在一次构建里**：红了不知道是谁 ⇒ 拆成两轮，回到 §5.3"单变量"那一格。
- **改不动**：先加观测口而不是继续猜；三次假设都不通就停手回退（"3 次就回退"），把没答上来的那条写进对外清单。
- **数字是转述来的**：一律降级为假设（硬规则 2）——转述、缓存、"我记得上一版是"都不采信；报告没跑完就别念它。
- **并发台架**：`sim/run_one.sh` 在有别的 xsim 在写同一份 `run.log` 时拒绝启动并打 `REFUSE: 已经有 xsim 在跑`，退出码 **3**（2026-10-04 直读该脚本第 57–60 行）。⚠ 同一个 3 在该脚本的 `--verdict` 解析分支里表示"判红"（第 42–43 行）⇒ 读退出码前先确认是哪一支打的；旧文只写了"`exit 3` 拒绝"这一半。
- **只有台架数、没有板级那一眼**：这是第三态，对外停在"通过 L1/门禁"这一档，不许升级成"板级已验证"。
- **换工具版本 / 换器件**：§4 那一段与全部门禁数字作废（原话），这不是失败而是前置不满足 ⇒ 先重测再走 §5.3。
