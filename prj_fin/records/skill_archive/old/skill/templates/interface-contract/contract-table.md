# 接口契约表模板

## 1. 主表（一行 = 一个可寻址对象；位域多时按位域再展开一行）

| 对象 | 偏移/地址 | 位域 | 读写属性 | 复位值（依据） | 写副作用 | 读副作用 | 中断号 | 单位与量程 | 最宽输入 | 时钟域（源→目的/同步方式） | 出处 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 【填入】 | 【填入】 | 【填入】 | RW/RO/WO/W1C/RC | 【填入或【未实测】】 | 【填入 或 无】 | 【填入 或 无】 | 【填入 或 无（轮询）】 | 【填入】 | 【填入】 | 【填入】 | 【文件:行 或 报告名】 |

列的填写口径（逐条可判定）：

| 列 | 必填？ | 填什么 | 禁止的填法 |
|---|---|---|---|
| 偏移/地址 | 必填 | 块基址 + 通道内偏移；同一张表内不许出现两个同址不同解释 | "由 IP 自动分配"（不写实际值＝没契约） |
| 位域 | 必填 | `[高:低]`，反相/低有效要在这里标 | 只写"控制字" |
| 读写属性 | 必填 | RW/RO/WO/W1C/RC 之一；两侧不对称（写被忽略、读恒 0）要另注 | 默认全写 RW |
| 复位值 | 必填 | 上电实际值 + 依据（约束里的初值、代码里的 `static` 初值、还是实测回读） | 写 `0` 而无出处 |
| 写副作用 | 必填（可写"无"） | 这一写会不会触发硬件动作/翻转/武装一个快照 | 留空（留空＝没人想过） |
| 读副作用 | 必填（可写"无"） | 读会不会移动窗口指针、武装锁存、清标志、改变下一次读的内容 | 留空 |
| 中断号 | 必填（可写"无（轮询）"） | 真实中断号来源（块图/中断控制器映射），并写"谁清它" | 猜测的编号 |
| 单位与量程 | 必填 | 原始单位（拍/计数）+ 换算式 + 换算发生在哪一侧；含"这一格可不可信"位 | 只给换算后的数 |
| 最宽输入 | 必填 | 该字段能接收的最大值（位宽上限、越界后的行为） | 只写合法值不写边界 |
| 时钟域 | 必填 | 源域→目的域 + 同步方式（2FF/灰码/握手/准静态）+ 是否要求"只在静止时改" | 写"跨时钟域没问题" |
| 出处 | 必填 | 具体 `文件:行` 或块图对象名；改代码要同批改这列 | "见 RTL" |

## 2. 三类最容易漏的字段（不写就会在下一次事故里补写）

1. **窗口式读回**（先写选择字段、再读一个数据口）：
   - 读副作用列必须写"读一次会消费一次选择"；
   - 增加成员时必须排在该组第一个字之后，否则按正常顺序读会拿到上一遍武装的那一轮（判据恒红，红的是脚本自己）；
   - 同一组内存在恒等式（总时长 = 三段之和、低 16 位与高 16 位同属一个量）时，
     要加一行"快照武装位"：取自读法本身（选择字段指到该组第一个字）而不是新控制位；
     live 值仍然保留（台架逐周期验"值对不对"，板级验"一组自洽"，两件事不能互相顶替）。
2. **反相/低有效位**：位域列里直接标（示例形状：`[20]` 是"OSD 关"，1 = 关掉叠层），
   否则主机侧写 1 期望"开"会长期查不下去。
3. **只在静止窗口生效的位**：写副作用列要写"这一写只在消隐/静止窗口生效"，并在时钟域列写清准静态假设。

## 3. 复位值与"上电实际值"必须分两栏的理由

- 仿真丢掉越界写、硬件按地址位宽截断：同一行代码两侧行为不同 ⇒ "声明的初值"不等于"上电读到的值"。
- 上电默认与文档默认不一致是一件会被演示当场发现的缺陷：默认档要从主机侧初始化代码里逐条 grep 出来，
  并给一条"屏上/回读怎么验"的列（本模板第 1 节的"出处"列承担不了这件事，可加一列"怎么验"）。
- 有开机自动动作会改写默认值（例如挂载成功就置位某个源选择）：这类"默认之后被覆盖"要写在复位值列的括注里。

## 4. 一致性检查四条（填完就跑，别等联调）

| # | 检查 | 做法 | 通过条件 |
|---|---|---|---|
| C1 | 偏移唯一、位域不重叠 | 把表导成机器可读（CSV/JSON），脚本按 `(偏移, 位区间)` 排序查交集 | 交集 = 0 |
| C2 | 两侧宽度一致 | 主机侧写的掩码/移位与该对象声明位宽逐条对 | 不一致项 = 0 |
| C3 | 复位值有出处 | "复位值"列每格都能 grep 到代码或约束里的初值 | 无出处的格 = 0（否则写 `【未实测】`） |
| C4 | 写图案再读回 | 上电路径里对所有 RW 位写一个图案、读回比对 | 读回 == 写入；失败时现象写进"写副作用"列 |

C4 的价值：硬件定义里缺了某个通道时，编译不报错，现象只是"命令全都没反应"，所以这一对自检值得留在开机路径上。

## 6. 主机侧配套（这张表要能被代码直接消费）

1. 表导成机器可读格式（CSV/JSON），主机侧访问层从同一份生成偏移与掩码常量，
   禁止在代码里手写第二份地址（写第二份就会漂）。
2. 每个位域的注释引用同一行的"出处"列，改 RTL 时由行号锚点检查器判红（本仓库那把尺子：
   `src/host/line_cite_check.mjs`，判"引用行号附近有没有那句话里必然出现的标识符"）。
3. 读回函数按第 2 节的窗口协议生成顺序（先选后读），并把"这一组可信位"当返回值的一部分，
   不可信时**既不判红也不判绿**。
