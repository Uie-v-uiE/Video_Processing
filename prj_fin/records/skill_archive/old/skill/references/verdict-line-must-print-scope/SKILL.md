## 1. 一句话用途

结论行的三态形状，逐行点名留档件。

## 2. 适用场景

- 当你手上是一把聚合型判据（门禁脚本、CI 检查、审计表），它把 N 项小判据合成一句结论时。
- 当它某天打印了绿色的总结，而你发现其中几项**今天根本没有可判的对象**——缺报告、缺凭据、目录里没有那个文件、上游没产出——
  脚本走的是"这条不判红"的分支时。
- 当"全绿"这句话的含义已经变了，但结论行一个字都没变时。
- 当你想让"只有全判定才允许冻结/发布"这条规则**不改下游**就自动生效时。
- 当你要给一条尺子改动留"同一份输入、改前改后"的一对输出时。
- 当你要判断某个检查器的作用范围有没有漂（它自己打印的"扫了多少文件"变了没有）时。

## 3. 不适用 / 失效条件

- **本层不是判据**：任何结论都不能靠本页自称成立，只能靠 `evals/` 的记录或实测输出；本页写的是"本仓的结论行现在长什么样"，不是"你该怎么判"。
- 不适用：单项判据（没有聚合结论行可写）。
- 不适用：那些"缺席本身就是错误"的检查——应当直接判红，而不是打 n/a；本页只管**已经被你判定为可以不判**的那几项。
- 不适用：探索期的一次性脚本（还没有要被它长期守护的对象）。
- 失效：如果"未判"是**长期状态**（某项判据的凭据结构上就不存在），那么每次结论都是 PARTIAL，它会很快被忽略——
  那时该做的是删掉那一项或把它改成硬要求，而不是留着稀释结论。
- 失效：三态改变了退出码，可能把**历史**重放也变成红（老目录缺新加的凭据文件）；上线前先跑一遍旧目录，
  确认"红的是真缺凭据"而不是"判据读错文件名"。
- 失效：行首换词会让既有的 `grep` 逻辑反转——这是动作 3 的目的，但也是它最容易伤到自己的地方：
  改完必须去看下游谁在读这行（本仓两处：`build/freeze_evidence.sh` 与 `build/refresh_evidence.sh`，示例取值，需按自身工程替换）。
- 版本/形状绑定：页内三串文字、两个数字（18 项 / 2 项）与退出码都绑本仓 r88 那一次跑（2026-09-29 落盘）；
  换轮次或改脚本措辞而不带对照，本页那些行随之作废，需重取。token 形状通则见 `skill/references/checker-convention-shapes/SKILL.md`。
- 不许越界：本页不给出"该把哪一项改成硬要求"，也不替你决定阈值。

## 4. 前置条件

- 一支会输出总结行的聚合脚本，且你能在里面加两个计数器（判定数、未判数）与两个会自增的打印函数。
- 一对可留档的输出件（同一份输入，改前/改后各一份）：本仓形状是 `build/r88_gates_naive.txt` 与 `build/r88_gates_partial.txt`。
- 能查下游读者：`grep -rn "ALL PASS" build` 一类；本仓的下游是 `build/freeze_evidence.sh` 与 `build/refresh_evidence.sh`。
- 报告集仍在盘上（要复算"改前那次其实已经有两条 n/a"这件事，得留着那两份件）。

## 5. 使用方法

1. **把"不判"变成一等公民**：给红绿计数器之外再加一个 `NNA`（未判数）与一个 `NSAY`（判定数），
   每个 n/a 分支必须走一个会自增的打印函数，而不是散落的 `echo "n/a ..."`。散落的 echo 是根因：它写的时候很自然，读的时候没人计数。
   完成后应看到：本仓形状是 `say()` 里 `NSAY=$((NSAY+1))`、`naa()` 里 `NNA=$((NNA+1))`（`build/gates.sh` 第 173–183 行）。
2. **让结论行携带范围**，并且分三态，不是一态：

| 收尾档 | 必须打印的行（本仓形状，示例取值） | 退出码 | 本轮打开过的出处 |
|---|---|---|---|
| 有红项 | `GATES: 有红项（判定 $NSAY 项）—— 不采纳，保留上一版` | 1 | 代码 `build/gates.sh` 第 582 行 |
| 无红项但有未判 | **`PARTIAL —— 判定 $NSAY 项全过，但有 $NNA 项因缺凭据未判`**，后面接着"见上面 n/a 行" | 1 | 代码第 584 行；件 `build/r88_gates_partial.txt` 第 43 行 |
| 无红项且未判 = 0 | `ALL PASS（N 项全部判定）` | 0 | 代码第 586 行 |
| 旧形状（只两态，会把未判念成全绿） | `GATES: ALL PASS` | 0 | 件 `build/r88_gates_naive.txt` 第 43 行——同一份件第 30–31 行已经写着两条 n/a |

   完成后应看到：末行有三种之一——有红项 / PARTIAL（判定 N 全过，但有 M 项未判）/ ALL PASS（N 项全部判定）。
3. **注意下游是 grep 行首**：如果"未判"那一档仍以 `ALL PASS` 开头，下游的 `grep '^ALL PASS'` 会照样放行。
   所以那一档的行首必须换成别的词（这里用 `PARTIAL`），这样"只有全判定才允许冻结/发布"这条规则不用改下游就自动生效。
   完成后应看到：下游一个字都没改，冻结那一步自然拒绝这一版（本仓第 27–28 行 REFUSE 分支、`build/refresh_evidence.sh` 第 97 行同一串）。
4. **给这条改动留一对对照**：同一份输入，改前打 `ALL PASS`、改后打 `PARTIAL … N 项 / M 项未判`，两份输出都留下来。
   否则你只是声称修好了尺子。
   完成后应看到：两份件同一时间戳落盘（本轮 `ls` 到两份都是 2026-09-29 15:42），且第 30–31 行的两条 n/a 在两份里都在。
5. 顺带同一族的另一条：每个检查器自己也要打印扫了多少文件（旧卡记的实例是 `扫了 353 个手写文件`），数字变了就说明作用范围漂了。
   完成后应看到：扫描面数字与本轮真实文件数同向变化。

## 6. 判读与失败分叉

- 步骤 1：
  通过 = 每一条 n/a 都让 `NNA` +1，且未判有独立计数与独立措辞。
  失败 = 结论行没有数字对 ⇒ `FAIL`（散落 echo 那一族；本仓脚本自己的注释就写着"同一个坑本仓记过五次"）。
  读不到输入 = 这一跑一条 n/a 都没走到 ⇒ 未判数必须打 `0` 而不是省略，否则 `NOT_MEASURED`——"没打印"不等于"没有未判"。
- 步骤 2：
  通过 = 结论行能被独立读出一个数字对（判定 N、未判 M），且 N = 绿+红行数。
  失败 = 末行只有 PASS/FAIL ⇒ `FAIL`：有 n/a 时会被念成 ALL PASS。
  读不到输入 = 末行没有数字 ⇒ `NOT_MEASURED`，先补分母打印再谈结论。
- 步骤 3：
  通过 = 下游未改却自然拒绝（它 grep 的是行首那个词）。
  失败 = 下游照样放行 ⇒ `FAIL`，行首词没换干净——本仓下游用的是行首锚（`grep -q "^GATES: ALL PASS"`），
  所以 PARTIAL 那一档必须换行首，而不是只在句中加入说明。
  读不到输入 = 没查出谁在读这行 ⇒ `NOT_MEASURED`，先全仓 grep 再改词。
- 步骤 4：
  通过 = 两份输出都在盘上、来自同一份输入，且差值只有措辞与退出码。
  失败 = 只有改后那份 ⇒ `FAIL`，你无法证明改前真的绿。
  读不到输入 = 那一份报告集已不在（历史轮次的件被覆盖）⇒ `NOT_MEASURED`，别把"跑不了"写成"过了"。
- 步骤 5：
  通过 = 扫描面数字随作用范围变化。
  失败 = 数字不变而范围变了 ⇒ `FAIL`（范围漂了没人知道）。
  读不到输入 = 该检查器不打印这个数字 ⇒ `NOT_MEASURED`，先补打印。
