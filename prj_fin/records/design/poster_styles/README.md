# 海报风格对比（归档）

最终选用的是 `poster_amd_template.*`（AMD 模板 16:9 横版，湖南工业大学）；提交件在 `../../../submission/deliverables/poster.*`。本目录保留早期六个 A4 竖版方案和最终的 AMD 模板方案，均使用同一组最终读数：WNS 1.341 ns、WHS 0.025 ns、BRAM 70.00%、效果链 15 cycles。

| 文件 | 风格 |
|---|---|
| `poster_amd_template.*` | AMD 模板 16:9 横版，湖南工业大学，最终选用 |
| `poster_dark_scope.*` | 深色仪表 / 遥测 |
| `poster_swiss_grid.*` | 瑞士网格 / 数据表 |
| `poster_blueprint.*` | 蓝图技术稿 |
| `poster_bold_blocks.*` | 高对比色块 |
| `poster_canvas_visual.*` | 参考 `canvas-design`：少字、90% 视觉、细字 |
| `poster_impeccable.*` | 参考 `impeccable`：奶油/焦橙分区、固定色盘、字号阶 |
| `contact_sheet.png` | 六版缩略对比 |

`canvas-design` 与 `impeccable` 是公开设计技能，本次只参考其公开原则，没有安装其运行脚本。`impeccable` 原推荐 Chakra Petch / JetBrains Mono，本机没有 Chakra Petch，使用 Bahnschrift + Consolas 代替。

选定后把对应 PNG/PDF/PPTX 替换到提交件的 `deliverables/poster.*` 并重新同步 FIN。
