# 演示视频分区脚本

每个部分给三件事：发什么命令、屏上和终端出现什么、后期在屏幕上打什么字。命令都是板内当前固件认的写法，串口参数 `115200 8N1`，板子 `192.168.1.10`，视频口 `UDP 5001`，遥测口 `UDP 1234`。

排版统一：右半屏拍面板，左半屏放终端或仪表盘。每条命令敲完静置 2 s 再切下一条。

---

## 第 1 部分 · 开机与整机身份（15 s）

| 发什么 | 出现什么 | 屏幕文字 |
|---|---|---|
| （上电，不接 JTAG、不碰电脑） | 2–4 s 后面板出画面，OSD 五行亮起 | `Zynq-7020 · 全 PL 视频通路` |
| `stat` | `[STAT] ctrl ... src=... frames=...` | `控制字、片源、帧数一次回读` |
| `temp` | `[TEMP] degC=62.3 ...` | `PS 侧 XADC 读数进 OSD` |

---

## 第 2 部分 · 网络收流（30 s）

| 发什么 | 出现什么 | 屏幕文字 |
|---|---|---|
| `src 1` | `[SRC] 已钉住 ETH` | `片源：网络推流` |
| `python src/host/video_sender.py --demo --seconds 30` | 面板出视频，OSD `SRC:ETH  FPS:30` | `上位机 → UDP → RGMII → DDR` |
| `python src/host/telemetry_listen.py 20` | 每秒一行 `frames= pkts= bad= aborts= lat_ms= pane_bad=` | `1 Hz 遥测：帧数、包数、时延都在板子上数` |
| `link` | `[LINK] drop= badpkt= aborts= rows_max= stall= gap_last/min/max live=1` | `链路计数：只读，不改状态` |

---

## 第 3 部分 · 缩放与双线性（40 s）

| 发什么 | 出现什么 | 屏幕文字 |
|---|---|---|
| `zoom off` | 源画面按最近邻铺开 | `双线性关：块状` |
| `bilin on` | 同一位置变平滑 | `双线性开：平滑` |
| `zoom 0.5` → `zoom 1.0` → `zoom 1.5` | OSD `Zoom:` 跟着换档 | `八档定档缩放 0.25–2.00` |
| `zoom auto` | 倍率自己呼吸变化 | `倍率自动扫描` |

坑：`zoom 1` 是开关，`zoom 1.0` 才是 1.00 倍。这一条最容易敲错。

---

## 第 4 部分 · 任意角旋转（40 s）

| 发什么 | 出现什么 | 屏幕文字 |
|---|---|---|
| `rot auto 1` | 画面开始连续转 | `任意角旋转 · 每帧走 2°` |
| `rot speed 0`（在任意角度停） | 画面停住，OSD `Rot:` 显示停在几度 | `角度读数来自 OSD，实测 X°` |
| `zoom fit 1` | 转到哪个角度就缩到刚好装得下 | `倍率跟角度走：自动定标` |
| `rot speed 5` | 转速变快 | `7 档转速` |

角度没有串口入口，靠按键 ±1° 或自动转来带；停在几度就报几度，别说成整数。

---

## 第 5 部分 · 六级效果链（50 s）

| 发什么 | 出现什么 | 屏幕文字 |
|---|---|---|
| `pipe 000000000` | 效果全关，回到原图 | `效果全关` |
| `pipe 100000000` | 变灰 | `1 灰度` |
| `pipe 010000000` | 变反色 | `2 反色` |
| `pipe 001000000` | 模糊 | `3 3×3 模糊` |
| `pipe 000100000` | 锐化 | `4 3×3 锐化` |
| `pipe 000010000` | 边缘 | `5 Sobel 边缘` |
| `pipe 000001100` | 黑白二值 | `6 二值化（阈值开判决）` |
| `th 120` → `th 200` | 二值图白区变化 | `阈值可调 0–255` |
| `gamma 1.8` | 右半画面亮度曲线变化，左半不动 | `Gamma 只作用于处理侧` |

屏幕文字用"1/2/3…"逐级点亮，不要写"六种效果同时开"。

---

## 第 6 部分 · 同帧 A/B 竖缝（40 s）

| 发什么 | 出现什么 | 屏幕文字 |
|---|---|---|
| `pipe 000010000` + `split screen` + `split 50` | 中间一条竖缝，左原图右边缘 | `同一帧 · 左原图 / 右处理` |
| `split auto`（录 8 s）→ `split manual` | 缝从左扫到右，内容不跳不断 | `缝在移动，画面不撕裂` |
| `split swap 1` | 左右内容互换，缝位读数不变 | `只换内容，不换缝位` |
| `split swap 0` | 换回来 | `两侧共用同一套几何` |
| `split marker 1` | 蓝色分界线消失，缝还在 | `分界线只是标记，不参与取数` |

这一段是全片最省力气的一镜：一次 `swap`，结论自明，不用旁白。

---

## 第 7 部分 · 帧提交三条件（60 s）

先开仪表盘：`python src/host/instrument_dashboard.py 192.168.1.10`（先点 Ping/ARP）。

| 发什么 | 出现什么 | 屏幕文字 |
|---|---|---|
| `python src/host/udp_push.py --pattern edge --fps 15 --count 600` | 整屏白↔整屏黑硬切，没有半灰行 | `换帧是原子的：整帧一起上屏` |
| `python src/host/udp_push.py --pattern edge --fps 15 --count 400 --drop-every 500` | 画面每隔几帧顿一下 | `每 500 包丢 1 包：部分帧被拦` |
| `python src/host/udp_push.py --pattern edge --fps 15 --count 400 --drop-every 100` | 画面冻在某一色上不再翻 | `每 100 包丢 1 包：收不满就不提交` |
| （同框看仪表盘） | FPS 曲线塌到 0，`ABORTS` 往上跳，事件栏打"作废帧 +N（最后一次缺 X 行）" | `缺字节 / 缺行 / 坏包，三门同时过才提交` |
| `python src/host/udp_push.py --pattern edge --fps 15 --count 400` | 画面恢复翻页 | `恢复：计数不再上升` |

旁白一句就够："包发出去了，屏没变——因为这一帧没收满。" 不要把三门拆开逐个演示，单包丢失会让字节门和行覆盖同时不成立，画面表现一样。

## 第 8 部分 · 仪表能被打红（45 s）

| 发什么 | 出现什么 | 屏幕文字 |
|---|---|---|
| `python src/host/link_selftest.py 192.168.1.10 6` | 三段依次打 `frames=/aborts=/bad=` 每秒变化量 | `三阶段：干净 → 注入丢包 → 干净` |
| （留判定行完整入画） | 末行判定与退出码 | `判据是变化率，不是绝对值` |
| `link clr` → 停推流 8 s → `link` | `stall=` 从几百 ms 涨到上万 | `断流也在计时` |
| 重启推流 → `link` | `gap_valid=1`，`gap_max=` 留下刚才断的时长 | `最大帧间隔被记住` |
| `pipe 100000000` + `split video` + `split 50` | 遥测行 `pane_bad=0` | `处理窗完整性计数：0 命中` |

## 短版怎么砍

3 分钟版砍第 9 部分、第 3 部分只留 `zoom off/on` 对照、第 4 部分只留旋转一次、第 5 部分效果链只留灰度→Sobel→二值三跳。

90 秒版只留四个镜头：`split swap 1`、`--drop-every 100` 画面冻住 + 作废计数上升、`link_selftest.py` 判定行、断电上电自己亮。

## 拍前小抄

```text
src 1
zoom 1.0
rot auto 0
rot speed 0
split screen
split 50
split swap 0
split marker 0
osd on
pipe 000010000
```

三条最容易敲错的：`zoom 1` 是开关不是倍率；`split marker 1` 是隐藏蓝线；`pipe` 九位最左是 bit0（灰度）。
