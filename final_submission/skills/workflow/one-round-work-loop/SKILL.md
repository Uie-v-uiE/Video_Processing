# 一轮工作的标准节拍与产出物

## 适用场景

任何"要被证明而不是看着对"的一轮：改 RTL、改约束、改流程脚本、改上位机侧代码都算。
症状级触发：说不清这一轮相对上一轮赢在哪；报告只在终端里看过一眼；两处文档各写一个数字；
下一轮开头第一件事是"上一轮那个读数在哪"。
不适用：纯查资料、不产读数的轮次——那种轮次只记"查了什么、出处在哪"，可省尺子但不可省判据。

## 使用方法

**动手前先查**（一手资料优先级：厂商用户指南/数据手册/接口规范 ＞ 应用笔记 ＞ 教程 ＞ 模型记忆）：
本工程的构建命令与报告落点约定、上一轮同一把尺子的位置与口径、目标器件/平台的资源与约束语法边界。
**先跟用户确认**：这一轮的边界（"只做这一件事"是否被认可）、会动到外观或演示顺序的部分、任何不可逆动作。

九步，每步都写"产出物是什么"和"缺了它下一轮会怎么断链"：

1. **立案**。产出物：一句话现象 + 一到三个可驳的假设 + 这一轮的判据（"看到什么算赢"）。
   缺了它：下一轮不知道上一轮在赌什么，结论既不能被推翻也不能被继承。
2. **先配一条能红的尺子**。产出物：判据脚本/台架用例 + 在**未改**的树上跑出的"改前红"（FAIL）读数，落盘。
   缺了它：改后无论报告长什么样，你都无法区分"DUT 变了"和"期望本来就是我猜错的"。
   判据要么自带能动的变异对照，要么显式标注"未配对照"。
3. **单变量最小改动**。产出物：一处能被一句话解释的 diff。
   缺了它：差分归因失效，赢的那格不知道是谁的功劳。多刀要么拆轮，要么逐刀各配判据（见失效条件）。
4. **构建**。产出物：构建日志 + 产物（位流/可执行件）与其版本号。
   硬规则：**构建在飞时禁改同一批源文件**——要么等它结束，要么在隔离拷贝树里做。
   缺了它：这一轮的产物不属于这一轮的源，后面所有量都在读旧树。
5. **量**。产出物：报告**落盘为可复跑的文本件**（时序/资源/台架读数），不能只有二进制日志；
   件里带命令、工具版本、时间戳。缺了它：下一轮拿不到同口径输入，只能重跑或凭记忆。
6. **差分**。产出物：与上一轮**同一把尺子**的对比表，且**成对**——赢的那格与可能跌的那格一起列
   （例：余量涨了，就同时列占用、别的路径、别处覆盖面）。只列赢面视为没做差分。
   缺了它：局部收益掩盖别处回退，下一轮在带着暗伤的新基线上继续加刀。
7. **落件**。产出物：件与被引用的结论进**同一次提交**，结论里点名件路径。
   缺了它：交付包"点名件不在盘上"，复核只能重跑或判 `NOT_MEASURED`。
8. **改口**。产出物：所有引用旧数字的地方一次改完，并跑一次**数字对账**（把被替换的旧值全文搜一遍，
   命中数应为 0，非 0 即未改完）。缺了它：两处文档各说一个真相，下一轮以错的那个当基线。
9. **提交**。产出物：一次提交=一轮，diff 与件与结论同处；提交信息带上判据与读数，
   判定用三态 `PASS / FAIL / NOT_MEASURED`，结论行最后一个字段是判定词，`判 N 项` 记的是比较次数。

**一轮记录的最小字段**（照抄即可，多一栏都不要）：

| 字段 | 内容 |
|---|---|
| 标题 | 这一轮动的是哪一类东西，一句话 |
| 判据 | 命令 + "应看到什么" + 改前红读数 |
| 件路径 | 落盘的文本件（相对位置，不写本机绝对路径） |
| 结论 | 三态判定 + 成对差分的两格 |
| 欠账 | 这一轮没做完、下一轮必须接走的东西 |

## 失效条件

- **单变量前提被破坏（同轮多刀）**：必须逐刀先红后绿——每一刀各自在未改树上取改前红、各自一条判据。
  做不到就把这一轮整体降级为"动过，归因不明"，不许写"因为 X 所以赢了"。
  征兆：diff 里同时出现两个模块或两类改动，而判据只有一条。
- **改了没量**：提交里有源改动、没有新落盘的件；或件的时间戳早于 diff。
  征兆：结论句用"应该/预计/按道理"而不是读数。
- **量了没落件**：读数只在终端或二进制日志里活过一轮，下一轮开头第一件事是重跑。
  征兆：复跑命令写不出来，或那一轮的件找不着。
- **落件没改口**：件是新版，文档里还挂旧数字；对账搜索命中旧值。
  征兆：同一指标在两个文件里差一点点——差的那一位属于旧轮次。
- **长夜批次把 0 字节日志当"还在跑"**：日志存在且 0 字节通常意味着刚起或已成孤儿，不是进度证据。
  判活看三样：进程是否在册、日志是否随时间增长、产物 mtime 是否推进。三者都读不到 ⇒ 判 `NOT_MEASURED`，
  不许猜成"还在跑"然后继续下一刀。
- **尺子换了**：改了期望、容差或提取口径 ⇒ 与上一轮不可比；这一轮结论只能写"新基线，无对比"。
- 空集、解析失败、读不到一律 `NOT_MEASURED`，不许当成绿；把"没扫到"写成通过是这条节拍最贵的失效。

## 已验证效果

未量过，属建议：本条按通用节拍整理，增益没做过干净工程带/不带的 A/B。
可自查的三个读数：每轮"改前红"件数（应为 1 或每刀 1）、数字对账搜索的旧值命中数（应为 0）、
结论来自落盘文本件的比例（应为全部）。三个数齐了才算这条在被执行。
