# 登记卡 S06 · 最终定版轮

> 本卡是登记卡，不是会话原文。原文含本机路径和临时文件，按 `redaction.md` 的处置不随包。

## 1 负责什么

这一轮把工程从“功能可用”推进到“可提交”：整理提交树、重构 board/build 目录、补技术文档与海报、修正文档事实，并把最终包推到 GitHub。模型主要做四件事：

- 把历史构建物、旧测量日志和过程文档移出提交面，只保留源码、台架、报告、板级工程和一手证据。
- 用 TCL 重建 `board/vivado` 工程并现场打开验证；把 Vitis 平台移到 `board/vitis`；把构建脚本集中到 `build/`。
- 重写 README、设计报告、验证、优化、复现、局限、协作记录和技能包索引；技术文档/海报改为本地交付件，不进 GitHub。
- 修复 `link` 命令不可达、A9 文档口径、BSP 路径、冷启动/帧间隔待复验等事实问题。

## 3 模型没有做的事

- 没有替人判断 HDMI 画面是否可接受；E1/E2/E3 仍是人眼项。
- 没有替人决定比赛模板、页数和提交系统字段。
- 没有把“台架绿”写成“板上也绿”；板上读数单独跑、单独落盘。
- 没有为了 WNS 数字继续改动已经签字的 RTL；时序边界写在 `report/limits.md`。
