## 2. 为什么需要一个"冻结时刻"

这份导出在我取证期间**还在被写**。同一条命令相隔约 25 分钟的两次读数：

| 读数时刻（本地） | 字节数 | `wc -l` |
| --- | --- | --- |
| 2026-10-04 11:47 | 466,438,307 | 174,796 |
| 2026-10-04 12:12:43 | 467,330,926 | 174,969 |

⇒ 不加截止条件的话，"行数/大小/哈希"永远不可重算（P22 质量判据 3）。
所以本档案规定：**一切统计只算 `timestamp < 2026-10-04T03:44:00Z` 的记录**；
字节数、行数、SHA-256 这三个"文件级"字段**只能按快照时刻报**，并同时报增长量。
日志是追加式的，所以冻结窗口内的数字随时间仍然成立。

## 4. 复算命令（本卡数字的出处）

```bash
# 均在 <本机 Qoder 目录>/projects/D--Xilinx-Prj-pro/ 下执行；只读，不修改导出文件
C1  sha256sum b20eed02-764d-4c48-b7a8-2791ce120863.jsonl && stat -c '%s' b20eed02-*.jsonl
C2  wc -l b20eed02-764d-4c48-b7a8-2791ce120863.jsonl
C3  python - <<'PY'                     # sessionId 去重、类型分布
import json,collections
c=collections.Counter(); ids=set()
for line in open('b20eed02-764d-4c48-b7a8-2791ce120863.jsonl',encoding='utf-8',errors='replace'):
    s=line.strip()
    if not s: continue
    d=json.loads(s); c[d.get('type','<none>')]+=1
    if d.get('sessionId'): ids.add(d['sessionId'])
print(len(ids), dict(c.most_common()))
PY
C4  # 冻结窗口内：人工轮次 / tool_use / is_error / 活跃时长 / 重试（算式与结果在 ../metrics.md §2）
C5  # 无 timestamp 记录数 = C2 − C4 的 `LINES_BEFORE_CUT`
```
