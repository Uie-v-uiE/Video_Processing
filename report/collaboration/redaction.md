原则（逐字照铁律 6）：绝对路径中的用户名、账号、令牌、内网地址、他人昵称与头像必须逐条记录
"改了什么、出现在哪、是否影响可核验性"；**不许整段删除关键证据来省事**；
涉及隐私无法公开的，改为"本地留存 + 摘要 + 口径说明"，并明确写第三方无法复现该项。

本档案的做法：**只用"改写/占位"，零删除**。下面 §5 给出"我删了什么"的答案 = 一条也没删，
并且给出可核对的反证方式。

**本档案自己的扫描命令**（判 9 类，逐类对 7 个新文件跑）：

```bash
cd <仓库根>
LIST=$(find report/collaboration -name '*.md' | sort)          # 7 个文件
echo "$LIST" | while read f; do
  for pair in 'win绝对路径:[A-Za-z]:[\\/][A-Za-z0-9_ .-]{4,}' \
              'posix家目录:/(home|Users)/[A-Za-z0-9._-]{3,}' \
              '内网IPv4:(192\.168|10\.[0-9]{1,3}|172\.(1[6-9]|2[0-9]|3[01]))\.[0-9]{1,3}\.[0-9]{1,3}' \
              '令牌:(ghp_[A-Za-z0-9]{16,}|github_pat_[A-Za-z0-9_]{16,}|AKIA[0-9A-Z]{12,})' \
              '键值凭据:(api[_-]?key|secret|passwd|password)[ ]*[:=][ ]*[A-Za-z0-9_/+.-]{6,}' \
              '邮箱域:@[A-Za-z0-9.-]+\.(qq|163|126|outlook|gmail|foxmail|189|sina)\.com' \
              '机器名:[A-Za-z0-9_-]+-laptop' \
              '本机用户名:<WINUSER 的实际字符串>' \
              'Windows账号段:<本机账号名的实际字符串>'; do
    n=${pair%%:*}; p=${pair#*:}
    printf '%-14s %s\n' "$n" "$(grep -Ec -- "$p" $f | paste -sd+ | bc)"
  done
done
```

> 最后两条模式**不在这份文件里写出实值**（写出来就自己造了一次命中）；
> 实值由队伍在本机执行时代入，占位符与还原口径见 §2。

## 5. 我删了什么？（铁律 6 最后一句的直接回答）

**一条证据都没有删。** 可核对的反证有三条：

1. 本档案的 11 个 `.md`（= P22 点名的 7 件，其中 `sessions/` 展开成 5 张卡）**全部是新建文件**，
   我对它们**没有做过任何删除或改写既有证据的动作**。
   需要如实补一句状态变化：12:2x 时 `git status --porcelain report/collaboration` 是 `?? report/collaboration/`；
   12:39 另一支兄弟子会话的装配提交 `1c4e26b` 把其中 10 个文件连带入了库，
   于是我在那之后的修订在 12:5x 显示成 5 个 `M` + `?? README.md`（逐条见 `README.md` §3 末的两时刻表）。

2. §3 的凭据类命中全是 0 ⇒ 不存在"因为敏感所以只能删"的对象。
3. 唯一的"隐去"是把两份**不随包**的原件留在本机（导出与文档工作区），
   并为它们登记了 SHA-256 与逐行统计——这是**指针 + 摘要**，不是删除。
