## 2. §3.3.4 优化目标

| 指南要求 | 落点与数字 |

| 合理使用片上资源，**不以显著资源代价换有限收益** | 每一条资源增减都记账：#38 那一对收包逻辑 +267 LUT、BRAM **不涨**（厂商 `udp_rx` 的 FIFO 省下来正好抵）；R25 的并行译码省 85 LUT 但**没有**据此声称时序收益；UltraRAM 先把算式写对（9 块 vs 72 tile 同数量级）再谈实验，实验没收口就不写成结论 |

## 4. 还没做到 / 待办（诚实清单）

1. **KU5P 未上板**：指南要求"作品须在板上跑通并提供实测输出"。Z7 满足；第二块板目前只有
   台架 + 门禁证据。**2026-09-23 决定**：这块板**暂停投入**（不做相机、不加新功能），
   保留为"同一套自研栈跨两种器件"的移植性证据；要下的 bit 已备好：
   `ku5p/build/frozen_r26/ku5p_eth.bit`（md5 `14bd5752`；R31 命令通道版是 `5ce3578c`，
   **只走 JTAG，绝不写 QSPI**）。上板窗口由用户安排，验收步骤在 `ku5p/README.md` §8。
2. ~~SD 卡本地播放尚未收口~~ **已上屏**（build#23，用户眼睛确认；串口 30.0 fps 两条独立判据）。
   剩下的不是"能不能放"，而是**切换体验的自动化**：片源仲裁（ISSUES #49）在 #25/#26 上
   门禁全绿，还欠三条眼睛判据（停流交回后画面真的在动 / 并发不闪不抢 / 长按四态轮转且图卡会动）；`#50` 那条读超时**已结案**（09-24 06:4x 前）：根因是 PS 固件把 FAT32 目录项高簇字按大端拼，修完整卡 4398 帧播完并回绕，卡与 FAT 都是好的（凭据 `build/frozen_r32_sdfix/`）。
3. **UltraRAM 帧缓存实验没收口**：2025.2.1 拒绝 `ultramark`/`ultraram` 两种 `ram_style` 拼法并静默退回
   `auto`，量到的 BRAM 仍是 72 tile、URAM 0 ⇒ 结论"工具不会自己为该形状选 UltraRAM"是实测的，
   但"9 块 UltraRAM"目前只是算出来的。要真量需 UG901 的属性名或直接例化 `URAM1240`。
4. **`udp_rx_parser` 的三个统计脉冲没接可读寄存器**（`stat_drop_filt` 等）：端口过滤已进顶层，
   但"被过滤掉的包数"还不是可读数。接不接是独立小决定，没有顺手塞进 #38 那一笔。
5. **`bad` 会动这件事只有台架证据**（`tb_v795_rx_chain` 的 C2）。现场没有可靠的注错手段，
   所以板上只能报"改前是死的、改后有判据"，不报"板上见过它跳"。
6. **不做 MIPI 摄像头（2026-09-23 决定）**：板上那个 15-pin FPC 只引出 CSI-2 两 lane 的三对差分
   （+ `CAM_CLK/SCL/SDA/GPIO`），**没有并行 DVP 数据线**；而 Zynq-7020 与 KU5P 都没有 MIPI D-PHY
   硬核 ⇒ 接相机等于自己写软 PHY（ISERDES + 参考时钟 + lane/字节对齐 + CSI-2 包层 + 传感器初始化），
   是一件独立且失败模式最难查（"收不到对齐码流"）的子工程。本期把**第三源位置用会动的测试图卡占住**
   （`src/rtl/video/test_card.v`），架构、按键切换、优先级回落全部照做；MIPI 写进"未来工作"。
   为什么图卡而不是静止彩条：静止图案分不清"通路在刷新"和"卡在最后一帧"，
   而本作品的核心主张是"宁可掉帧也不让坏帧上屏"，所以第三源必须自己会动、且动得可判读。
7. **仿真器只有一家**（并且**现在只剩这一家**）：ModelSim AE 2020.1 的 `vlib/vlog` 曾可用作第二意见 lint（确实抓到过
   "端口连接里先出现的标识符成隐式 1 bit 网"这类 Vivado 侧看不见的错），
   但 `vsim` 起不来 —— 许可证 `D:\Software\ModelSim\LICENSE.TXT` 是真的、也绑本机 MAC，
   可是它由新版 FlexNet 签发，2020.1 自带的 2019 版客户端判 `inconsistent license key`
   （2026-09-23 复测记录）。**2026-09-24 起本机已没有 ModelSim 安装**（`D:\Software\ModelSim` 不存在，
   PATH 里那条是残留），所以下面这些结论今天**无法**在本机复跑；仓库里可复现的仿真路径只有
   `xsim` 一家（`build/gates.sh` / `sim/`）。这一条要如实写，而不是含糊说"多工具验证"。
