# 选题背景、创新点与前人工作

## 1. 要解决的问题

嵌入式视觉设备里最常见的一个取舍是：显示通路交给处理器，还是交给可编程逻辑。
处理器路线（ARM + Linux + 协议栈 + 显示框架）开发快，但画面要经过 CPU 与内存两次以上拷贝，
延迟与抖动由调度决定；而很多现场要的恰恰是"网线里进来的画面立刻、稳定地出现在屏幕上，
同时还能做几何与滤波处理，并且**当场能判断这帧干不干净**"。

本作品做的是 PL 侧的一条视频通路：接收 → 缓存 → 几何与效果处理 → 显示，不依赖处理器参与数据面；
并且把"稳不稳、对不对"做成板子自己报出来的数字，而不是靠人盯着屏幕判断。

一句话概括取向：**把显示方式本身做成一台测量仪器**。屏幕中线以左是未处理画面、以右是同一坐标系下
的处理结果，逐像素对齐，分割线可以固定、自动扫描、或贴在图像域里跟着旋转缩放一起走。
于是"处理错了一行""边缘少了一列""越界被填黑"这类问题不需要探针、不需要抓图对比，
在同一条扫描线上就能被看见，也能被同一套几何关系算出来。

## 2. 前人做过什么

公开可查的获奖名单显示，这个赛道近两年获奖项目的共同形状是
**"一个具体应用对象 + 一个可量化的硬件能力"**：脑电异常检测（2024 全国一等）、
手语识别 SoPC 的神经网络推理加速（2024 二等）、深度学习垃圾分类（2024 三等）、
2025 年的名单里则直接有"内窥图像处理系统""图像畸变校正系统""机场动物识别与驱鸟系统
（FPGA 预处理 + SoC NPU 推理）""面向 FPGA 的高效算子实现与优化"。
出处见文末链接（各校公开的竞赛通报，只有题目与一句话简介，没有完整技术报告）。

按这个坐标系诚实定位本作品：

- 它**不是**又一个"能播视频 + 能做几个滤波"的作品。同类的实时显示/畸变校正/内窥项目做的是
  "把算法做进硬件"；本作品的重心在**可观测与可复现**——处理结果与原始结果同帧逐像素对照、
  链路健康由硬件自计数、24 项机器门禁 + 判据必须能变红 + 变异检验。
- 厂商例程是真实起点：以太网协议栈那一层（`arp/icmp/udp/eth_ctrl`）来自开发板厂商例程，
  它止于"收发通了"。把它接成视频通路的过程中发现并修掉了它自带的两处缺陷
  （发送仲裁在帧中间换源 = ISSUES #37；`udp_rx_parser`/`gmii_rx_mac` 三处未验证行为 = #38），
  逐文件的"哪些是厂商代码、哪些是自研"标在 `report/log/VERSION_LINEAGE.md`。
- 与 PYNQ 路线的差别是有意选择的：同一颗 XC7Z020，官方生态用 Python/Notebook 驱动 PS 侧；
  本作品数据面完全在 PL，PS 只跑一个几百行的裸机控制面。取舍论证写在 `report/PS_VS_PL.md`。

**边界声明**：上面那份名单来自学校公开发的竞赛通报，不是完整的获奖作品集，也没有做系统的
文献检索（IEEE/CnKI 关键词、往届报告库）。所以本节是"我知道自己参照过什么、同赛道大致在
做什么"，不是"相关工作综述"。补一次真检索仍然欠着。

## 3. 创新点（每条后面跟着能自己核的证据）

1. **同帧逐像素对照显示 = 仪器**。原图抽头用一条行延迟环与处理链对齐到同一拍同一列；
   效果链固定 15 级，混合域延迟 `MIX_D=20` 由常数推导而不是量出来凑的。
   这条设计直接产出了机器可判的结论：`sim/tb_v98_top_seam.v` 的 C 系列判据按"每行只应有一段
   连续画面""每一格应带回它自己的源行号/源列号"这类**形状**来判，不猜坐标；
   历史上它抓到过一条"从视频里切出来贴在屏幕左缘的细线"（ISSUES #102：行环在消隐期读到错列，
   行行都有一格）与一类"缩放碰到分割线时出现的色带"（#68 那族相位错 9 列）。
2. **链路健康做成硬件自计数、三方可对账**：同一组计数器有三个独立出口——OSD 直接印在屏上、
   AXI GPIO 可被 JTAG `mrd` 读回、串口命令可清可读。于是"报告里写 0 丢包"变成"你能自己验证它是 0"。
   板级三态、拔线可逆性、`gapclr` 对账见 `report/log/OVERNIGHT_LOG.md` R08–R10；工具在
   `src/host/health_read.mjs`、`ddr_stale.mjs`。
3. **抗乱序、抗丢包的 offset 拼帧**：每包自带帧内偏移，比"要求按序到达"更适合尽力而为的以太网；
   配三重提交门限（行覆盖位图 ∧ 字节预算 ∧ 无坏包标记），使"丢一包 + 一包重复偏移"这种
   **能被累计字节数伪装成完整**的帧不会上屏。证据：`sim/tb_v6_cover_gate.v`、`report/log/V6_ROOT_CAUSE.md`、
   `skill/runtime/udp-offset-reasm/SKILL.md`。
4. **消隐期内原子提交的 DDR 乒乓 + 拷贝看门狗**：显示侧永远只读一整帧；拷贝赶不上消隐窗口就
   整笔作废并保留上一帧（宁可不动，不可撕裂）。看门狗跨时钟域用翻转式脉冲同步器（#36 的修法），
   判据是相位扫描 30/30。证据：`sim/tb_v79_abort_toggle.v`、`sim/tb_v5_vblast.v`、`report/ARCHITECTURE.md`。
5. **一条可复用的设计规则：窗口类滤波必须做在目标域**。否则旋转与平滑互相打架（转的时候模糊跟着抖）。
   规则被固化为技能条目与台架：`sim/tb_rotate_window.v`、`skill/pitfalls/rotate-window-target-domain/SKILL.md`。
6. **多片源仲裁，而且"谁拥有屏幕"是可机器判定的**。三路（网流 / SD 裸帧 / PL 自生图卡）共用同一台
   DDR→帧缓存搬运机；判据不是"曾经收过包"（那是粘性命，ARP 就触发、拔线不回 0），而是
   "最近真有帧 **且** 量它的那个时钟还准"——后者是板上测出来的物理事实（RTL8211 断链时不停 RXC
   而是拉到 ≈1/48，于是所有 ms 数都是周期数）。换手只发生在两个引擎都空闲时，往 PS 方向带 20 ms 滞回，
   状态从 AXI GPIO 读回。证据：`src/rtl/util/src_arb.v`、`sim/tb_v796_src_arb.v`（29 条，含两条反面
   对照）、ISSUES #49。
7. **第三源刻意做成"会动"的图卡**（移动块 + 帧号二值格 + 梳齿 + 灰阶）：静止图案分不清"在刷新"和
   "卡在最后一帧"，而本作品的核心主张是"宁可掉帧也不让坏帧上屏"，所以测试源必须自带"活着"的证据；
   帧号用 8 个二值格表示 ⇒ 不需要字库，拍一张照就能读出"屏上这帧是第几帧"，丢帧/重复帧变成可核对的数。
   证据：`src/rtl/video/test_card.v`、`sim/tb_v81_test_card.v`（18 条，含"跨帧必须变"与
   "静止彩条跨帧必须完全不变"的成对判据）。
8. **同一套自研收包链曾跨到第二种器件收敛过——但这一条不作为交付主张**。第二块板
   （`xcku5p`，纯 PL 无 PS）确实用同一套链跑通过，移植过程暴露了原设计里两处
   "平时不炸、加周期任务才炸"的并发缺陷（#36/#37），这两处修在本作品的 RTL 里、可判可复现。
   但那块板的工程已于 2026-09-28 从仓库撤出（范围收回到一块板），**本包里没有它的 bit、报告与台架凭据**
   ⇒ 读到这里不要把它当成可复核项；能复核的是"那两处缺陷的修法"，不是"跨器件收敛"这件事本身。
9. **可复现性本身做成工程**：一条命令跑 24 项门禁（两个整屏台架 + 时序/资源/端口/CDC + 五把文档检查器，含行号锚点与首页数字对账），
   台架报告与 RTL 按 md5 绑死；判据要求"能变红"（每条结论配一条"这一格到底有没有样本"的地板判据，
   以及一条正对照）；修改要有变异检验（把修复 revert 掉应当**正好**红一条）。
   证据：`build/gates.sh`、`sim/run_one.sh`、`src/host/*.mjs`（这些检查器自己也带 `--self`）。

## 4. 应用价值（不夸大的版本）

适合"网线一头是算力或相机、屏幕一头是人"的展示与调试场景：机器人/无人机图传的落地显示、
多路视频墙、工业检测与内窥类设备的即时回看。价值点在**可观测性**——画面出问题时能当场区分
是链路问题、几何对齐问题还是显示问题，而且区分依据是板子报出来的数，不是主观判断。

**明确不做的**（每一条是取舍，不是遗漏）：

- 不做 H.264 等编码与多路并发解码（SD 源播的是 PC 预转换的 512×300 RGB565 裸帧）。
- 不做网络抗弱网/重传：做的是"尽力而为网络下的丢包检测 + 坏帧不上屏"，不是纠错。
- 不做 MIPI 摄像头接入：这颗 Zynq-7020 没有 D-PHY 硬核，板上那个 FPC 只引出 CSI-2 差分对
  （没有并行 DVP 数据线）⇒ 接相机等于自写软 PHY，是一件独立且失败模式最难查的子工程。
  第三源位置先用会动的图卡占住（第 3 条），架构与切换逻辑都是真的，只有传感器是空的。
- 不跑 AI 推理：本作品的资源全部花在通路、时序与可观测性上，与"加速一个网络"类选题不在同一轴上竞争。
