## 5. 答辩备问

| 问题 | 可答要点 |
|------|----------|
| 为何网口送视频？ | 赛题方向；PS 协议、PL 像素，分工清晰 |
| 为何 512×300？ | BRAM/带宽余量；再高卡片上存储 |
| 旋转如何与窗滤共存？ | 目标域 3×3，见 PS_VS_PL / ROTATION |
| UDP 如何保序？ | 包头 offset |
| 拖影如何处理？ | 边收边写 BRAM；双缓冲资源不够；可后续优化 |
| EMIO 为何不用？ | 本板读回异常，改 AXI GPIO |
| CPU 占用？ | 数据面全硬件，PS 仅 UART |
