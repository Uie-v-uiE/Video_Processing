# 旋转、效果与缩放（第三版）

## 1. 组合能力

| 能力 | 说明 |
|------|------|
| 旋转 0–359° | 左右窗均可（右窗在缩放后叠加） |
| 效果五级 | gray / binary / blur / sobel / invert |
| 右屏缩放 | 1.0×（最大）↔0.5× 循环 |
| 组合 | 旋转 × 效果 × 缩放可同时开；源选择独立 |

**效果显示位置：** 右窗（缩放后画面）。左窗为原图（可旋转），便于对比。

---

## 2. 目标域窗滤

原先 `angle≠0` 时旁路 blur/sobel，因误在源图邻域取窗。

**现行：**

1. 屏幕坐标 →（缩放）→（旋转）→ 源像素  
2. 沿右窗光栅得到的数据流 = 显示域图像的扫描序  
3. blur/sobel 用 **右窗 cx/cy** 建 3×3 行缓  
4. `rotate_active` 只作状态，不再强制 bypass  

```text
源像素(映射后) → 点运算 → 目标域 3×3 → 右窗输出
```

实现：`src/rtl/process/proc_pipeline.v`  
仿真：`sim/tb_rotate_window.v`

## 3. 无极缩放

| 项 | 值 |
|----|-----|
| inv_scale Q8 | 256=1.0× 最大，512=0.5× 最小 |
| 循环 | 每帧 STEP=2，三角波 |
| 锚点 | 图像中心 |
| 越界 | oob 黑边 |
| 默认 | PL 常开（`zoom_en=1`） |

映射（无旋转）：

```
sx = W/2 + ((x - W/2) * inv) >> 8
sy = H/2 + ((y - H/2) * inv) >> 8
```

与旋转叠加时，先缩放偏移再套 Q8 旋转公式（inv=256 时与纯旋转一致）。

---

## 4. 数据通路关系（v3）

```
左窗: cx,cy → rotate → FB → 原图显示
右窗: cx,cy → zoom [→ rotate] → FB → 效果链 → 右窗显示
```

FB 单口按 `left_pane` 时分选择地址。

---

## 5. 金标 / 仿真注意

- 与 Python 比对：先几何变换（缩放/旋转）再窗滤，或统一到目标域定义  
- `tb_zoom_mapper`：1.0× 恒等、0.5× 中心与 OOB、控制器三角波  
- 效果在右窗：比对时勿假设效果在左窗 line_cache 路径

## 6. 串口与显示

| 命令 | 显示 |
|------|------|
| `10000` | 右窗灰度（仍在缩放循环中） |
