# 旋转与效果关系

## 结论（重构后）

| 角度 | gray | binary | blur | sobel | invert |
|------|------|--------|------|-------|--------|
| 0–359° | ✓ | ✓ | ✓ | ✓ | ✓ |

## 架构说明

原先在 `angle≠0` 时强制旁路 blur/sobel，是因为曾按**源图扫描邻域**理解 3×3 窗口。

**现行方案（目标域处理）：**

1. 屏幕坐标逆映射取源像素（任意角）  
2. 得到的流是**旋转后图像**的光栅序  
3. 窗口滤波用 **屏幕 x/y** 建行缓，对旋转后图像做 3×3  
4. 点运算与窗口运算在同一目标域级联  

因此 blur/sobel 与旋转**可组合**，`rotate_active` 仅作状态指示，不再强制 bypass。

实现：`rtl/process/proc_pipeline.v`  
仿真：`sim/tb_rotate_window.v`  
OOB 仍填黑，效果后强制黑边。

## 金标对比注意

与 Python 金标比对时顺序应为：**先旋转再窗滤**（或按目标域定义），勿再按「先源域滤波再旋转」。
