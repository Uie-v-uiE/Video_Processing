这一版把用户 2026-09-24 晚报的右窗两条现象里**机器能修的那一半**修掉了，并且把三处
"看着绿其实没判/没生效"的洞一起补上。四件事：

1. **#54 (A′) 抽头与边界约定统一**：`proc_sobel` 的旁路从 `din` 改回**窗口中心抽头**
   （加了一条与 `lb1` 同步的原色行缓存 `mc1`，写法照 `proc_morph`），它那个 `+2 列` 特例随之消失；
   四个窗口级的边界守卫改成**一根跟着有效像素移位的 3 位旗标链**
   （深度是量出来的：让台架回读"发出槽位 0 那一拍"的 `x_in`，四个模块都报 3 ⇒ 3 个有效像素）。
2. **#54 (A″) 级间坐标**：`proc_pipeline` 以前把顶层的 `x_in/y_in` **一份喂四级**，
   而每级的数据比顶层晚若干拍 ⇒ 行缓存按"后面那个像素的列号"写。
   修法是给坐标加一条与 de 同节奏的延迟线，抽头 2 / 5 / 8 / 12（= 前面各级深度之和），
   代价 312 个触发器、零 BRAM。
3. **#54 (B) 读侧补偿**：`proc_pipeline` 声明 `OFF_LINES = 4` 并用输出口 `off_rows` 报给顶层，
   顶层 `cy_r = clamp((y + OFF_LINES) >> 1)` **只喂右窗的 mapper** ⇒ 左右两窗同一行内容、
   缩放/旋转时右窗不再串位。帧缓存是随机地址，所以"提前读"不花缓存。
4. **#59 快照口**：`frame_latency` 加 `arm` + 一组 `q_*`，`system_top` 用"lane 选到 25"武装；
   读回口从此给**同一拍抄走的一组**，恒等式 `tot ≥ c1 + c2` 在板级必须成立。
