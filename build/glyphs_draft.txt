# ASCII → 索引的映射（`glyph_idx()` 仍然是**一个 case 平铺**，不许写区间比较：
# V7.9.4 那一次就是 `c >= 0x30 && c <= 0x39` 串成 27 级链成了全设计最差路径）：
#   0x30..0x39 → 0..9
#   0x41..0x5A → 10..35 里已有的那 17 个大写保持原索引；**没画的大写**落到 63（空格）——
#     四行格式里出现的大写只有 F P S E T H G R Z L A U D I N O M C V W Q X 之外暂不补，
#     补的时候接在 50 之后，别回头改已用的。
#   0x61..0x7A 小写：a c e i l m n o p r s t u x y → 上表的号
#   0x3A ':'  0x2E '.'  0x25 '%'  0x28 '('  0x29 ')'  0xDF '°'
#   0x2A '*' 已在 26、0x3D '=' 已在 27（老 OSD 行还在用，V8-5 收尾时如果不再用再清）

#   tb_v794_osd_glyph：金表从 32 项扩到 64 项，**逐项**核 ASCII→号；
