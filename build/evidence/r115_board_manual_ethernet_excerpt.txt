一 开发板简介 
RK-ZYNQ7020-F 开发板采用 Xilinx 公司的 Zynq7000 系列的芯片，型号为 XC7Z020-
CLG484-2。ZYNQ7020 芯片可分成处理器系统部分 Processor System  PS） 和可编程逻辑部
分 Programmable Logic PL）。 
采用整版设计，扩展了丰富的外围接口，包括 DDR3、EMMC、QSPI、板载 JTAG+UART
合一、SD 卡、USB2.0 HOST/SLAVE、PS 千兆以太网、PL 千兆以太网、RS485x2、FMC(LPC)、
CANx2、HDMI、MIPI、EEPROM、RTC、SPI LCD、40PIN IO、 PS LED KEY、PL LED KEY。

1.1 ZYNQ 
开发板使用的是 Xilinx 公司的 Zynq7000 系列的芯片，型号为 XC7Z020-CLG484-2。芯
片的 PS 系统集成了两个 ARM Cortex™-A9 处理器，AMBA®互连，内部存储器，外部存储
器接口和外设。这些外设主要包括 USB 总线接口，以太网接口，SD/SDIO 接口，I2C 总线接
口，CAN 总线接口，UART 接口，GPIO 等。PS 可以独立运行并在上电或复位下启动。ZYNQ7000
芯片的总体框图如下所示： 
 
其中 PS 系统部分的主要参数如下： 
• 基于 ARM 双核 CortexA9 的应用处理器，ARM-v7 架构 高达 1GHz 
• 每个 CPU 32KB 1 级指令和数据缓存，512KB 2 级缓存 2 个 CPU 共享 
• 片上 boot ROM 和 256KB 片内 RAM 
• 外部存储接口，支持 16/32 bit DDR2、DDR3 接口 
• 两个千兆网卡支持：发散-聚集 DMA ，GMII，RGMII，SGMII 接口 
• 两个 USB2.0 OTG 接口，每个最多支持 12 节点 
• 两个 CAN2.0B 总线接口 
• 两个 SD 卡、SDIO、MMC 兼容控制器 
• 2 个 SPI，2 个 UARTs，2 个 I2C 接口 
• 4 组 32bit GPIO，54 32+22）作为 PS 系统 IO，64 连接到 PL 
• PS 内和 PS 到 PL 的高带宽连接 
其中 PL 逻辑部分的主要参数如下： 
• 逻辑单元 Logic Cells：85K； 
• 查找表 LUTs: 53,200 
• 触发器(flip-flops):106,400 
• 乘法器 18x25MACCs：220; 
• Block RAM：4.9Mb； 
• 两个 AD 转换器,可以测量片上电压、 温度感应和高达17 外部差分输入通道，1MBPS

1.7 USB2.0 HOST/SLAVE 
开发板有 1 个 USB2.0 HOST /SLAVE 接口，USB2.0 收发器采用的是一个 1.8V 的，高速
的支持 ULPI 标准接口的 USB3320C-EZK 芯片,ZYNQ 的 USB 总线接口和 USB3320C-EZK 收
发器相连接，实现高速的 USB2.0 Host 模式的数据通信。USB3320C 的 USB 的数据和控制信
号连接到 ZYNQ 芯片 PS 端的 BANK501 的 IO 口上。24MHz 的晶振为为 USB3320C 芯片提
供系统时钟。 
USB 接口为扁型 USB 接口(USB Type A 和 TYPEC)，方便用户同时连接不同的 USB Slave
外设(比如 USB 鼠标和 USB 键盘），也可使用 TYPEC 连接主机。另外开发板为 USB HOST 接
口提供了+5V 的电源。 
 
1.8 千兆以太网 
 开发板有 2 路千兆以太网接口，1 路连接到 PS 端， 另1 路连接到 PL 端。PHY 芯片采用
REALTEK 公司的 RTL8211F-CG 以太网 PHY 芯片为用户提供网络通信服务。RTL8211F-CG
芯片支持 10/100/1000 Mbps 网络传输速率，通过 RGMII 接口跟 ZYNQ7020 系统的 MAC 层
进行数据通信。

3 使用串口终端测试 
使用串口终端测试前，请先关闭测试程序，避免端口占用的情况： 
ps |grep qt 
kill 569 
 
3.1 ETH 测试 
 开发板在 PS 侧和 PL 侧各有一个网口。 
测试时网口需连接至带有 DHCP 服务的主机或路由器。 
查看系统中的所有网络设备，eth0 为 PS ETH，eth1 为 PL ETH： 
 ifconfig -a 
 
两个 ETH 默认已开启，并连接至具有 DHCP 服务端功能的主机，开机后也可使用以下
命令通过 DHCP 使相应网口获取地址：  
udhcpc -i eth1

 下面将使用 iperf3 测试网口速率 
  1）将 windows 防火墙关闭 
 
  2）下载网盘中的 iperf3 工具，并解压至磁盘中 
 
 
 3）测电脑下发到开发板的速率：  
开发板作为服务器端，电脑作为客户端进行测试。在开发板串口终端中执行以下命令：  
iperf3 -s

在电脑的 cmd 命令提示符中执行以下命令： 
cd /d D:\iperf-3.1.3-win64  
iperf -c 192.168.1.100  
 
执行上面的命令共打印出了 10 次带宽测试报告，每一秒钟报告一次带宽，耗费时间为
10 秒钟；平均带宽表示 10 次带宽报告所得出的平均值，包括上传带宽 sender）和下载带
宽 receiver）。 
注：此处的带宽值跟电脑有关，不同的电脑值有差异，一般大于 500Mb/s 即可。 
由此可以知道开发板上的 PS 网口是千兆以太网接口  1000Mbits > 带宽 > 100Mbits）。 
测试完成后，在串口终端中按“CRTL+C”结束 iperf3。 
 4）测开发板上传到电脑的速率：  
电脑作为服务器端，开发板作为客户端进行测试。在电脑的 cmd 命令提示符中执行以
下命令：  
iperf3 -s 
 
然后在开发板的串口终端执行以下命令：  
iperf3 -c 192.168.1.111
