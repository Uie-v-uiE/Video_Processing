判据（六条，逐场景各打一行）
  C1 每腿字节数 = 54 + max(len,18) 的解析式（8 前导 + 14 以太 + 28 IP/ICMP 头 + 数据 + 4 CRC）
  C2 两腿逐字节对账（真正的等价判据）
  C3 改前流的非零字节地板（防台架空转）
  C4 每场景 IP 校验和两字段不许全零（证明被动的那个锥真被驱动过）
  C5 tx_done 计数 = 场景数、无超时
  C6 打印的散列相同性必须与逐字节结果一致（旁证自洽）

C6 抓到的是我自己写坏的旁证（已修，记下来防复发）

  任何一处差异必然留到末尾。改后腿 b 两值同、腿 c 三场景两值全不同（380837a4 / 64383590 / 2463ec8a）。
