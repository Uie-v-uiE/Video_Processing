# 尺子的假绿：九种名不副实的 PASS

## 适用场景

- 判据输出了 PASS，而你对被测量的结果存疑或预期对不上。
- 一条"出生以来从未红过"的判据要被拿去签收。
- 收紧或放宽阈值之后，只有测试跑过、真件没重跑。
- 不适用：判据还没写的时候——先造尺子，再来审尺子。

## 使用方法

**先查什么**：先查尺子自己印出的数（结论行末位判定词、"判 N 项"的比较次数、实际扫到的样本数），再查它读的件（盘上文件的归属与修改时间）；一手顺序=件原文＞尺子 stdout＞记忆。**先跟用户确认**：想豁免一项、调一个阈值、改判据口径——尺子的任何改动必须显式申报，不许暗改。

审绿总则：**见绿先问三个数**——比较了几次（0 次⇒假绿）、扫到几个样本（0 个⇒空集）、判定词是从哪一行取的（取错行⇒我的解析错）。尺子自身报异常却仍打出 PASS⇒工具报错未截停，先修退出路径再看内容。空集、读不到、解析失败一律记 NOT_MEASURED。

### 坑一：空集上判通过

- 触发条件：比对清单被过滤成 0 条（名字改版、路径变化、名单清空）。
- 现象/一眼假绿：PASS 且"判 0 项"，或全程无逐项行只有总结论。
- 排查步骤：1) 读"进入比对的样本数"：0⇒空集，从源头名单重算应扫条数；2) 样本数>0 而比较数=0⇒我的解析错，拿一条已知会存在的项做正对照测提取层；3) 尺子输出里有异常文本而退出码 0⇒工具报错未截停；4) 把空集分支改成 NOT_MEASURED 复跑，结论应由绿变未测——不变说明还有别的默认绿路径。
- 根因分类：收尾逻辑把"没比"当"比过且通过"。
- 修法：比较数为 0 强制 NOT_MEASURED；门禁场景再叠非 0 退出。
- 预防：结论行必带计数；判据验收含"清空清单应出未测"演练。

### 坑二：仿真里的 X 被当 0

- 触发条件：比对或聚合的读数含 X/Z；数组元素默认 X、标量默认 0——两者语义不同，未初始化在结果上看不出来。
- 现象/一眼假绿：绿了但 DUT 从没动过；提取结果里 x 字符消失。
- 排查步骤：1) 读原始波形/日志里该值的形态：有无 x/z；提取输出与原文不一致⇒我的解析错（被转字符串折成 0）；2) 给比对器加"含 X 项计数"打印：原文有 X 而计数 0⇒X 被吞；原文无 X 而计数非 0⇒提取层抓错件；3) 强制造一个输出为 X 做变异对照：判据不红⇒无效；仿真/编译本身报错⇒工具报错，先修运行。
- 根因分类：非法符号被静默折算；未初始化数组与未初始化标量的默认值本就不同。
- 修法：X/Z 在比对中记 NOT_MEASURED 或 FAIL；期望清单写明该项是否允许未初始化。
- 预防：数值提取层保留非法符号原样上送，禁止解析层填 0。

### 坑三：两个不同单位的数相减，残差被钉成常数容差

- 触发条件：判据写成 `abs(a-b)<K`，而 a、b 维度不同（一个周期数一个时间量），K 抄自某天的残差。
- 现象/一眼假绿：稳绿；一改频率或换个工况就红（或反向地永不红）。
- 排查步骤：1) 给公式两项各标单位：标不上或不同维⇒维度错实锤；2) 缩放重跑（改时钟频率或等比放大数据）：绿随绝对残差走⇒维度错；3) 先排除空集（比较数>0）再讨论真伪。
- 根因分类：这个绿证明的是维度错，不是被测对象好。
- 修法：先化同维再比（都折成周期或都折成单位时间），容差由维度推导而非钉常数。
- 预防：容差必须带"从哪推出"的注释；不同维相减当错误拦下。

### 坑四：射程静默变窄

- 触发条件：手写文件清单（目录加深即漏）、解析层少剥一层、被测对象改名；`--self` 照旧绿。
- 现象/一眼假绿："通过数下降"被读成"变差"；真相常是总条数同降——扫少了，通过率没动。
- 排查步骤：1) 读本轮"覆盖条数/进入比对数"，与按生成规则重算的期望数对质：不等⇒射程变窄；2) 塞一条已知该扫到的件进树再看是否出现：不出现⇒清单/提取层少一件；3) `--self` 绿而覆盖降⇒尺子逻辑没错、射程错——这是自测盲区；4) 查文件清单的 glob 是否递归深目录（递归参数错⇒清单侧失效）。
- 根因分类：清单层/提取层与判定层解耦，收窄只体现在计数上。
- 修法：清单由目录规则生成而非手写；把覆盖数当硬判据项。
- 预防：射程变化必须列显式原因；呈现时把总数与通过数并排对比。

### 坑五：正对照永远不动

- 触发条件：配了变异对照但从未验证过它能红；或判据设计成不可红。
- 现象/一眼假绿：一条判据自建立以来全绿。
- 排查步骤：1) 人为破坏被测量（翻一位/删一行）重跑：应红；2) 仍绿⇒核对尺子读的路径与你破坏的是否同一份件（读修改时间定归属）；3) 变异命令自身报错⇒工具报错，不算判据问题；4) 确实无对照可配的判据，明标"未配对照"。
- 根因分类：对照只证明了"跑过"，没证明"能红"。
- 修法：每条判据配变异对照，并留档那次红的读数。
- 预防：判据验收=一次红演示，没有不签收。

### 坑六：豁免名单按被测对象作键

- 触发条件：豁免记的是"豁免某信号/某条目名"，该名字在别的用例或别的对象下重现。
- 现象/一眼假绿：新用例的失败被老豁免静默吸收；豁免条数不随用例增删而变。
- 排查步骤：1) 读豁免命中打印（命中在哪条用例、哪期期望上）：跨用例命中⇒买通；2) 临时撤一条豁免重跑：绿不变⇒该豁免本就无效；变红⇒核对它该挂的期望侧；3) 无命中记录⇒豁免在空转，顺带检查射程。
- 根因分类：键在被测侧而不是"用例+期望项"侧。
- 修法：豁免按（用例，期望项）作键，并打印每次命中的对象。
- 预防：豁免限量、带原因与失效期。

### 坑七：检查器输出落在被检查的树里

- 触发条件：尺子的报告写到被"目录清洁/文件不变"类检查覆盖的位置。
- 现象/一眼假绿：第二次跑因第一次的输出而红；或每轮运行后树里多改一次"自己"。
- 排查步骤：1) 展开检查的文件清单，对质是否含尺子自身输出；2) 把输出重定向到树外重跑：由红转绿⇒自指坐实；仍红⇒另有真实变化；3) 尺子运行报错⇒工具报错，与自指无关。
- 根因分类：检查器成了被检对象的一部分。
- 修法：输出目录与被检树分离，或在清单里显式排除自身产物。
- 预防：目录约定把报告落点定在被检树之外。

### 坑八：判定词不在行尾，被中途文本误匹配

- 触发条件：解析规则是"行内含 PASS 字样即算结论"；说明文、字段名或对照名里也含这个词。
- 现象/一眼假绿：结论行数比用例数多；某轮的绿来自一句人读的文本。
- 排查步骤：1) 打印全部命中行，看被取用的是哪条；2) 改成"结论行最后一个字段为判定词"再跑：结论翻转⇒此前是误匹配；3) 末位取不到三态词⇒记 NOT_MEASURED，禁止默认绿；4) 格式变了导致解析失败⇒我的解析错，先重探形状。
- 根因分类：用模糊包含代替结构化取字段。
- 修法：判定词固定行尾、字段分隔符固定；解析断言"恰有一条结论行"。
- 预防：结论行由统一格式化函数生成，不逐条手写。

### 坑九：收紧判据后只跑测试不跑真件

- 触发条件：改了阈值或判据逻辑，跑了尺子的单元测试（夹具全过）就收工。
- 现象/一眼假绿：测试绿≠真件在新阈值下还绿，而没人重跑真件。
- 排查步骤：1) 列出本判据适用的真件清单，逐件核对新阈值下的结论行是否带新时间戳：缺⇒未重测，记 NOT_MEASURED；2) 夹具过而真件缺读数⇒只证明了提取层逻辑，没证明实测值；3) 真件跑出解析失败⇒我的解析错，不等于真件红。
- 根因分类：夹具与真件覆盖面不同，判据变更的冲击只在真件上可见。
- 修法：判据收紧触发全量真件重跑，跑不完就把该项标未测。
- 预防：阈值改动的提交必须附"重跑清单+读数"件。

## 失效条件

- 尺子什么都不印（无比较数、无样本数）时，"看数"总则退化为"先补打印再审"；征兆是输出里找不到任何计数行——此时别拿本条当"已审过"的依据。
- 变异对照若直接改共享产物目录，会制造证据竞态（pitfalls/build-artifact-races 一族）；在隔离副本上做。
- "存在性检查"类判据天然难配变异对照，别为凑对照制造假红；明标未配对照即可。
- X 的默认语义与语言/仿真器设置有关（有的可改默认初值），照抄坑二前先实测你所用版本的行为。
- 本条审尺子不审被测物：判据全部真红且红得一致时，问题在被测对象一侧，别继续在尺子上找。

## 已验证效果

未量过，属建议。可自查读数：比较次数为 0 的 PASS 条数（应为 0）、配变异对照的判据占比、判据变更后带新时间戳的真件读数数（应等于适用件数）。

## 来源

长自一类观察：0 条比对被打成通过；未初始化数组的 X 被折成 0 后比绿；两单位相减的残差被钉成容差；手写清单随目录加深失效、自测全绿而真实射程已红；从未发红的正对照；豁免按被测名作键串到别的用例；检查器把自己的输出写进被检树；说明文本里的判定词被误匹配；收紧阈值后只重跑了测试。相邻条目：verify/checker-selftest、verify/three-state-verdicts、verify/mutation-controlled-coverage、pitfalls/build-artifact-races。
