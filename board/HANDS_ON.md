> 用途：这一份不是"演给评审看"的顺序（那在 `report/DEMO_SCRIPT.md`），而是**你自己把每个功能都用一遍**，
> 每行都写了"串口该回什么、屏上该看到什么、看到的若是别的就对应哪条已知问题"。
> 命令逐字取自两处有凭据的地方：`board/cmd_battery_v81.txt`（99 条在当前 elf 上 99/99 PASS）
> 与 `report/COMMANDS.md`（语法唯一出处）。**大小写不敏感**，回车结尾。
>
> 板子上现在跑的是 **r78**（bit `a0bbe1c8e857` / elf `926565342970`）。r79（时序/资源那轮）正在构建，

## 1. 三路片源与仲裁

| 命令 | 串口应回 | 屏上应看到 |
|---|---|---|
| `src 0` | `[SRC] … mode=2` | 片内**测试图卡**：底色渐变 + 一个移动块 + 一排帧号二值格在跳 |
| `src 2` | `[SRC] … mode=3` | SD 卡视频开始播；`[SD] frame N: last 100 frames 29.9xx fps` 每 4 秒一行 |
| `frame 100` | 回显帧号 | 画面跳到第 100 帧附近（内容跟着换 = 通路真的在刷新，不是定格） |
| `stop` → `play` | 各自回显（**没有 `pause` 这个动词**，停是 `stop`，119 行语法表） | 停住 / 继续 |
| `sd` | `[SD] FAT32 part_lba=… frames=… fps=… files=…` | 不改画面 |
| `sd files` / `sd file 1` | 列出每段首帧 / 跳出全局帧号 | 换到第 2 段 |
| `sd file 99` | **明确拒绝**且不改状态 | 无变化 |
| `src 1` | `mode=1` | PC 没推流时是**黑/占位**（正常：有流才优先网络） |
| `src auto` | `mode=0` | 交回自动仲裁 + 按键轮转 |

**只有你手能测的两条**（放最后，见第 10 组）：拔网线/插回、拔 SD 卡/插回。

## 2. 无极缩放

| 命令 | 应看到 |
|---|---|
| `zoom 0.25` → `zoom 0.5` → `zoom 0.75` → `zoom 1.0` | 画面连续变小/变大；屏上 `ZOOM:` 那一格写的是**实际生效倍率**（`0.25x…1.00x`） |
| `zoom 1.33` → `zoom 1.5` → `zoom 2` | 2.0× 时只看到约四分之一幅，但边缘**不糊**（第 5 组再对照） |
| `zoom off` / `zoom on` | 关/开缩放（注意：`zoom 1` = **开**，要 1.00× 必须写 `zoom 1.0`） |
| `zoom auto` | 呼吸档自己来回变；`ZOOM:` 那格跟着动 |
| `zoom fit 1` / `zoom fit 0` | 开/关"按角度自动收进屏内"（第 3 组配合看） |

已知未修：缩小档屏最左那条细线（**#102**，已钉在原图抽头那一路，晚上修）。

## 3. 旋转

| 命令 | 应看到 |
|---|---|
| `rot speed 1` | 串口回 `speed=1 度/帧`（=60°/s） |
| `rot auto 1` | 开始转；**固件会顺带把缩放切到 fit**（回显里明说），`ZOOM:` 跟着角度变 |
| `rot auto 0` | 停在当前角度——但**串口读不到角度**（**#101**），要看屏上 OSD 的 `ROT:` 格 |
| KEY1 / KEY2（板上按键） | 每次 ±1°（想停在指定角度只有这条路） |
| `split follow 1` + `rot auto 1` | 那条分割标记线**跟着画面一起转**（缝量在图像列里） |
| `rot speed 9` / `rot auto 2` | 越界**必须拒**并说不认；`rot show` 念当前 auto/speed |

已知未修：大角度时角点戳出屏幕 + 对角方向出现宽彩条（**#93**，你说过先记不修）。

## 4. 五级效果链（九种算法）

**位序先看这条**（写错的后果是"你以为在看灰度，其实开了膨胀"）：`pipe` 的九串里
**最左边那一个字符 = bit0**，位定义出自 `src/rtl/process/proc_pipeline.v` 的文件头：

| 位 | 算法 | 单独开它的那一串 | 回显应是 |
|---|---|---|---|
| [0] | 灰度 | `pipe 100000000` | `sel=001 生效: gray` |
| [1] | 反色 | `pipe 010000000` | `sel=002 … invert` |
| [2] | 3×3 模糊 | `pipe 001000000` | `sel=004 … blur` |
| [3] | 3×3 锐化 | `pipe 000100000` | `sel=008 … sharpen` |
| [4] | Sobel 边缘 | `pipe 000010000` | `sel=010 … sobel` |
| [5] | 二值化 | `pipe 000001000` | `sel=020 … binary` |
| [6] | 判决反相（只在 [5]=1 时有意义） | `pipe 000001100` | `sel=060 … 两个名字` |
| [7] | 腐蚀 | `pipe 000000010` | `sel=040 … erode` |
| [8] | 膨胀 | `pipe 000000001` | `sel=080 … dilate` |

| 命令 | 应看到（屏 + 串口） |
|---|---|
| `pipe 000000000` | 原图；`sel=000`（先照这张拍一屏当基线） |
| 上面那一列逐条敲 | 屏上的变化要**与名字对得上**：`gray` 变黑白、`invert` 负片、`blur` 发糊、`sharpen` 边发硬、`sobel` 黑底亮边、`binary` 二值块、`erode/dilate` 在二值底上分别"吃瘦/胖一圈" |
| `th 60` → `th 200` | 二值化判决阈值变 ⇒ 黑白面积当场变（`th` 只在 binary 开着时看得见） |
| `pipe 000000011` | **两个形态学都不做**（开/闭要两遍 3×3 窗口）⇒ 屏上应回到"没有形态学"的样子，`PIPE:` 那一格给 **0 而不是 3**（这条不是缺陷，是明说过的语义） |
| `pipe show` | `[PIPE] sel=… 生效: 名字…` |
| `pipe 00001`（五位老写法） | **拒绝且一个位都不写**，并回给你等价的九位串 |
| `pipe 00000000`（八位） | 明确拒绝（只认九位） |

## 5. 双线性插值 A/B

| 命令 | 应看到 |
|---|---|
| `zoom 1.5` 然后 `bilin off` ↔ `bilin on` 来回 | 斜边在"硬台阶 ↔ 软过渡"之间**当场**切换（固件的 `bilin show` 自己写着"看得出的条件：角度=0 且**倍率非整数**"） |
| `zoom 2` / `zoom 1.0` 后来回 | **看不出差别才是对的**：整数倍率时每个源像素占整数个显示像素 ⇒ 小数权重 `frac=0` ⇒ 插值按构造逐位等于最近邻（`tb_v101` 的 L5 用 4088 格钉住）。旧版这份清单原来写的是 `zoom 2`，2026-09-27 用户照做后报"没区别"——那是**我档选错了**，不是功能坏 |
| `bilin show` / `bilin 2` | 念当前状态 / 第三态必须拒 |

## 6. Gamma

| 命令 | 应看到 |
|---|---|
| `gamma 1.8` | 中间调压暗；`GAMMA:` 那格变 1.80 |
| `gamma auto 100 300 20 2000` | 在 1.00..3.00 之间来回扫，屏上数字跟着走（参数是 **γ×100 的整数**） |
| `gamma auto 1.0 3.0 0.2 2000` | **必须拒**（说要 γ×100 的正整数） |
| `gamma manual` / `gamma off` / `gamma show` | 停在当前值 / 逐位旁路（表保留）/ 念当前 |

## 7. 同帧 A/B 分割线

| 命令 | 应看到 |
|---|---|
| `split 50` | 屏正中一条缝：**左半=原图抽头，右半=处理后**（同一帧同一坐标，不该有错位） |
| `split 20` → `split 80` → `split 0` / `split 100` | 缝平移；`0`/`100` 时整屏只剩一路（**这是判断"某条带属于哪一路"的正规手段**） |
| `split marker 0` / `1` | 那条 2 px 标记线关/开（`split show` 里的 `marker=` 才是真相） |
| `split swap 1` / `0` | 左右两路互换 |
| `split px 512` / `split px 9999` | 按列设缝 / 越界必须拒 |
| `split video` / `split screen` | 缝量在**画面里**（跟着旋转走）/ 量在**屏幕里** |
| `split auto` + `split range 20 80` | 缝自己来回扫，端点按你给的区间 |
| `split show` | 念 `pos=…/1024`、百分比、manual/auto、marker 状态 |

已知：**`split <百分比>` 会把 marker 重新武装**（**#100**）——所以每次比完画面边缘，先看
`split show` 的 `marker=` 是不是被你间接改掉了。

## 8. 温度 / 阈值 / OSD

|---|---|
| `temp` | `[TEMP] degC=… raw=0x… vccint=…mv th=85C over=0 sane=1 osd=…C gpio=0x…`（三方一致） |
| `temp th 60` | 冷板也可能 `over=1`（证明 `over` 是比出来的，不是抄来的）——**屏上不变色、不变数字**：`osd_overlay.v` 只吃 7 位 BCD 的 `temp_disp`，没有 `over` 输入（这一条 2026-09-27 更正，旧文档写的"屏上变色"是假承诺） |

## 10. 只有你能做的最后两件事（约 40 s）

1. **拔网线再插回**（如果第 1 组 `src 1` 时 PC 在推流）：停推流 = 拔线等价 ⇒ ≤0.5 s 画面自己回到 SD，
   `SRC:` 那格跟着改口，串口说清它为什么让位。
2. **拔 SD 卡再插回**：拔 → ≤0.5 s 落到 `SRC:TEST`（图卡在动）+ `[SRC] PS 停心跳…`；
   插回 → 每 2 s 自动试重挂，成功打 `[SD] 卡回来了：自动重挂 ok（试了 N 次），继续回放`。
   **这一步排在整场最后**：中间那几秒屏上是图卡，后面要用 SD 的对照就得等它恢复。

## 11. r80 那一刀该看的那一眼（左缘细线，约 30 s）

机制（量出来的，不是猜的）：原图抽头那条行环在每行**第一格**摆的是"消隐期地址读回来的格子"
（实测 = 源列 160 那一档的内容），所以屏最左一列看着像"从画面里切出来贴在边上的一条线"。
改法 = 行环在掉进消隐那一拍预读下一行第 0 列，只换行首那一格，中间每一列一个比特都没动。
机器那一半已经绿：模块台架 T7（含变异对照，只有 T7 红）+ 顶层新增 **C8**（本体行第 0 列，两路各自判）。

**为什么还要你的眼睛**：台架喂的是 DDR 片源（`fb_vis` 一直是 1），**图卡那一路没有任何面板级判据** ⇒
这一眼只能在 `src 2`/`src 1` 之外，用 `src 0`（PL 自绘图卡）补上。

| 步 | 命令（行尾 CRLF，一条一行发） | 该看到什么 | 如果不对 |
|---|---|---|---|
| 1 | `src 0` | `[SRC] mode=…` 回到图卡 | 没回到图卡 ⇒ 先 `src auto` 看第 1 组 |
| 2 | `zoom 1.0` | 图卡铺满全屏 | — |
| 3 | `split 100` + `split marker 0` | 整屏 = 原图抽头；**最左那一列不该再是一条与画面内容无关的亮线** | 仍在 ⇒ 是图卡那一路，另开条目（台架判不到它） |
| 4 | `split 0` | 整屏 = 处理抽头，同一列应一致 | 只在某一边有 ⇒ 说清是哪一边，这条最值钱 |
| 5 | `split 50` | 缝左右各一半，看那条线**跨不跨缝** | 跨缝 ⇒ 与抽头无关，我前面的归因就错了 |
