# 全量问题台账（all 分支归档）

本目录是 `main` 分支 `report/issues/key-issues.md`（精选 20 条）对应的全量过程台账，放在全量资料分支 `all` 上公开归档；`main` 只保留精选，避免提交树被过程细节淹没。

| 文件 | 内容 |
|---|---|
| `issues-full.md` | 按主题整理的问题与修复记录全量台账（含第三版编号说明），`### N.` 编号是引用锚点 |
| `known-issues.md` | 已知未修与验证边界，对应设计报告指南 3.3.5.3 的失败分析口径；每条五段：现象→触发条件→已定位原因→处置→凭据 |
| `open-items.md` | 开放项与未验证清单 |

## 阅读约定

- 编号与 `main` 分支 `report/issues/`、`report/limits.md`、技能包条目互指，两处同编号指同一条。
- 状态词（已修／未修／部分生效／搁置／误报／NOT_MEASURED）与 `main` 分支 `report/issues/README.md` 的定义一致。
- 凭据引用的台架判定行、板上日志在 `main` 分支 `sim/results/`、`build/reports/`、`board/measured/`。

## 归档口径

- 内容按 2026-11 台账原样归档；本机盘符路径（工具安装目录、工作区绝对路径）已泛化为 `<本机…>` 占位，语义不变。
- 证据件（仿真判定行、板上日志）逐字保留；台账只解释判断链，结论以 `main` 分支验证文档为准。
