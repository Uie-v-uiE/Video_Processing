## 三条读法约定

1. **WNS 的绝对差不算收益也不算损失**。同一域自己的关键路径锥真的动了才算，且别的域不许变差；
   要念就念相对余量（例：`clkout0_1` 那条从 1.130 ns / 23 级 / route 77.5 % 变成 4.094 ns / 21 级 / 62.8 %，
   相对余量 5.65 % → 20.5 %，代价 +2 LUT / −6 FF）。
2. **判负的要照原样读**。九次对照里六次没采纳：复制驱动赢 1 格跌 4 格含最紧两格、Pblock 被工具拒
   （`Place 30-439`，进位链半内半外）、±0.500 ns 输入窗一挂就 WHS −2.885、两档实现策略一档方向不利一档毫无作用、
   BRAM 换 setup 只买到 +0.182 ns（期望 +0.516，仍 4 级）。这些不是失败记录，是"这条路为什么不通"的证据。
3. **测量与采纳是两件事**。统一给四域加 0.800 ns hold 不确定度带那次，读数变难看
   （全设计 WHS 0.053→−0.747、THS 失败端点 25,742），它的产出只是把"四域 hold 全为正"这句
   限定成"在现行约束集下为真"，并说明四个 WHS 不可跨域比大小——那一次没有任何东西被采纳。
