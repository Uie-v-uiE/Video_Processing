# S1 · UDP 乱序重组协议设计与验证

## 适用场景
PC 向 FPGA 推送原始帧（视频/点云/矩阵），UDP 不保证顺序与可靠。

## 使用方法
包格式：`[u32 LE byte_offset][payload]`
- 接收端：`mem[base+offset] = payload`，勿按到达顺序线性追加
- 收满一帧字节数（或包位图）再切换显示缓冲
- 坏帧：丢弃、不重传、下一帧自动恢复

## 已验证效果
- ISSUES#16：无 offset 时乱序导致块状错位；加 offset 后流式视频正确
- `sim/tb_udp_reasm.v`：正常 / 乱序 / 坏包 / 重复 / 帧跳变

## 失效条件
- offset 本身损坏且无校验 → 写飞（应用层可再加 magic/CRC）
- 覆盖率用「累计字节」在有空洞时会误判收满 → 本工程流量下可接受；严格场景改用位图
- 载荷超过 MTU 分片未处理（本工程上位机 1400B 单包）
