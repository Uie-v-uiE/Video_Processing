# 黄金文本比对器（容差 + 按期望键的豁免 + 三态判定）

## 适用场景

- 有一版"期望文本"：上一轮未改动树的输出、参考模型的逐样本输出、人工核对过的报告摘录。每轮要知道变了没有、哪几行变了。
- 数值列带舍入噪声（打印精度不同、末位不同），逐字比永远红，于是开始手删比对行——那是在削尺子。
- 已知偏差需要白名单挡在门禁外，但白名单加到第 N 条后没人敢删。
- 出现"比对报绿，翻开输出却根本对不上"：多半是空集或压根没比。
- 判定要进 CI，需要退出码与三态判定词。

## 使用方法

在条目根目录跑，两侧是你自己的两个文本文件：

```bash
node scripts/compare.mjs <actual.txt> <golden.txt> [--tol <num>] [--exempt <file>] [--self]
```

**先跟用户确认**（这三件都会改变红绿，属判据口径，不许自作主张）：容差的量级与单位、允许进白名单的偏差由谁批、行数不同是否算红（脚本默认算）。
**先查一手资料**：期望文本的出处（哪一轮、哪个未改动的树、规范的哪一节）。推不出出处的那一行不要写进 golden，先标"未核"。

按序走，每步只加一样东西：

1. 裸跑（不设 `--tol`、不给豁免）：`node scripts/compare.mjs a.txt g.txt`。先看清本来有多少行就一致。一上来就调容差，会把"其实是输出格式变了"读成"数值噪声"。
2. 再加 `--tol`：只允许取测量/打印误差那个量级（末位是 1e-3 就给 1e-3，别顺手给 1e-1）。复跑。
3. 最后才加豁免文件：一条规则一行；键 = 被豁免那一行的**期望原文**（整行精确，或 `*期望行里的独特片段*`）；行首 `#` 为注释。
4. 读输出：每条判据一行，**最后一个字段是判定词**。应看到 `X2 豁免命中数 命中=K 期望侧键命中行=K 规则=R PASS` 和结论行
   `判 N 项：红=… 未测=… 豁免命中=… 容差=… <token>`。N 是**做了多少次比较**（打印出的判定行数），不是通过多少。
5. 退出码：有 FAIL ⇒ 1，其余 ⇒ 0。**退出码 0 不等于通过**——只认每行最后一个字段；CI 里要判的是 token。
6. 动过尺子本身（比较逻辑、容差、豁免格式、夹具）之后，第一件事是 `node scripts/compare.mjs --self`。

## 失效条件

- **报告格式随工具版本漂移 ⇒ 射程静默变窄**：本器按"行内分列"比，前提是新旧版本用同一方式分行分列。换版本后摘要行折行、列序变、单位后缀挤进数值列，该列就会走"字符串不等"分支；若那行恰好又被豁免盖着，你会得到全绿而一次数值都没比过。征兆：某列的差异从项目起就没被报出过。
- **把夹具绿当真实可用**：`--self` 只证明比对器对自带的 8 个夹具行为正确，不证明你那份 golden 是该被相信的期望。真实首轮必须人工抽三行原文与出处核对。
- **豁免买通**：脚本只能机械判出"键只出现在被测侧、期望侧没有"这一类（`X1` 报红）；键文本两侧同名（表行标签两侧都在）时判不出来。所以命中数必须打印、每次命中单独占一行。做法：删空豁免复跑一次，红项集合与"已批准偏差"清单对不上，就说明豁免在藏东西。加豁免前先问用户。
- **0 样本真空通过**：任一侧为空 ⇒ 只出两条 `NOT_MEASURED`（`判 2 项`），不会绿。把空件（构建还在飞、0 字节日志）喂进来时，该回去查产生件那一步，而不是在 CI 里加 `|| true`。
- **命中 0 条的豁免**：会打印"警告：豁免可能失效"并落 `NOT_MEASURED`。留着它，下一次参考漂移时它可能突然豁免一条你并不想豁免的行——删掉，而不是继续加。
- 容差是**绝对**的：同一列混着相差几个量级的数时，一个 `--tol` 只对一半有效，另一半要靠列拆开比。
- 行数不同时只列前五行（防刷屏）；差距很大时先读行数，别把截断清单当全部。

## 已验证效果

`node scripts/compare.mjs --self` 实跑读数：`判 10 项：红=0 未测=0 夹具=8 … PASS`，退出码 0。逐条断言均为"期望=实得"：

- 等值通过 `PASS` 红 0 比较 8；容差内通过 `PASS` 红 0 比较 7。
- **能红的变异对照**：把 golden 里的一个数改 1 ⇒ `FAIL` 红 2；不设容差跑同一对文件 ⇒ `FAIL` 红 4（证明容差真在干活，不是永远绿）。
- 超容差失败 `FAIL` 红 2；行数不等 `FAIL` 红 3 并打印 `实际侧多出 1 行 [L4「…」]`。
- 被豁免夹具：`NOT_MEASURED` 红 0 未测 3 **豁免命中=2**（命中数是断言项，不是"绿就行"）。
- 一侧空文件：`NOT_MEASURED` 红 0；买通键夹具：`FAIL` 红 3；零命中豁免：`NOT_MEASURED` 并打印警告。
