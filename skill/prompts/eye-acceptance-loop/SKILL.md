description: 给"代理发命令、人看屏"这套分工的提示词模板：把一句"看一眼"写成带前置状态、一次一条命令、每个"不"各有病灶的观测配方，用能切换归属的旋钮做二分，一次问不超过三条单事实问题，最后把现象换成可归档的归属结论与两半签收。当症状只有眼睛能判（一条线、一条带、闪烁、走样、颜色不对）、当台架判不到某一路而必须有人签收最后那一半、当代理的每句话成了操作者唯一的线索时使用。当症状能被一条命令判（先造判据）、当要收敛的是画质审美、当命令通道本身不通、当症状是时间类需要连续捕获时不要用。
---

## 1. 一句话用途

让"看一眼"变成一条能判归属、能归档的观测。

## 2. 适用场景

- 当你准备叫人来"看一眼"，而这一路你手里没有一条命令覆盖它时。
- 当症状只有眼睛能判：一条线 / 一条带 / 闪烁 / 走样 / 颜色不对。
- 当分工已经是"代理发命令、人看屏"，而代理的每句话成了操作者唯一的线索时。
- 当一个功能修完、但台架判不到那一路、必须有人签收最后那一半时。

## 3. 不适用 / 失效条件

- **任何能被一条命令判的症状**：先去造判据（见 `../criterion-before-code/`、`skill/pitfalls/criterion-blind-spot/SKILL.md`、
  `skill/references/bench-self-inflicted-reds/SKILL.md`），别占用人。
- **画质好坏的主观收敛**（缩放走样、色彩、抖动的美学判断）：本方法只判**归属**，不判审美；对演示图案的审美抱怨不是红项。
- **命令通道本身不可用时**：先修连线与串口（见 `../../board_eth_uart.md`），这一页的一切都要靠"发得出、看得到回读"。
- **症状是时间类的**（几秒一次、只在看的时候闪）：要的是带时间戳的连续捕获或一个计数器出口，不是第二双眼睛。
- **没有可切换归属的 A/B 通道时**："看一眼"没有区分力——"有没有线"会得到一个无法归因的答案；先造一个旋钮（哪怕一次性命令）。
- **操作者不在场时**：不许自代签，这一格只能记"未验证"。

## 4. 前置条件

- 一条能发命令并留档的通道：每发一行的原文都要能事后 grep 到（一次性捕获，或按脚本批量发并留档）。
- 一个能切换归属的旋钮。本工程的旋钮是一个 0/50/100 的分割量（示例取值，需按自身工程替换）：
  0 = 整屏处理、100 = 整屏原图、50 = 一屏两条同看（最省事的一档，一次回答"跨不跨缝"）。
- 一段"台架为什么不覆盖这一路"的说法（写不出这句，这一眼就只是形式主义，下一个人会拿它当免检）。
- 症状的可观察描述：看见什么算有、看见什么算没有、它在哪个自变量档位上出现或消失。
- 叠加类开关（标记线一类）的当前状态，能读回而不是"我记得关了"。
- 操作者在场，且接受"一次不超过三条提问"的约定。

## 5. 使用方法

### 5.1 提示词正文（整段复制，先填 5.2 的槽位）

```
你是"眼睛在操作者那侧"这一格的观测发起 agent。本轮规则：只有当这一眼无法被机器替掉时，
才允许占用人；你的产出是提问配方与归属结论，不是"看起来正常"。你不替操作者作答。

【本轮事实（全部由我填；我没给的数字不许补）】
- 症状（肉眼看见的那一物）：【填入】（一条线 / 一条带 / 闪烁 / 走样 / 颜色不对）
- 判不到这一路的台架清单，以及"台架为什么不覆盖它"那一句：【填入】
- 可切换归属的旋钮及其取值：【填入】（本仓库示例取值，需按自身工程替换：一个 0/50/100 的
  分割量，0 = 整屏处理、100 = 整屏原图、50 = 一屏两条同看）
- 命令通道与捕获留档位置（发出的每一行都要能事后 grep 到）：【填入】
- 叠加类开关（标记线等）的当前状态与读法：【填入】
- 操作者可用时间与单次提问条数上限：【填入】（默认一次不超过三条）
- 该症状随哪个自变量变化（倍率 / 片源 / 位置）：【填入】

第 0 步 · 先取证再提问，并先证明这一眼不可被机器替掉：
  输出 A"我读过哪些文件的哪些行"（含"台架为什么不覆盖它"那句的出处路径 + 行号）与
  B"我做了哪些假设（已确认/未确认）"。写不出那一句 ⇒ 回答"这一眼是形式主义，请提供可判的
  读数或先造判据"并停住，不许占用人。

第 1 步 · 给这一眼一个配方，不是一个提问。三样写死：
  前置状态（哪一路片源、哪一档倍率、标记线开没开）→ 一次一条的命令 → 每一个"不"分别指向什么病灶。
  禁止把多条命令拼成一段发：操作者无法把"画面没变化"归到某一条动作上。

第 2 步 · 用一个能切换归属的旋钮做二分，而不是问"有没有东西"。一次问不超过三条、每条只问一个事实：
  ①在不在？②宽度跟不跟着倍率走？③颜色跟不跟着内容走？
  三个答案就把"哪一路 / 几何还是取值 / 是不是我自己造出来的"分开。每条都要写明"看哪一格"。

第 3 步 · 先排除自己造出来的伪像，再下结论：
  凡是"操作者看到的异常"与"代理刚刚动过的东西"落在同一条边上，先关自己的那个开关
  （如确认标记线是 off），并把关闭动作的命令与它的回读一起写出。

第 4 步 · 状态断言只从捕获文件里读，不从记忆里读：
  要说"我已经发了 X"，就去那一次的捕获里 grep 这一行。grep 不到 ⇒ 当场收回上一句并说明实际
  发了什么——收回比面子便宜得多。

第 5 步 · 看完立刻把这一眼换成可复跑的东西：眼睛报现象 → 补一条判据 → 下一次同类问题不必再叫人。
  输出建议判据的编号、谓词句（"当【激励条件】时读数【字段】应当【期望值】"）与它该红的条件。

第 6 步 · 输出契约（顺序写死）：
  1) 那一句"台架为什么不覆盖这一路"
  2) 配方三件：前置状态 / 逐条命令 / 每个"不"分别指向的病灶
  3) 提问列表（≤3 条，每条只问一个事实）+ 每条答案对应的归属分支
  4) 我从捕获文件里 grep 到的发出行原文（grep 不到就写"未发出"，不许写"应该发过了"）
  5) 结论形状：只能是归属句（"某条带属于哪一路"）或"未验证"；不许写"看起来正常"
  6) 待补的判据（第 5 步那条）与签收两半：操作者原话 + 机器判据的数字
  没有数据处写【未实测】；禁止替操作者作答；禁止引用我不存在的报告；
  禁止"通常/一般来说"式措辞；任何数值结论都不许由眼睛给出。

第 7 步 · 停止条件（任一命中就停下并报我卡在哪一条）：
  命令通道不通（先修串口/网络）；旋钮切不出归属（先造旋钮）；判据所看的那条边在这一档碰不到
  （换一档再看，比再看一次有用）；症状是时间类的（要连续捕获或计数器出口）；操作者不在场。
```

### 5.2 槽位清单

| 槽位 | 该填什么值 |
|---|---|
| 症状 | 肉眼看见的那一物：线 / 带 / 闪烁 / 走样 / 颜色不对，并写清在哪个档位出现或消失 |
| 台架不覆盖这一路的说法 | 一句可核对的话 + 出自哪份台架清单（路径 + 行号）；写不出就先补，别叫人 |
| 可切换归属的旋钮及取值 | 旋钮名 + 全部档位 + 每档"屏幕上应看到什么"（本仓库示例取值，需按自身工程替换：0/50/100 分割量） |
| 命令通道与留档位置 | 捕获文件名或归档目录；事后要能按行 grep 到本轮发出的每一条 |
| 叠加类开关状态与读法 | 标记线一类"可能是我自己造的"的开关，以及读回它当前值的命令 |
| 单次提问条数上限 | 默认 3 条；每条只问一个事实，多了归因就糊了 |
| 自变量 | 倍率 / 片源 / 位置——第 2 步的②③两问就靠它 |

### 5.3 执行步骤

1. 填槽发出。**完成后应看到**：第 0 步 A 节先出现，含"台架为什么不覆盖它"那句的出处；缺这句就是拒绝发问。
2. 读第 1 步配方。**完成后应看到**：前置状态、逐条命令、每个"不"指向的病灶三样齐全，且不是一段合并命令。
3. 逐条发命令（一次一条），把发出内容留在捕获里。**完成后应看到**：捕获文件里能按原文 grep 到这一行。
4. 只问三条以内的事实题。**完成后应看到**：三条回答分别落进"哪一路 / 几何还是取值 / 是否自造"三格之一。
5. 收到"画面没变化"而你以为自己发过命令时：回第 4 步 grep。**完成后应看到**：要么捞出那一行，要么公开收回上一句并说明实际发了什么。
6. 收尾。**完成后应看到**：一条归属结论或"未验证"登记 + 建议补的判据编号与谓词句 + 两半签收（原话与数字）。

## 6. 判读与失败分叉

- **通过**：这一眼绑出一条可判的归属结论（"某条带属于哪一路"），并且每条排除项都是一条能发的命令、其发出**能从捕获文件里 grep 到**。
- **未验证**：绑不出归属 ⇒ 登记成"未验证"；不许写"看起来正常"（那是把"没答上来"写成"过了"）。
- **两半都签才算关闭**：关闭一次眼睛验收要两半都签——操作者原话 + 机器判据的数字，各签一半，谁也没替谁签；操作者不在场 ⇒ 该格空着，记"未验证"。
- **声称"已发"而操作者回"画面没变化"**：本条要防的反例——上一条调用其实只发了别的两行。处理：grep 捕获、收回上一句、说明实际发了什么（不靠面子续结论）。
- **换一档再看，比再看一次有用**：判据所看的那条边在这一档碰不到时不算证据（画面铺满整屏 ⇒ 屏上没有一列背景可对照）；与 `skill/pitfalls/criterion-blind-spot/SKILL.md` 同源。
- **眼睛越界给数值**：眼睛只答"在不在 / 在哪一路 / 跟不跟"，任何数值结论仍要走采集链（`skill/pitfalls/metrics-gap-sum/SKILL.md`、`skill/pitfalls/frameid-loss-signature/SKILL.md`）。
- **该格其实能自动化**：那一路已有面板级判据时，这一眼不该再要人——把可自动化的症状交给人眼，是花别人的时间换自己的安心。
- **3 次问不出归属**：停下，列出试过哪些档位与命令，等人类裁决；不许把提问改成"要不要我猜一个成因"。
