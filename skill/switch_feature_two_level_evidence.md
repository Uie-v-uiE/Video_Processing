# S26 加一个"开关"类功能：要两级证据——模块内逐位等价，顶层接线可达

## 触发
需求形如"给 X 加个开关/使能位"：OSD 叠层、插值、调试输出、通道选择。改动小，但**最容易假绿**。

## 不适用
纯组合的调试信号（只影响一个 LED）。

## 动作
1. **不要新加一级寄存器**。把开关做成"已有的那个选择多一个输入"——本项目 `osd_en` 就并进
   `if (pixel_on)`，于是开/关的内容延迟逐拍相同，顶层所有延迟账（`MIX_D`/`LATENCY`/行环）都不用动。
2. 跨域的准静态控制位**每一位一条独立同步链**（#65 的教训：两个翻转位挂同一级扇出会被 CDC 判据打回）。
   复位值选"与旧行为一致"的那一极（本项目 `osd_off` 复位 0 = 仍显示），这样"忘了初始化"不会改变观感。
3. 两级判据：
   - **模块级**：关掉 ⇒ 输出**逐位等于**背景/直通。背景**不许取全黑**（否则"等于背景"与"被清成 0"是同一个数）。
   - **顶层级**：在**引脚/最终产物**上量一个只有这条链能产生的特征（本项目数 rose 字形格数：
     开着 > 1000、关掉 = 0）。它判的是"接线真的通"——端口加了但台架/顶层没接，是本项目真发生过的事故（#88）。
4. 帮助文本、回显字段、文档命令表**同一版改完**，并删掉那条已经走不到的"待接"提示。

## 完成判据
两级判据都带**正对照**（开着必须有东西）；固件产物里查得到新字符串（证明不是链接失败的旧件）。

## 失效边界
- 顶层判据若采样点在被控层**上游**，它对开关全盲——必须先确认采样点在下游。
- 若开关被做进数据通路（多一级 mux/一拍延迟），所有延迟对齐判据都会红，那不是开关是改版。
