# `evals/` —— 技能包的验证协议（怎么证明一条技能真的有用）

赛题对技能包的要求是"每一项须写明适用场景、使用方法与**已验证的效果**"（§3.3.5.2），
对加分项写得更严："已验证的复用结果（干净环境部署，或跨设备、跨场景迁移）"（§3.2.5.3）。
本目录的存在意义就是让这两句可以被复核，而不是被宣称。

## 1. 双跑定义（同条件基线）

同一道任务跑两遍，唯一的差别是**给不给这一条技能**：

| | 基线运行 | 技能运行 |
| --- | --- | --- |
| 任务 | 同一句话描述的任务 | 同一句话（逐字相同） |
| 提示词 | 只含任务本身 | 任务 + 该条 `SKILL.md` 的 5/6 节 |
| 模型 / 上下文 | 同一模型、同一上下文长度 | 声明"其余条件与基线一致"并列出被控制的变量 |
| 重试 | 单次生成、不重试、不调用工具 | 同 |
| 工具版本 | 同一 Vivado/Vitis/xsim 版本（版本号真相源见 `_meta/naming-and-format.md` 第 4 节） | 同 |
| 输入文件 | 同一份（写明路径与规范化后摘要） | 同 |

差值 = 这条技能的增益。**两份原始输出都要归档进 `raw/`**，只留结论的记录不算记录。

## 2. 判定口径

- 判据必须可机检：写明它来自哪个脚本（`skill/scripts/...`）或本仓库哪把现成尺子
  （`src/host/metric_recheck.mjs`、`src/host/doc_currency_check.mjs`、`src/host/line_cite_check.mjs`、
  `src/host/doc_enc_check.mjs`、`build/gates.sh`、`sim/run_one.sh`）。
- 每条记录打印分母：`判 N 项`。计数类断言（共几条技能 / 几项判据）由命令现算，改一次文件就重算一次。
- 三态：`PASS` / `FAIL` / `NOT_MEASURED`。**读不到输入 = `NOT_MEASURED`，绝不等于 `PASS`**；
  空集合、全 0、全 X 都不许被算成通过。
- 阳性对照必须能动：每条 `PASS` 的记录里至少有一个"本来就该变坏"的对照用例，它没变坏 → 这条记录降级为
  `NOT_MEASURED`，并写明是哪个对照没动。
- 重复次数：能重跑的至少 3 次，报 pass@1 与 pass@3；口径参考
  `https://github.com/NVlabs/verilog-eval` 与 `https://github.com/sharc-lab/HLS-Eval`
  （外部口径，只有在 `_meta/sources.md` 有对应行时才允许在记录里引用其定义）。
  差值缩小 = 稳定性提升；这不是"更快"，两者分开报。

## 3. 记录字段（`records/<条目路径>-<序号>.md`，顺序不可变）

```
- 被测条目：
- 任务描述：（一句话，不含本队专有名）
- 基线运行：命令 + 输入文件 + 输出归档路径 + 时间
- 技能运行：同上，并声明"其余条件与基线一致"，列出被控制的变量
- 判定：可机检口径（脚本路径 + 判 N 项）
- 结果：数值差 + 单位 + 出处（文件:行 或 报告字段名）
- 阳性对照：用例 + 是否如预期变坏
- 三态结论：PASS / FAIL / NOT_MEASURED + 理由
- 边界结论：本次覆盖到哪些条件、没覆盖哪些
```

## 4. 让记录作废的两件事（硬规则）

1. 判据或条目正文被改动 → 它此前引用的所有"已验证"记录自动作废，必须重跑；
   未重跑的记录一律标 `需重跑`，不得继续被 README 一览表念成"已复跑"。
2. 验证不过就如实记成红，并把 `skill/README.md` 那一行的状态降级为 `待验证` 或删掉条目。
   **禁止**留着条目、把结论写成有效，也禁止为了让记录变绿去改判据。

## 5. `migration/` 的最低要求

每份迁移记录只回答一个问题：**换个题目或换块板，改动量落在哪几行**。
当前不具备迁移条件时，这一节不许留空：写"不具备 + 缺什么"（第二块板卡、第二个可套用的模块、
或一个从未走过该流程的子功能作为替代证据）。

## 6. 本目录当前的真实状态

计数由命令现算，不手抄：

```bash
ls skill/evals/records/*.md 2>/dev/null | wc -l
grep -l "三态结论：PASS" skill/evals/records/*.md 2>/dev/null | wc -l
grep -l "三态结论：NOT_MEASURED" skill/evals/records/*.md 2>/dev/null | wc -l
grep -l "需重跑" skill/evals/records/*.md 2>/dev/null | wc -l
```

记录与条目之间的双向核对（孤儿记录数必须为 0）由 `skill/scripts/check/gates.mjs` 的 G7 执行。
