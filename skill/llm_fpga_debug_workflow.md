# S5 · 大模型辅助 FPGA 调试提示词工作流

## 适用场景
用 LLM 写 RTL / 定位上板问题 / 整理工程材料时，控制幻觉与可验证性。

## 使用方法
1. **先给上下文**：器件、工具链版本、当前架构图、失败日志原文  
2. **拆问题**：一次只要「根因假设列表 + 最小验证步骤」，不要一次要完整工程  
3. **要求可证伪**：让模型写出「若假设成立应看到 X」  
4. **RTL 约束**：要求注释只写非显然 WHY；禁止无端流水线「以防万一」  
5. **交叉验证**：模型改完必须过仿真/综合；上板问题优先对照 ISSUES 清单  
6. **披露**：按 `report/AI_COLLABORATION.md` 记录用途与人工边界  

## 已验证效果
- 本仓库 ISSUES 19 条可直接当检索索引  
- 技能包与文档从协作过程中沉淀  

## 失效条件
- 只让模型「直接改 bit/xdc 管脚」而无原理图依据  
- 无仿真/无日志的纯猜测循环  
- 把未上板数据写成实测结论
