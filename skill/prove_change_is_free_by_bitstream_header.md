# S27 一次代码改动到底"是不是免费的"：用位流包头自己回答，不要用推理回答

## 触发
你改完 RTL（或删掉一个没被例化的模块、换掉一个 `ram_style`、清掉一处综合告警），
想知道**这次改动会不会动到时序/资源/行为**。常规做法是"再滚一轮构建然后念 WNS"，
但那一轮会把 `build/system.bit` 与全套报告覆盖掉——于是板子上那块与你引用的那份报告不再是同一次构建，
而下一个人无法判断"板上是哪一版"。

## 不适用
- 你真的改了逻辑行为 ⇒ 数字必然变，本条只教你怎么**证明它没变**。
- 只想比较两个策略的 WNS ⇒ 那是策略扫描（`build/tcl/sweep_impl_strategy.tcl`），别期待位流相同。

## 动作
1. **把这一轮产物写到旁边**，不要动 `build/` 那套被门禁与文档引用的东西。
   仓库里的做法是 `build/roll_isolated.sh`：它**不复制**那 300 行构建脚本，
   只用一条 `sed` 把 `set outdir [file join $root build]` 换成隔离目录，并且**替换不生效就拒绝跑**
   （正式脚本哪天改了写法，这条 sed 会静默不匹配，于是一轮构建就把 `build/` 覆盖掉——那是本条要避免的事故）。
2. 跑完先比**报告**再比**位流**：`diff <(滤掉 Date/Command 两行的 timing_summary) …`、`route_status.rpt`。
   只差报告头里的 `-file` 路径 ⇒ 布局布线结果相同。
3. 再比位流本体：
   ```bash
   ls -la a.bit b.bit                    # 长度必须先看
   cmp -l a.bit b.bit | wc -l           # 差几个字节
   python -c 'print(repr(open("a.bit","rb").read()[100:160]))'
   ```
   Xilinx 的 `.bit` 头部是键值对：`a`设计名 / `b`部分 / `c`日期 / `d`**时刻** / `e`ID。
   若 `cmp` 数出来的差异全部落在 `d` 那几个 ASCII 数字里 ⇒ **配置内容逐位相同**，
   这句话的强度远高于"两块位流的 WNS 一样"。
4. 结论要连带说出**代价**：位流相同 ⇒ 板上那块不必重烧（重烧只是再走一次 JTAG）；
   而 `rtl_md5` 变了 ⇒ 所有钉 md5 的台架报告必须重跑才算当前树的凭据（这是同一件事的另一面）。

## 完成判据
一条可复现的声明，三样都留档：① 隔离目录里的 `timing_summary.rpt`/`utilization.rpt`/`route_status.rpt`
与上一版的 diff（"只差两行 `-file`"）；② `cmp -l` 的**字节数**与那几个字节所在的头部字段；
③ 两块位流各自的 md5 + 生成时刻。凭据形状见 `docs/OPTIMIZATION_LOG.md` 的 r85 一节
（2026-09-29：同为 2 222 010 B，`cmp -l` 差 4 个字节，位置 126/128/129/132，
`d 01:12:23` ↔ `d 03:06:24` ⇒ 只差构建时刻）。
**失效**：如果你顺带改了约束（XDC）、器件速度等级或 IP 版本，包头以外的字节一定会动——
那时本条只告诉你"改动不是免费的"，不告诉你贵在哪。

## 失效边界

上面那行 `**失效**` 说的是同一件事的另一种情形：**位流大小恰好相同**也不等于免费——
只有 `cmp -l` 逐字节过完、并且差异全部落在包头那几格时刻字段里，才叫"这一版位流就是那一版"。
反过来，只差时刻这 4 个字节时也**不能**推出"改动对时序零影响"：布局是确定的，但确定不等于不变，
本条只能证"配置内容相同"，证不了"收敛余量相同"。
