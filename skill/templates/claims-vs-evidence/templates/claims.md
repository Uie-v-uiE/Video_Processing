# 声明—证据对照表模板

> 用法：复制本文件，先只留表头，然后把准备写进交付文档的每一句断言登记成一行。
> **先入表、再入文**；表是用来决定措辞强度的，不是给已成文的文档补理由的。
> 方括号占位逐处替换；单元格内不要出现竖线（要分隔就用顿号或分号），否则脚本统计会错位。

---

## 1. 主表（列序固定，不要增删列、不要换序）

| # | 声明 | 类型 | 依据（件 + 节 + 复跑命令） | 状态 | 允许写进交付文档的措辞 |
|---|---|---|---|---|---|
| 1 | 【填入：一句可判真的话，含数字与单位】 | 实测 / 计算 / 二手引用 / 假设 | 【填入：相对位置的件名】第【填入：节名】；复跑：【填入：命令】 | 已核 / 未核 / 未量过 | 【填入：见第 3 节对照表】 |
| 2 | 【填入：…】 | 【填入：…】 | 【填入：…】 | 【填入：…】 | 【填入：…】 |

首列 `#` 是行号（统计脚本靠它认表体行，不是内容列）；其余五列就是本表的五个内容列，一列不多一列不少。
"记录位置"不单列——它写进依据格里（例：`复跑：… ；记录：一轮记录【填入：轮次标识】第 6 栏`）。

填写范例（形状参照，数值自己换）：

| # | 声明 | 类型 | 依据 | 状态 | 允许写进交付文档的措辞 |
|---|---|---|---|---|---|
| 1 | 目标域最差余量为【填入：数值】【填入：单位】 | 实测 | 【填入：实现报告件】第【填入：节名】；复跑：【填入：出该报告的那条命令】 | 已核 | 实测【填入：数值】【填入：单位】（件、节、命令同上） |
| 2 | 片上存储占用为【填入：数值】 | 实测 | 【填入：占用报告件】第【填入：节名】；复跑：【填入：命令】 | 已核 | 实测【填入：数值】（同一件同一节） |
| 3 | 外存带宽预算约为【填入：数值】 | 计算 | 公式：每样本位宽 × 采样率 × 通道数；输入取自【填入：指标表件】 | 已核 | 按公式由【填入：输入件】推得，未在本平台直接量过 |
| 4 | 该平台某接口的理论速率上限为【填入：数值】 | 二手引用 | 【填入：出处（资料名 + 节）】（转述，未在本平台复核） | 未核 | 据【填入：出处】转述为【填入：数值】；未在本平台复核 |
| 5 | 观感上切换过程不引起可见闪烁 | 假设 | 待人判，见验收配方第【填入：判据编号】条；机器侧只给得出可数特征（帧号/时长/亮度读数），判不了"是否引起可见" | 未量过 | 未量过，属预期；已登记为人判项 |
| 6 | 长时间运行不会累积误差 | 假设 | 无件 | 未核 | 不许进正文；移入未决项清单 |

## 2. 四条硬规则（填表前读一遍，逐条对着查）

1. **没有件的声明只能标 `未核`。** 依据栏写不出"件 + 可复跑命令"，状态就不许是 `已核`。
   件打不开、被同名覆盖、不在交付包内 ⇒ 一律 `未核`，不许"沿用上次"。
2. **`二手引用` 必须自报是转述。** 依据栏末尾追加"（转述，未在本平台复核）"，并写明转述的是哪一层
   资料（用户指南/数据手册/接口规范 ＞ 应用笔记 ＞ 教程 ＞ 记忆）。权威出处也不改变它的类型。
3. **资源/频率/吞吐类数字必须绑到具体报告。** 依据要点名到某一份工具报告文本件与节名；
   写"综合结果""实现之后"这种泛指 = 未绑 = `未核`。跨件取数（几份报告不是同一次运行）同样 `未核`。
4. **状态列只写一个词**（`已核` / `未核` / `未量过`），解释放依据栏。这样表才能被脚本统计。

补充：`假设` 类型的行不可能出现 `已核`；`实测` 不等于 `已核`（抄错了也叫实测过）——
类型与状态是两个独立的轴，别互相推。

---

## 3. 状态 → 允许措辞对照

| 状态 × 类型 | 交付文档里可以这样写 | 禁止 |
|---|---|---|
| 已核 × 实测 | "实测 <数值><单位>（<件> 第 <节>，命令 <…>）" | 去掉件与节、只留数值 |
| 已核 × 计算 | "按 <公式> 由 <输入件> 推得 <数值>，未直接量过" | 写成"实测" |
| 已核 × 二手引用 | "据 <出处> 转述为 <数值>；未在本平台复核" | 把转述写成自己的读数 |
| 未核 × 任意 | 不进正文；进未决项清单，写"待验：<声明>" | 出现在正文、汇报、结论行 |
| 未量过 × 任意 | "未量过，属建议/估计"，可写趋势不写点值 | 给具体数字、给"保证/一定" |
| 待人判（外观/观感） | "已由 <判定人> 于 <时刻> 判为 <原话>（见验收记录）" | 用机器读数替人下结论 |

## 4. 统计（表能被脚本数出来，才算一条判据）

前提：**统计前先删掉范例行**，让文件里只剩一张主表；表体行的形状是 `| <序号> | …`，
列序固定为 序号 / 声明 / 类型 / 依据 / 状态 / 措辞（即 `awk -F"|"` 下的 `$2…$7`）。

```bash
# 未核条数 + 总声明数（状态在 $6）
awk -F"|" '/^\| *[0-9]+ *\|/ {t++; v=$6; gsub(/[ \t]/,"",v); if (v=="未核") n++;
                             if (v=="未量过") m++}
            END {print "声明 " t+0 " 条：未核 " n+0 " 条，未量过 " m+0 " 条"}' \
  【填入：本表件名】

# 实测类的"绑件率"（类型在 $4，依据在 $5）
awk -F"|" '/^\| *[0-9]+ *\|/ {v=$4; gsub(/[ \t]/,"",v);
            if (v=="实测") {t++; e=$5; if (e ~ /\./) k++}}
            END {print "实测绑件 " k+0 "/" t+0}' \
  【填入：本表件名】
```

两条都不许静默：表体行数为 0 时上面会打印 `声明 0 条` ⇒ 判 `NOT_MEASURED`，不是"没有问题"。
单元格里出现竖线、状态列写了句子、序号列空着，都会让这两条抽错——那是表写坏了，先修形状再看数。

结论行写法：`判 N 项：声明=X 已核=Y 未核=Z 未量过=W <PASS|FAIL|NOT_MEASURED>`
（`N` 是做了多少次比较，不是通过多少；`Z>0` 而正文里仍有对应句子 ⇒ `FAIL`；表为空 ⇒ `NOT_MEASURED`）。

## 5. 交表前的自查（5 分钟，逐条回）

1. 正文里每一个数字都能在表里找到一行吗？找不到的那一行数字先删掉。
2. 有没有 `未核` 的句子还活在正文/汇报里？应为 0 条。
3. 每一行 `已核` 的依据件，现在就能打开并看到那一句吗（不是"记得看过"）？
4. 资源/频率/吞吐是不是都绑到同一批次的件（同一次运行的报告）？
5. 转述类是否都写了"未在本平台复核"？
6. 有没有把"未量过"写成 0、写成"通过"、写成"应该没问题"？（这三样都算假绿）
7. 表末的统计行是否重跑过一次、读数是否与正文一致？
