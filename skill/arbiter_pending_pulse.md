# S12 · 共享介质的发送仲裁："全部空闲" + pending 记账 + 脉宽判据

## 触发

- 当你看到切源条件是把几个**互相独立**的 busy 标志用 OR 连起来的（`req && (a_busy==0 || b_busy==0)`）：它读作"任一空闲"，而你想要的是"全部空闲"。
- 当你看到帧长、载荷、CRC **一起**错、而且错得看起来随机：那是一帧还在飞时被换走了源，剩下的一半字节就地作废。
- 当你准备把一拍宽的请求脉冲直接 AND 上授权条件：授权常常在那一拍不成立 ⇒ 整笔请求被吃掉，表现成"要等对端超时才动"，最难查。
- 当你把清 pending/busy 的语句写进**另一个** always 块：非阻塞赋值读到的是上一拍的使能 ⇒ 默认晚一拍。
- 当你看到介质靠某个 `*_done` 释放，而几路的 done 混在同一个分支里、没区分"是谁的 done"。

## 不适用

- 需要公平性或带宽配额的仲裁：本方法只保证"不抢占 + 固定优先级"，第一路大流量可以饿死后几级。
- 带 ready/valid 或 outstanding ID 的总线（AXI/AHB）：那里的正确形状是握手通道与 ID 记账，不是这套 busy 位。
- 单一数据源，或介质由上层协议仲裁（本地没有 mux 可换）。
- `*_done` 可能永远不来（状态机被外部 abort）：那需要超时兜底，本条不含；几个发送状态机都是自走完的就不用。

## 动作

1. **读**（先不改）现有切源式，把它翻译成人话：判的是"任一空闲"还是"全部空闲"？要"全部"就必须是**所有** busy 的 AND。
2. **加**一个 pending 记账位，把脉冲变成电平：置位语句放**同一个 always 块的块尾**（同拍"兑现旧账 + 又来新请求"时新请求不会被吃掉），清零与授权**同拍**。
3. **收**释放条件：授权那一拍把 owner 寄存下来，**只有当前 owner 的 done** 能清 busy；于是多路 done 混着来也不会提前放掉介质。
4. **写**三条一起看的判据：帧在飞时不出现别人的字节 / 每一路的字节数等于完整帧长 / 请求既不丢也不重复 —— 要"数每帧几个字节"，不能只数帧。
5. **证**判据有牙：跑一次**实现策略变体对照**（同一批激励喂四种形状：原始 OR 版、只改 AND 版、AND+跨块清账版、本版），确认四条变体各挂在不同判据上（例如本仓库在临时目录的副本上改，不动仓库）。
6. **上板**只在以上全绿之后；改不动的活性风险（某一路压根没有 busy 标志 ⇒ 第二笔请求会重启在飞的那一路）登记成已知问题，不盲改。

## 完成判据

一次变体对照的实测形状（把来源编在标签的高位，"帧内换源"就能直接数出来；这里完整帧长 = 12 字节）：

| 仲裁形状 | 帧在飞时别人的字节 | A 路字节数 | B 路字节数 |
|---|---|---|---|
| "任一空闲"（OR） | 3 | 12 | **7**（那帧被截断） |
| "全部空闲"（AND）、无 pending | 0 | **0**（整笔丢） | 12 |
| AND + 跨 always 块清账 | 0 | **13**（第 0 字节发了两遍） | 12 |
| 本版（AND + 同块记账 + 只认 owner 的 done） | **0** | **12** | **12** |

- 绿 = 三条同时成立：`别人的字节==0 && A==完整帧长 && B==完整帧长`。
- 红 = 这条生效：第 2 行证明"只判别人的字节"会放走丢请求，第 3 行证明它放走"多一字节"；第 1 行的 A 仍等于 12，证明"只判字节总数"放走帧中间混源。

## 失效边界

- 它只保证"不抢占 + 固定优先级"，不保证活性与配额；要公平就得另加机制，别在本条形状上偷偷换成轮询。
- 两笔请求落在同一帧的发送时间内时，第二笔只是排队；但**已经在发的那一路**如果没有 busy 标志，第二笔仍会重启它 —— 那是原有行为，补 busy 位要付"done 丢了就永久不再应答"的代价，需上板验证，所以只登记不顺手改。
- 与 `skill/pulse_toggle_cdc.md` 的分界：那条管跨时钟域的脉冲被吃掉；本条处理**同域同拍**的仲裁窗口，先确认请求与授权同域。
- 判据覆盖"帧内不混源 + 字节数"，不验优先级本身对不对；优先级要另写一条对照激励。

## 出处

`docs/log/ISSUES.md` #37 —— 一路"任一空闲"的切源，在加了周期性发送（占空比从接近 0 变成常态）后开始每天撞车几次。
