# S10 · 单口存储器分时读：先算槽数与 RAM 代价，再动手

## 触发
- 当你想在不加 RAM 的前提下，把一个 1 读/1 写存储器的读口供多个消费者用，而片上有一个 N 倍于工作时钟、
  同一个 PLL/MMCM 出来且同相的快时钟。
- 当违例集中出现在"跨进快域"的那几条路径上。
- 当你准备把地址/偏移算术放进快域时。
- 当你打算用 `set_multicycle_path` 把这一组时钟间的红色关掉时。
- 当你改了读口、下游所有配准抽位都要跟着挪时。

## 不适用
- 两个时钟不同源或不同相 —— 那是异步握手（FIFO / 格雷码 / 翻转位）的场合，硬套分时只会把错误推到硅片上。
- 器件有真正双口 RAM、或换了原语不同的家族 —— 分时这一整套的动机消失，先量 RAM 代价再决定。
- 需求本来就有余量（N 次读里还有空槽），不必为它重排节拍。

## 动作
1. **先算两道算术题，再写 RTL**。槽数：每工作周期可用快槽 = N，需求 = 各消费者每次读次数之和；
   算出来是零余量（本项目 5 抽头对 N=5）就把"以后再加一次读要从哪个槽挤"写进模块头。
   RAM 代价：在同一组阵列上再加一个逻辑读口会不会让阵列翻倍（本项目探针 80 → 160 个 RAMB36，
   全片只有 140 ⇒ 封死，分时成了唯一出路）。
2. **按方向分配组合逻辑预算**。同相派生下，慢域触发器在 `t=T_slow·n` 变化，快域最早能采它的沿是
   `t=T_slow·n+T_fast` ⇒ **跨进快域的 Setup 预算是一个快周期，不是慢周期**。据此把地址/偏移算术全部
   在慢域算完并各打一拍，快域只留"本域寄存器 → 一个 mux → 存储器地址脚"；快→快只放一两级 mux、
   不放加法；快→慢最宽松。
3. **同一份读所需的所有描述量，必须在同一个沿采集**（如"字号"与"字内选道"）。两者错开一个沿会让整列
   颜色对、位置偏一格，且不报错、综合不告警。判据写法：让台架把其中一个量驱动成与另一个无关的
   独立图案，错了必然露；只测其中一个维度的判据抓不到。
4. **延迟常数要量出来并钉死，不要手推拍数**：端到端台架在候选平移量里搜**唯一**能全对的量并断言唯一
   （两个都对 ⇒ 判据没牙）；顶层写成一处定义、其它抽位由它推导；再用旧值回代自检，把旧延迟代回公式
   必须原样得到旧代码里的字面量——对不上的那一格就是"只有眼睛能看见"的真实错位。
5. **不要用整组 multicycle 豁免把红色关掉**：数据整个慢周期稳定常常是真的，但整组豁免会一并免掉同组里
   别的真实跨域路径（输出串行化器里往往就藏着一条慢→快路径），换来的是一条时序全绿、显示随机花屏的位流。
   要么按具体寄存器名限定并接受"改名即失效"，要么按第 2 步把设计写成真能过一个快周期。
6. **违例先分诊"逻辑不够 vs 离得太远"**：看 `report_timing` 一条路径就够，别猜。逻辑级数很少而 route 占
   八成 ⇒ 不是深度问题，再砍逻辑是白费，方向是复制高扇出驱动器（`phys_opt_design` 的 fanout replication）、
   加一级贴着存储器的寄存、或 Pblock 圈住调度器与那批 RAM tile；含进位链的算术才是真深度问题，只能把
   算术搬回慢域。多份策略同红且起止点相同 ⇒ 是同一条锥，先当"同一张网表重掷"，连着三滚不中才动结构。
7. **改节拍要能一次性回退**：分时调度器一旦换采样沿或加一级寄存，抽头采集沿、valid 跟随链、搭车槽全都要动。
   把实验版整份留档（含槽位表与失败现象），回退到全绿的那版只补回确定的真错，工具侧旋钮一次只动一个。

## 完成判据
- 快域到快域、以及慢域跨进快域的每一条违例路径：`Logic Levels` 与 route 占比能对上"该走直线的那段
  确实只有触发器→触发器"（本项目实测某版 `Logic Levels 2`、route 占 84.7%，据此判为离得太远而非逻辑不够）。
- 延迟量唯一成立且**用旧值回代能原样复现旧字面量**。
- 成套冻结与 md5 校验见 [S15](artifact_freeze_and_freshness.md)；上板前 `md5sum`，不信文件名
  （构建会原地覆盖同名位流）。

## 失效边界
- 改了像素/快钟比例（分频参数一动）⇒ 整张槽位表与所有推导抽位一起作废，必须重新量，不许沿用推导常数。
- 需求里有任何一次读要加法 ⇒ 快域那一个周期塞不下，算术必须搬回慢域。
- 报告里的路径名会读穿模块头注释里的结构断言：注释说"输入都打过一拍"而路径显示跨模块组合直驱一批
  CE 脚时，信报告，注释只是旧约定。
- 与 [S11](pulse_toggle_cdc.md) 的分界：本页只管**同源同相**的分时与预算；跨时钟域的脉冲/握手走 S11。
