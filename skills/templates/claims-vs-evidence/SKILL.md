# 声明—证据对照表

## 适用场景

- 写交付文档/说明/汇报之前，把里面每一句断言拆成表里一行。
- 症状级触发：一个数字说不出它是量来的、算来的还是抄来的；同一指标在两份文件里各有一个值；
  别人问"依据呢"，答案是"我记得报告里是…"；把资料页里的说法写成了自己平台的实测。
- 资源/频率/吞吐/余量/占用这类会被拿去比较的数字，尤其要先入表再入文。
- 不适用：纯计划、纯设计意图（那些进未决项清单，不进本表）；本表不替代一轮记录，
  它只管"话能不能这么说"。

## 使用方法

**动手前先查**：本表每一行的"件"是否真在盘上（相对位置能打开、内容能读出那一句）、
该件与产生它的命令是否同轮、二手资料的原始出处层级（厂商用户指南/数据手册/接口规范 ＞ 应用笔记 ＞
教程 ＞ 模型记忆）。**先跟用户确认**：文档允许的措辞强度（可否写"实测"、可否写"保证"）、
没有件支撑的那些话是删、是降级为"拟"、还是留在未决项里。

取本条目 `templates/claims.md`，五列固定，一行一条声明：

| 列 | 只允许填什么 |
|---|---|
| 声明 | 一句可被判真的话（含具体数字与单位；不带"明显/大幅/足够"这种没法判真的词） |
| 类型 | 四选一：`实测` / `计算` / `二手引用` / `假设` |
| 依据 | 哪份件（相对位置）+ 哪一节 + 能复跑的命令；`计算` 则给公式与输入来源 |
| 状态 | 三选一：`已核` / `未核` / `未量过` |
| 允许措辞 | 按状态与类型给定的一句话（见下） |

四条硬规则（违反任何一条，整表的信用就没了）：

1. **没有件的声明只能标 `未核`。** 依据栏写不出"件 + 可复跑命令"的，状态一律不许是 `已核`，
   哪怕它显然正确。件不在盘上 = `未核`，不是"应该有"。
2. **`二手引用` 必须自报是转述。** 类型写 `二手引用`，依据栏末尾追加"（转述，未在本平台复核）"，
   并写明它转述的是哪一层资料。资料页的数字不是实测，即使它来自权威出处。
3. **资源/频率/吞吐类数字必须绑到具体报告。** 依据栏点名到某一份工具报告文本件（相对位置 + 节名）；
   指向"综合/实现结果"这种泛指 = 未绑 = `未核`。同一次运行不同报告口径可能不同，不许跨件取数。
4. **状态列只有一个词**，不写解释、不写"已核（大概）"；解释放依据栏。这样表才能被脚本统计。

状态与措辞的对应（写进"允许措辞"列，直接抄进文档）：

| 状态 | 交付文档允许的措辞 |
|---|---|
| `已核` + `实测` | "实测 <数值><单位>（<件> 第 <节>，命令 <…>）" |
| `已核` + `计算` | "按 <公式> 由 <输入件> 推得 <数值>，未在本平台直接量过" |
| `已核` + `二手引用` | "据 <出处> 转述为 <数值>；**未在本平台复核**" |
| `未核` | 不许进正文。改写成"待验"或移进未决项清单 |
| `未量过` | "未量过，属建议/估计"，且不许带具体数字（要给范围就给来源） |

`假设` 类型的行只能是 `未核` 或 `未量过`——它是待验证的东西，本身不是证据。

## 失效条件

- **表沦为抄写**：先写了文档再补表，于是每一行都"已核"。征兆：`未核` 条数长期为 0，
  而文档里仍有没有出处的数字。补表之前先让文档里每一句断言被登记，再决定措辞。
- **件被覆盖或删除**：昨天能打开的件今天同名被吃掉 ⇒ 该行自动降级为 `未核`，不是"沿用上次结论"。
  凭据件命名带轮次标识正是为了挡住这个。
- **跨件取数**：从 A 报告取频率、从 B 报告取占用、从 C 表取吞吐，三件不是同一次运行 ⇒ 整行 `未核`，
  重跑同一次流程再登记。征兆：一行依据里出现两个以上互不相容的时间戳。
- **口径漂移**：同名指标换了定义（例：余量从"最差路径"改成"中位"），旧行不许直接改数继承，
  要新起一行并标"旧口径已作废"。
- **把类型当状态**：`实测` 不代表 `已核`（抄了错表也叫实测过），`计算` 不代表可信（输入可能是假设）。
  两列独立填。
- 表格被改成散文、单元格里出现竖线分隔符、状态列写了句子 ⇒ 脚本统计失效，本条最大的收益就没了。

## 已验证效果

未量过，属建议：没做过"带表/不带表"提交被评审打回次数的 A/B。表本身的可自查读数都是可复跑的形式，
其数值只在同一设计里有意义、随设计变，**不可当普适结论引用**：

1. 未核条数：`awk -F"|" '/^\| *[0-9]+ *\|/ {v=$6; gsub(/[ \t]/,"",v); if (v=="未核") n++}
   END {print "未核 " n+0 " 条"}'` 作用于对照表件（表首列为行号 ⇒ 状态落在第 6 列；列序固定才能这样抽）。
2. `未核 > 0` 的行同时出现在正文里的条数：应为 0（拿正文里每个数字反查表）。
3. 资源/频率/吞吐行的依据列点名到具体报告件的比例：应为 100%；任一件打不开即该行 `未核`。
