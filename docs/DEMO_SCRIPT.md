# 演示目录（照抄就能演）

> 这一份只回答两件事：**按顺序敲什么**、**每一步看见什么算通过**。根因与历史不在这页（在
> `docs/log/ISSUES.md`、`docs/log/OVERNIGHT_LOG.md`）。命令的权威出处是固件解析器 `src/ps/main.c` 与
> `docs/COMMANDS.md`；每一幕都标了行号，**没实现过的写法一个都不出现**，九个小节的标题就是台上念的名字。
> 每幕四件事：**前置 → 敲什么 → 看见什么算过 → 每一个"不通过"分别说明什么**。全套约 6 分钟；
> 时间不够只演第 1、2、3 幕（那三样就是项目名里的东西）。
> **顺序上唯一不许动的是第 9 幕（拔卡）排在收尾 `stat` 之后**：它要一只手，而插回前那几秒屏上没有 SD 这一路。
> 台上不要说两件事："设成某个绝对角度"（`rot <数字>` 有意不做，`main.c:1042`；要停角度只有板上 KEY1/KEY2
> 每按一次 ±1°）、任何"AI/识别/深度学习"字眼（一个都没有）。
> `osd on|off` 从 **r83 起是活的**（`gpio_o[20]` **反相**，1 = 关掉叠层）：拍屏或逐像素比对前把五行字关掉、
> `osd on` 立刻回来。这一对可以现场演，凭据三处：`sim/tb_osd_lines.v` 的 T13（关掉逐位等于背景）、
> 顶层 `tb_v98` 的 C12pre/C12a（叠字格 ON 看得见、OFF 归零）、串口 `AXI_GPIO` 差正好 `0x100000`。
> 可复跑的凭据：`sim/tb_v102_src_life.v`、`sim/tb_v100_fit_rot.v`、`sim/tb_v86_pipe_sel.v`、`sim/tb_v98_top_seam.v`（C1/C2/C3）、
> `sim/tb_v93_split_ctrl.v`、`sim/tb_v101_fb_bilin.v`、`sim/tb_v88_gamma.v`、`sim/tb_link_monitor.v` + `sim/tb_osd_lines.v`、
> `board/cmd_battery_v81.txt`、`bash build/board_verify.sh --battery --geom`；排练：`node src/host/demo_cmds.mjs --emit` 从本文件的代码块**抽**出脚本 → 逐条发给板子 → `--check <回包>`。

## 0. 开机到"能演"：五步，缺一步就不要开始

| 步 | 做什么 | 看见什么算过 |
|---|---|---|
| 1 | 只走 JTAG，**三条按顺序**（先起 `hw_server`，否则第一句就是 `Invalid target`）：`xsdb.bat build/tcl/ps_jtag_boot.tcl` → `vivado -mode batch -nojournal -source build/tcl/program_pl.tcl` → `xsdb.bat build/tcl/ps_app_reload.tcl` | 第一条打 `DDR_ECHO: …5A5AA5A5`（它写进 DDR 的就是这个字，`build/tcl/ps_jtag_boot.tcl:72`）+ `PS BOOT STEP DONE`；第二条打 `PROGRAMMED …`（这条**只能**在 Vivado 批处理里跑）；第三条打 `CON: ok`。之后 LED0 以 1.5 Hz 跳、串口出 `[BOOT]`（`main.c:1457`） |
| 2 | 另开一个终端在 **COM6 115200 8N1**（或 `board/uart_cap_once.ps1 -Port COM6 -Seconds 20`；**开着终端就没法同时用脚本发**，二者只能有一个） | 敲 `stat` 回一行 `[STAT] ctrl thr=… src=… zoom=… bilin=… zsel=… zman=… pub=… sd=… frames=… playing=… sel=… gm=… mode=… geom=…`（字段顺序就是 `main.c:1378`） |
| 3 | HDMI 接 1024×600 屏 | 屏上五行 OSD（`src/rtl/video/osd_overlay.v:326`–`385`）：L0 `1024X600 FPS:59 SRC:ETH`（**这一格数的是显示场同步**（`pl_video_top.v:893-910` 累加 `vs_tick`，面板 1344×625 @ 50 MHz ⇒ 59.5 场/秒），**不是片源帧率**；源帧率的可信出处是 `data/metrics.csv` 那两行（板上 100 帧滑窗，SD 那一路 29.8–30.0 fps）。把它改成"写进屏的新帧"是已选定但暂缓动工的 B 方案，见 `docs/log/ISSUES.md` #157），其中 `SRC:` 写的就是屏上真的那一路（只有 `ETH`/`SD`/`TEST` 三个词，末尾 `*` = 手动锁住） |
| 4 | PC 有线网卡静态 `192.168.1.100/24`，`ping 192.168.1.10` | 0% 丢包 = PL 网络栈活着；不通就别开第 1 幕 |
| 5 | **先记起点**：敲一次 `stat`，把这一行抄在纸上 | 第 8 幕拿它对账；少了它"跑完回不回得来"就无从判 |

⚠ **永远不要把这一版写进 QSPI/SPI flash，也不要碰板上 FT2232 的 EEPROM**（哪些条目要人在板前确认，是 `board/README.md` 那张表的事，不由本文说）。
**怎么证明屏上跑的就是你手上这份产物**：`md5sum build/system.bit build/ps_app.elf`，与 `board/README.md` 第一行"板上现在"那两个 md5 逐个字符对上 —— **只认 md5，不认文件名**。

## 1. 三路片源自适应仲裁（约 50 s）

**说什么 / 前置**：三个片源在无人干预下互相让位，而左上角那一格写的就是屏上真的那一路，不是"我希望是哪一路"；本幕只演**可逆**的两跳（ETH ⇄ SD），不可逆那第三跳（拔卡）在第 9 幕。卡上必须已经有 `node src/host/make_sd_video.mjs --in <mp4> --out E:` 准备好的**裸帧序列**（提前做，不是现场做）；PC 网卡按第 0 步第 4 条配好；PC 侧推流 `node src/host/video_sender.mjs --fps 15 --test bars`。
```
src auto
play
```
**看见什么算过**：推流一开始 → 屏上换成推过去的那一路、`SRC:` 变 `ETH` 且**不带** `*`（是让位来的）；拔网线 → ≤0.5 s 回 `SD` 并且还在播；插回 → 又回 `ETH`。⚠ L0 的 `FPS:` 画的是**面板**刷新（数的是 vs 拍，`src/rtl/top/pl_video_top.v:1005`–`1016`），**不是**收到的流帧率；串口也没有 `[LINK]` 这种回包，别把它当链路读数念。（`src auto` = `main.c:901`；`play` = `main.c:1287`，它会顺手把源钉到 SD。）
**不通过分别说明什么**：① 敲什么都没回、反而出"`[CMD!] dropped N trailing byte(s)`（ASCII 打头，见 `ISSUES #134`）" → 终端没发行尾（`main.c:1387`），先修终端设置，与板子无关；② `play` 回 `play refused: …`（`main.c:1304`）→ 卡没挂载或卡上不是那种裸帧序列，先敲 `sd` 看摘要（`src/ps/sd_play.c:641`）；③ `SRC:` 与屏上画面不一致 → 再敲一次 `src auto`，仍不一致就是仲裁那一层的事，**不要**改成手动锁源继续演（锁了就看不出"让位"），跳第 2 幕；④ 拔线后画面冻住不动 → 心跳/看门狗那一条没成立（`main.c:256` + PL 的 500 ms 超时），当场说"这一项今天不演"，别蒙。

## 2. 无极缩放（0.25×–2×）+ 任意角旋转（约 80 s）

**说什么**：512×300 的源在 1024×600 的屏上一格一格连续放大，缩放与旋转是同一套逆映射；旋转时倍率还能跟着角度自动收，整幅永远在屏内。
**前置**：`src 0`（图卡，格子肉眼可数）+ `split 50` + `split marker 0`（一屏同时拿两份抽头，口径见第 4 幕）。
```
zoom 1.0
zoom 1.5
zoom 2
rot speed 1
rot auto 1
zoom auto
```
**看见什么算过**：`zoom 1.0`→`zoom 2` 画面连续变大且边缘**不糊**（八档取最近档，回声把"你写的"与"我用的"并列出来，`main.c:944`）；`rot auto 1` 之后画面开始转、屏上 `Zoom:` 那一格同步在变并带 `(Fit)`（`main.c:1024`–`1033`）；`zoom auto` 交还呼吸，后缀变回 `(Auto)`。
**⚠ 不当卖点的状态**：低于 1.00× 的缩小档不进这一幕。大角度旋转的角点出屏（原 #93）**已修**：旋转一开，生效倍率就被 `zoom_ctrl` 钳进"这个角度刚好装得下"那一档 ⇒ 整幅永远在屏内；代价是旋转态**不提供放大**，手动 1.33x/1.5x/2.0x 三档会被拉回 fit 并标 `(Fit)`，档号不丢、关掉旋转立刻回去（`sim/tb_v94_zoom_sel.v` 的 T8a~T8f）。
**不通过分别说明什么**：`Zoom:` 不动而画面在动 → 倍率读回的欠账（#85），这句话别藏；`rot auto 1` 顺带把缩放切到 fit 是**成对语义**（回显里明说），可先 `zoom fit 0` 也解不开旋转那一钳（#93：钳的是"旋转在不在生效"，不是 fit 开关）⇒ 转着的时候放大档一律被拉回 fit，那一格也照样标 `(Fit)`；要"回到 1.00 倍"必须写 `zoom 1.0`，`zoom 1` 是开关（`main.c:951`）。

## 3. 五级可重构效果链 · 九种算法（约 60 s）

**说什么**：同一帧当场变算法。**前置**：`src 2`（在播的 SD 画面比图卡好看）+ 第 2 幕末尾的 `zoom auto`。
**位序**：`pipe` 的九个字符里**最左边那一个是 bit0**（`main.c:458`–`468`）。
```
pipe 000000000
pipe 000010000
pipe 000001000
th 60
pipe 000001010
pipe show
```
**看见什么算过**：从原图当场变**边缘**（第 5 个字符 = bit4 = Sobel）、变**二值**（bit5；`th 60` 一改黑白面积立刻变）、变**二值 + 腐蚀**（bit5+bit7 ⇒ 白笔画变细）；`pipe show` 按名字念（`[PIPE] sel=008 生效: sharpen`，`main.c:571`）。
**不通过分别说明什么**：屏上 `Pipe:` 那一格**不是**这串 0/1，它是五位、每位 0..3（每级选了第几个算法），有人问就敲 `pipe show` 给他看；`pipe 00001`（五位老串）**一个位都不写**、只回等价的九位（`main.c:463`），长度 6/7/8 一律拒；bit7 与 bit8 同时为 1 时两个形态学**都不做**（一遍 3×3 窗口做不了开/闭），那一格也因此给 0 而不是 3。

## 4. 同帧 A/B 分割线（原图 ↔ 处理图，约 40 s）—— 判断"某个现象属于哪一路"最省事的手段

**说什么**：一条缝把**同一时钟、同一份源坐标**下的"原图"和"处理后的图"摆在同一屏上；缝可以在屏里扫，也可以跟着画面转。
**前置**：先让处理那一路真的有活干：`pipe 000010000`（Sobel）。
```
split 50
split marker 0
split show
split 20
split video
split screen
```
**看见什么算过**：`split 50` + `split marker 0` ⇒ **一屏同时给出两份抽头**（左 = 原图、右 = 处理后），而且中间没有那条 2 px 标记线盖住缝那一列（`split marker 0` = 关，`main.c:1087`）；`split show` 必须回 `marker=off`（`main.c:1057`）；`split 20` 平移时两侧严格是同一帧；`split video` 之后旋转，缝跟着画面一起转（`main.c:1106`）。
**不通过分别说明什么**：`split show` 里 `marker=on` → 中间有人又敲过 `split marker 1`，重敲 `split marker 0` 再看 `show`；屏上 `Split:` 的百分比与 `show` 不同 → 缝位只有 10 位，`split 100` 被夹到 1023 并**在回显里说出来**（`main.c:1143`）；`split px 9999` 之类越界**必须被拒且不改状态**（`main.c:1124`）；`split range 20 80` / `split speed 2` 会被拒（端点与速度是构建参数，`main.c:1150`）—— 台上不要念。

## 5. 双线性插值开/关对照（约 25 s）

**说什么**：放大档的台阶是插值补掉的；整数倍率时插值按构造退化成最近邻，所以老行为没被偷偷改掉。
**前置**：`rot auto 0` + `zoom fit 0`（屏上 `Rot:` 必须是 0）+ `zoom 1.5`。
```
bilin off
bilin on
bilin show
```
**看见什么算过**：`bilin off` ↔ `bilin on` 在 **1.5×（非整数倍率）** 下斜边"硬台阶 ↔ 软过渡"当场切换；`bilin show` 的回声里那句"角度=0 且倍率非整数"（`main.c:964`）是 #104 之前的措辞，别照念（旋转态见下一条）。
**不通过分别说明什么**：**用 2.00×/1.00× 做对照看不出差别是正确行为**（每个源像素占整数个显示像素 ⇒ 小数权重 0 ⇒ 插值逐位等于最近邻；`sim/tb_v101_fb_bilin.v` 的 L5 用 4088 格钉住），别把它说成功能坏；**旋转态下现在切得出来**（#104 已修：旋转那一支过去把小数权重钉 0，现在接的是 `>>>16` 之后的 [15:8]；纵向那一次 `Y_disp = H/2 − Y_math` 的翻转必须连着 floor 一起改 —— 小数≠0 时多减一格、小数取 256−f；判据 `sim/tb_zoom_frac.v`：改前 298 行 FAIL、改后 `build/r94_zoomfrac_after.txt` 绿）；`bilin 2` 必须被拒（`main.c:972`）。

## 6. Gamma 表（256 项，可自动扫，约 30 s）

**说什么**：256 项曲线由 PS 算好灌进 PL，中间调当场压暗/提亮。**前置**：`split 50`（缝左边是原图 ⇒ 明暗对比当场成立）。
```
gamma 1.8
gamma auto 100 300 20 2000
gamma manual
gamma show
```
**看见什么算过**：`gamma 1.8` 立刻压暗中间调；`gamma auto …` 在 1.00..3.00 之间来回扫（2 s 一步 0.20），屏上 `Gamma:` 那一格的数字跟着走；`gamma manual` 停在当前值。
**⚠ 参数单位**：lo/hi 认 `1.20` 也认 `120`，但 **step 与 ms 必须是整数**，step 要的是 γ×100（`20` = 0.20）。
**不通过分别说明什么**：写成 `gamma auto 1.0 3.0 0.2 2000` 会被明确拒绝（`main.c:1185`），而拒绝就是**没改任何状态**；ms < 200 也拒（一次要写 256 项表，`main.c:1188`）；开机自检 `[GAMMA] g=… mono_bad=0 first=0 last=255` 若 `mono_bad≠0`，表已写入但**不要用它演**（`main.c:406`）。

## 7. 链路自诊断 + 端到端时延 + 片上温度（约 40 s）

**说什么**：时延多少毫秒、片上多热，都是板子**自己**报出来的数，不在我的嘴上。
```
stat
temp
temp th 60
temp
```
**看见什么算过**：`temp` 回 `[TEMP] degC=… raw=0x… vccint=…mv th=…C over=0 sane=1 osd=…C gpio=0x…`（`main.c:855`）—— 一行里驱动读数 / 屏上那三个字符 / 写进 PL 的值三方一致；`temp th 60` 之后**再敲一次 `temp`** 才有 `th=60C over=1`（阈值是比出来的，不是抄来的）；屏上 L3 的 `Latency:` 在有可信测量时是毫秒数。
**不通过分别说明什么**：屏上那一格是 `--` → "没有可信测量"，**不是** 0，不许现场说成 0（`osd_overlay.v:76` 的 `lat_ok`）；出现 `[TEMP!]`（`main.c:859`）→ 这一格的数不许写进报告；`temp th 60` 只回 `[TEMP] th=60C` → 正常，`over` 要下一次 `temp`（`main.c:825`）。⚠ **不要说"屏上那一格会变色"**：`osd_overlay` 只有一个 8 位 BCD 的 `temp_disp` 输入（`osd_overlay.v:90`），PL 侧没有任何温度告警通路，过阈值只体现在串口那一个 `over=`。

## 8. 复位对账（约 20 s）—— 这一串同时是"板子已经不干净了"的兜底

任何时候某一幕演砸、或你不知道板子被谁动过：**先敲 `stat` 看现在在哪，再敲下面这一整串**，然后回到第 0 步的判据重新开始。
```
pipe 000000000
th 80
zoom 1.0
zoom auto
zoom fit 0
rot auto 0
rot speed 0
bilin on
split screen
split 50
split marker 1
gamma off
temp th 85
src auto
stat
```
**每一项被前面某一幕改过的，都必须在这里写回去 —— 少一项就是没复位。** 三个反直觉的点：`zoom 1.0` 之后才 `zoom auto`（前者把**手动档**放回 1.00×，后者把控制权交回呼吸，反了就变成"手动停在 1.00×"）；`rot auto 1` 会顺带开 fit、还可能在 speed=0 时把它抬到 2（`main.c:1017`），所以两个都要归零；**`split marker 1` 才是初态** —— 那一位是"marker **off**"位（`main.c:1087`），开机默认蓝线是画着的。
**看见什么算过 / 不通过分别说明什么**：最后一条 `stat` 与第 0 步抄在纸上的那行**逐字段相等**（只允许 `pub=` 不同：发布位每 100 ms 翻一次）；不一致就是**状态没回去**，现场说清哪一项没回去比蒙混过去好得多。`playing=0` → 中途 `stop` 过，补一次 `play`；`sd=0` → 卡不在了，看第 9 幕；`geom=` 与基线不同 → 上面三个反直觉的点里少写回了一项。

## 9. 最后一演：拔掉 SD 卡（约 20 s，**排在第 8 幕收尾 `stat` 之后**）

这一幕只有**手上动作、没有串口命令** —— 拔插卡这件事脚本变不出来，需要一只手；它不进 `--emit` 那份排练脚本，也不参与首尾 `stat` 对账（对账在第 8 幕已经判完）。**前置**：卡正在播（第 8 幕那条 `stat` 里 `playing=1`）。
**说什么**："最后演一个更狠的：把卡直接拔掉。三件事同时发生 —— 画面 ≤0.5 秒换到片内图卡、左上角那一格跟着改口、串口说清它是**为什么**让位的。"
**看见什么算过**：≤0.5 s 落到 `SRC:TEST`，图卡自己在动（移动块 + 帧号格）；串口出一行 `[SRC] PS 停心跳：片源不可信（拔卡 / 读错），画面交回仲裁`（`main.c:256`）。
**不通过分别说明什么**：冻在最后一帧、屏上还写着 `SD` → 活判据/心跳那一条不在位流里，与命令无关；插回后不自动恢复 → 主循环每 2 s 试一次重挂（`main.c:1519` → `sd_play.c:607`–`637`），成功那行是 `[SD] 卡回来了：自动重挂 ok（试了 N 次），继续回放`；只有它自己报了"30 次没成功，停手"（`sd_play.c:627`）才需要手工 `sd remount`（`main.c:1265`）或重跑第 0 步三件套（约 90 s，不必拔电源）。
**如果有第二场**：第二场之前确认 `SRC:` 已回到 `SD` 且在播，否则第 1 幕那一跳演不出来；**只有这一场**就演完直接收场，不必恢复。
