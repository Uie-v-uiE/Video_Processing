# 2026 FPGA 创新设计赛道 · AMD 自主选题

摘自《全国大学生嵌入式芯片与系统设计竞赛'2026 FPGA 创新设计赛道选题指南（AMD）》§3.3，以及报名/提交常见要求。**以当年官网 PDF 为准。**

官网：http://www.fpgachina.cn/

---

## 1. 赛道与组别

| 组别 | 资格 | 器件 | 本项目 |
|------|------|------|--------|
| **初级组** | 大一至大三本科生 | 7 Series / **Zynq-7000** / UltraScale(+) | **XC7Z020 符合** |
| 高级组 | 大四及硕士 | 任意 AMD FPGA/SoC/Versal | — |

队伍含更高年级则归高级组。两组任务与提交物相同，**独立排名、独立评奖**。

报名后台有学生证/学历审核。

---

## 2. 评分权重

| 评测项 | 权重 |
|--------|------|
| 创新性与应用价值 | 30 |
| 性能与资源优化效果 | 20 |
| 功能正确性与设计完整性 | 20 |
| 大模型协作与技能包 | 15 |
| 文档质量与可复现性 | 15 |

初级组侧重：逻辑设计、状态机、时序约束、接口协议。  
高级组再加：软硬件协同与器件整体性能。

## 3. 工具与开源

- Vivado / Vitis **2026.1（推荐）或 2025.2**（本工程 2025.2.1）
- 强烈要求 GitHub/Gitee 开源，推荐 **MIT / Apache-2.0**
- 须提交 **大模型协作交互记录**（提示词、回答、纠错轨迹）
- 须提交 **skill/** 技能包（可复用，不绑死本题）

---

## 8. 答辩备问

| 问题 | 可答要点 |
|------|----------|
| 为何网口送视频？ | 赛题方向；PS 做协议、PL 做像素，分工清晰 |
| 为何 512×300？ | BRAM/带宽余量；再高主要卡片上存储 |
| 旋转为何少两个效果？ | 窗口滤波与旋转坐标不兼容，见 KNOWLEDGE A |
| 时序如何过？ | 50 MHz 像素钟 + mapper 插拍 + 0° 旁路 |
| UDP 如何保序？ | 包头 offset |
| EMIO 为何不用？ | 本板读回异常，改 AXI GPIO |
| 与金标如何比对？ | Python 模型同序输出 PNG |
