## 3. 演示时的三条口径边界

- SD 一路放的是 PC 预转换的 **512×300 RGB565 裸帧序列**（`src/host/make_sd_video.mjs` 生成），
  板上不做任何解码 ⇒ 对外说"SD 帧序列（预转换）"，不说 MJPEG/视频解码。
- 缩放 0.25×–2× 八档、旋转有限角度档、分割线 0–100 % 固定/自动扫描/贴在图像域跟随，
  都是**已实现且可当场演示**的；但小倍率与负半边会带来黑边与取样台阶（最近邻固有），
  被问到时说"对齐是修过的，台阶是最近邻"，不要说成"抖动已消除"。
- "为什么这一帧干不干净不用人眼看"是本作品的主张：同一组计数器有 OSD、JTAG 回读、
  串口三个出口，演示时先展示三方对账，再展示逐像素对照（`split 50` + `split marker 0` 一屏两条抽头）。
